---
title: 3.30. Showing Page Text by Background Image Number
---

> [!abstract] Make background images from page text, and show them with a packet or the discrete signal input board


#### 1. Send a background playlist (.bgp)

1. Run DabitOne and connect
2. Register the number of page text pages (number of pages: 5 > Send)
	- DabitOne: `전송` (Send) > `페이지메시지` (Page message) > `페이지 수` (Page count)
	- DBPS: `설정` (Settings) > `페이지 메시지 설정` (Page message settings) > `총 개수 설정` (Total count setting)
	- DabitChe: `고급설정` (Advanced settings) > `Protocol Simulator` > `특수기능` (Special functions) > `페이지문구 페이지 개수` (Page text page count)
3. Register and upload the display files 
	- Register 5 normal texts in the playlist of the DabitOne `편집` (Edit) tab
	- Select the file type `배경 파일 (*.bgp)` (Background file (*.bgp)) and save
	- Upload with the `전송` (Send) button

When you complete this step, the 5 normal texts (default values) show repeatedly in order

#### 2. Send page text packets

- Send page text packets in DabitOne (legacy: DBPS, Dabit Protocol Simulator, and DabitChe send the same packets)
- Examples
	- `![001/P0000/C1안녕하세요!]` («Hello»)
	- `![001/P0100/C2반갑습니다!]` («Nice to meet you»)
	- `![001/P0200/C3감사합니다!]` («Thank you»)
	- `![001/P0300/C6가나다라마바!]` (Korean letters)
	- `![001/P0400/Y0004/E0606/S1000/C7방문을 환영합니다.!]` («Welcome to your visit.»)


When you complete this step, the 5 page texts that you entered above show repeatedly in order

#### 3. Send a blank playlist (.pla)

1. Make and save 1 blank screen (.dat) with nothing entered
2. Register and upload the display file
	- Register only the 1 blank screen in the playlist of the DabitOne `편집` (Edit) tab
	- Select the file type `스케줄 파일 (*.pla)` (Schedule file (*.pla)) and save
	- Upload with the `전송` (Send) button

#### 4. Call a page number to show it
- Send the background image packet: `![0020xxx!]`
- Call the number with a discrete signal - [[3.8. Showing Playlists with the Discrete Signal Input Board]]
