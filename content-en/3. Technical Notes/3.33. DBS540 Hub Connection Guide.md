---
title: 3.33. DBS540 Hub Connection Guide
---

> [!abstract] How to connect 4 lines of panels to one controller port with the DBS540 hub
> The commands to turn the hub mode on and off, the supported models and firmware, and the panel conditions to check before you turn it on

#### What is a hub connection?

- You connect the **DBS540 hub** to the panel ports of the controller (`J10`·`J11`), and the hub splits the panels into **4 lines (4 chains)**
- Connecting the panels to the controller directly, without a hub, is called **direct connection**
- The controller works in only one mode: direct or hub. To change it, use the commands below

#### Supported models and firmware

| Model | Colors | Firmware |
| --- | --- | --- |
| DB720 series | 256 colors | Official V4.5.4 |
| DB520 series | — | No hub support (direct connection only) |

- DB400 · DB402 · DB502 · DB600 do not support the hub mode
- **DB520 supports direct connection only** — use the hub only with DB720
- If you send the command to firmware that does not support it, the response is `![00H8F3!]`

#### Turning on the hub mode

1. Send the ASCII command `![00H81!]` to the controller
2. The board responds and then **reboots by itself** (no response for about 5 seconds)
3. After the reboot, it works in hub mode

> [!warning] It applies after the reboot
> The hub mode is a value that sets the use of the panel port pins at boot, so it does not change at once. Even if no write response comes, do not treat it as a failure. Check with the methods below after the reboot

#### Going back to direct connection

1. Send `![00H80!]`
2. In the same way, the board reboots by itself and then works in direct connection

#### Checking the current state

- **Check only the hub mode**: `![00H8!]` → `![00H8 {"saved":1,"applied":1}!]`
	- `saved`: the saved value, `applied`: the value applied now
	- `0` is direct connection, and `1` is hub
	- Right after a write, only `saved` changes. `applied` follows after the reboot
- **Check together with the firmware information**: `HB=a1s1` at the end of the `![0081!]` response
	- `a` is the applied value, and `s` is the saved value — see [3.21. Reading Controller Firmware Information](https://docs.dabitsol.com/3.21) (Korean)

#### Check before you turn it on

> [!warning] Do not turn it on for 1/32 scan panels
> The hub mode **uses pin 8 (E) of the HUB75 cable to select the chain**. 1/32 scan panels use this pin as a row address, so the screen overlaps if you turn on the hub mode. Use it **only for panels of 1/16 scan or lower**

#### Find it by symptom

| Symptom | What to check |
| --- | --- |
| Only half of the panel shows, or it shows black | Check `HB` in `![0081!]`. If it is direct connection but `HB=a1`, send `![00H80!]` and reboot |
| The screen overlaps | Check whether the panel is 1/32 scan. If it is 1/32, turn off the hub mode |
| Only the modules in the first row do not show | Upgrade the firmware to the official V4.5.4 |
| The response is `![00H8F3!]` | DB520 does not support the hub (direct connection only). If it is DB720, upgrade the firmware to the official V4.5.4 |

- For wiring and the connection of each module, see [[3.7. Signal Distribution Board Connection Guide]]
