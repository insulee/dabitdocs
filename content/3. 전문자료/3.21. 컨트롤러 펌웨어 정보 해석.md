
> [!abstract] 다빛솔루션 컨트롤러 펌웨어 정보 읽는 방법
> 다빛 컨트롤러의 펌웨어 정보는 컨트롤러의 상태 확인, 고장 진단 및 업그레이드 과정에서 중요한 데이터로, 다빛솔루션 컨트롤러의 펌웨어 정보를 읽고 해석하는 방법에 대한 설명

#### 펌웨어 정보 읽기 방법

- 아래 방법 중 하나를 사용하여 펌웨어 정보를 확인
	1. DabitOne
	    - `고급` > `펌웨어 업데이트` > `펌웨어 읽기`
	2. ASCII 또는 헥사 프로토콜 전송
	    - ASCII 프로토콜: `![0081!]`
	    - 헥사 코드: `10 02 00 00 02 6F F1 10 03`

#### 펌웨어 정보 해석 예시

```
<32> DIBD600T_08C_04R020C V3.0.6 2024-12-13 
02x006-L0-F0U0-D1-S4P05_0_E1-blV0
R-180MHz-16D_D1S11_11-C0-G-W 
mac:54-ff-82-01-2d-c3 ip:192.168.000.201 port:05000 
Addr:00-115200bps
```

| **항목**                  | **항목설명 및 옵션내용**                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `<32>`                  | 펌웨어 구분 번호                                                                            |
| `DIBD600T`              | 해당 컨트롤러 모델 이름                                                                        |
| `08C`                   | 표시 색상<br>`08C`: 8컬러, `08B`: 256컬러, `02B`: 3컬러                                        |
| `04R020C`               | 최대 표출 화면 크기<br>세로 `4`단, 가로 `20`열                                                     |
| `V3.0.6`                | 펌웨어 버전                                                                               |
| `2024-12-23`            | 펌웨어 제작 날짜                                                                            |
| `02x006`                | 현재 설정된 화면 크기<br>세로 `2`단, 가로 `6`열                                                     |
| `L0`                    | 모듈 배열 방식<br>`L0`: 가로형, `L1`: 1줄 세로형, `L2`: 2줄 세로형, <br>`L3`: 가로줄 양면형, `L4`: 세로줄 양면형  |
| `F0U0`                  | 외부 메모리 상태<br>`F`: 플래쉬롬, `S`: SD 메모리, `U`: USB 메모리<br>`0`: 연결되지 않음, `1`: 연결됨          |
| `D1`                    | 디버깅 모드 값<br>`0`: Disable, `1`: Enable1 ..... `8`: Enable8                            |
| `S4`                    | 섹션 개수<br>섹션 `4`개까지 분할가능                                                              |
| `P05`                   | 페이지 메시지 설정 개수<br>페이지 메시지 `5`개 등록                                                     |
| `0`                     | 페이지 메시지 저장 위치<br>`0`: Flash ROM, `1`: RAM                                            |
| `E1`                    | 실시간 문구 관련 설정<br>`E0`: 섹션별 효과 동시 시작, `E1`: 섹션별 효과 개별 시작                               |
| `blV0`                  | 부트로드 버전<br>`blV0`: 부트로드 V8.0, `blV1`: 부트로드 V3.0.0                                    |
| `R`                     | 펌웨어 모드<br>`R`: Release 모드, `D`: Debugging 모드                                         |
| `180MHz`                | CPU 클럭 주파수                                                                           |
| `16D_D1S11_11`          | 표출 신호 설정값                                                                            |
| `C0`                    | 조도 센서 상태<br>`C0`: 수동 모드, `C1`: 자동 모드                                                 |
| `G W`                   | 적용 옵션<br>`G`: GPS, `W`: Watchdog Reset, `B`: Bluetooth, <br>`M`: Modbus, `K`: 암호롬 적용 |
| `mac:54-ff-82-01-2d-c3` | MAC 주소                                                                               |
| `ip:192.168.000.201`    | 설정된 IP 주소                                                                            |
| `port"05000`            | 설정된 포트 번호                                                                            |
| `Addr:00`               | RS485 통신 주소                                                                          |
| `115200bps`             | RS485 통신 속도                                                                          |
