
> [!abstract] 접점보드를 이용하여 표시목록을 표출하는 방법 안내
> PLC 또는 릴레이/스위치로부터 접점 신호를 받아서 미리 저장된 번호의 메시지를 LED 모듈에 표시하는 방법 안내

#### 접점입력 변환보드 연결 방법

1. **PLC NPN 출력카드**
	- PLC의 COM 단자와 외부전원의 플러스(+12V/24V)와 연결
	- 접점보드 COM 단자와 외부전원의 마이너스(-GND)와 연결
	- PLC와 접점보드의 S1~S8을 연결
	- ![[접점보드NPN.png]]
2. **PLC PNP 출력카드**
	- PLC의 COM 단자와 외부전원의 마이너스(-GND)와 연결
	- 접점보드 COM 단자와 외부전원의 플러스(+12V/24V)와 연결
	- PLC와 접점보드의 S1~S8을 연결
	- ![[접점보드PNP.png]]
3. **PLC RELAY 출력카드**
	- PLC의 COM 단자와 접점보드의 RCOM 단자를 연결
	- PLC와 접점보드의 S1~S8을 연결
	- ![[접점보드RELAY.png]]

#### 접점입력 설정 및 전광판 표시
- 컨트롤러의 JP3 3Pin Connector
    - 3.3V와 COM 을 점퍼핀으로 연결 (PLC RELAY 출력시)
        - BH1의 1번핀(VDD)으로 3.3V를 공급
        - "접점 신호 입력 모듈"의 입력 신호는 4V ~ 28V 사이의 전압에서 정상 동작
    - 5V와 COM 을 점퍼핀으로 연결
        - BH1의 1번핀(VDD)으로 5V를 공급
        - "접점 신호 입력 모듈"의 입력 신호는 9V ~ 28V 사이의 전압에서 정상 동작
- 보드기능설정 > BH1(TTL/RS485) Function에서 3가지 접점입력 설정이 가능
	- 8Pin Input(HEX): 최대 255개의 리턴값
	- 8Pin Input(BCD): 최대 99개의 리턴값
	- 8Pin Input(Number): 최대 8개의 리턴값
	- 3가지 접점입력 방법별 자세한 리턴값은 [[3.9. 접점신호 설정별 리턴값]] 참고
- (중요) 접점보드 S5에 적색 점등 되거나, 데이터가 전송 안될 때
	- 보드기능설정 > BH1(TTL/RS485) Function이 TTL/RS485 인지 확인 후 8Pin Input으로 변경
	- **점퍼핀을 3.3V <-> 5V로 변환**해보는 것을 권장
- [[2.7.3. 표시목록 만들기]], [[3.30. 페이지 문구를 배경이미지 번호로 표시]]를 통해 미리 업로드한 문구 또는 이미지를 접점입력으로 호출하여 LED 모듈에 표시
