---
title: 7.7. Display Signal Filter
---

> [!abstract] In the display signal list, check only the conditions that you know, such as duty, drive method, and driver IC, and the list narrows at once
> When you are not sure of a condition, turn on several values together. The filter window opens attached to the left side of the program, so you see the list get shorter the moment you check an item.

#### Overview

- The display signal list has more than 40 types, so it is hard to find the signal of a module that you see for the first time.
- `표출신호 필터` (Display signal filter) narrows the candidates with **only what you know** from the back of the module or its documents. You do not need to know everything.
- The filter does not change the signals themselves — it changes only the items shown in the list.

#### How to use

1. `설정` (Settings) > `표출신호 설정` (Display signal settings) > the `표출신호 필터` (Display signal filter) button under the list
2. The filter window opens **attached to the left side** of the program. Check the conditions that you know
3. The moment you check an item, the display signal list behind it gets shorter — check the remaining signals with `전송` (Send) or `자동전송` (Auto send)
4. Click `초기화` (Reset) to clear all, and the list returns to the full list

#### Conditions that you can select

| Condition | Example | Where to check |
| --- | --- | --- |
| Duty | 1/8, 1/16, 1/32 | Marking on the back of the module (example: `1/16S`, `16S`) |
| Data line | Single (D1), dual (D2) | Module specification, HUB75 connector signals |
| Drive method | BCM / S-PWM / EPWM | Set by the driver IC type (below) |
| Driver IC | Standard, SM16380SA, IT1504, FM6363C … | IC part name printed on the module board |
| Decoder IC | 74HC138, 74HC595, L800 … | IC part name printed on the module board |
| Other conditions | Control pixel count, module type, color order | Folded — unfold it when you need it |

> [!tip] When you are not sure, turn on several values
> When you check several values in one row, the signals that **match any of them** remain. If you do not know whether it is 1/8 or 1/16, turn on both, and run the remaining candidates with `자동전송` (Auto send).

> [!tip] Items shown dimmed
> A value that has no matching signal under the conditions that you selected now shows dimmed. If you select it, the list becomes empty. If that value is correct, check the other conditions again.

#### What is a drive method

The method to drive the LED display falls into 3 types by the driver IC. When the method is different, the brightness control and the transfer operation are different, so they must match.

- **BCM** — most HUB75 modules (standard IC, FM6126A, ICN2038S, MBI5153, and others)
- **S-PWM** — SM16380SA(I7), IT1504(I8)
- **EPWM** — FM6363C(I9). A third method that is neither BCM nor S-PWM

> [!note] The DB720 shows **ICND1065L** panels — I code **I10** (S-PWM)
> See [[2.3.2. Display Signal String Pattern Protocol Settings]]

When an S-PWM · EPWM module receives a display signal, the LED display turns itself on again. It is normal that the screen is empty for a few seconds.

#### Showing old-version signals

- When you turn on `구버전 6종도 보기` (Also show 6 old-version types) at the bottom of the filter window, 6 old signals without a string pattern are added separately at the bottom of the list
- These signals have no header information, so the conditions above do not filter them. Turn them on only when old documents show their names

#### When a filter stays on

- The filter stays on after you turn the program off and on
- When a filter is on, **`필터 적용 중 · 모두 보기`** (Filter on · Show all) shows above the list. On a PC that several people use, if the list looks short, check this line. Click `모두 보기` (Show all) to return to the full list

> [!note] List order
> The display signal list is sorted from the largest duty (1/32 → 1/1). Newly added module signals go into the same order.
