
>[!abstract] 컨트롤러의 펌웨어 정보 확인 및 업데이트 방법 안내

### dbPS

#### 펌웨어 업로드 창 열기
- `설정` > `펌웨어 업로드` 선택

#### 펌웨어 정보 확인
1. 통신 연결 후 `펌웨어 읽기` 버튼 클릭
2. **컨트롤러 펌웨어 정보** 영역에 현재 펌웨어 정보 표시

#### 펌웨어 업로드
1. `불러오기` 버튼 클릭
2. 펌웨어 폴더에서 업로드할 펌웨어 파일(.bin) 선택
3. **업로드 펌웨어 정보** 영역에 선택한 펌웨어 정보 확인
4. `파일 전송` 버튼 클릭
5. 펌웨어 업로드 진행 및 완료

### 다빛프로토콜시뮬레이터

#### 펌웨어 업그레이드 창 열기
- `설정 및 제어` > `펌웨어 업그레이드` 선택

#### 펌웨어 정보 확인
1. 통신 연결 후 `읽기` 버튼 클릭
2. **Controller firmware information** 영역에 현재 펌웨어 정보 표시

#### 펌웨어 업로드
1. `열기` 버튼 클릭
2. 펌웨어 폴더에서 업로드할 펌웨어 파일(.bin) 선택
3. **Firmware file information to be updated** 영역에 선택한 펌웨어 정보 확인
4. `전송` 버튼 클릭
5. 펌웨어 업로드 진행 및 완료
