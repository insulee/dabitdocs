
> [!abstract] 표시목록 만들기
> - DabitOne: `편집` 탭에서 표시목록 작성 > `저장`(.pla/.bgp) > `전송` 버튼 한 번으로 컨트롤러 전송
> - 다빛채(레거시): .dat파일을 playlist file(.pla) 또는 background playlist(.bgp) 파일로 표시목록을 만들어 컨트롤러에 전송하는 방법

### DabitOne

#### 표시목록 작성
1. `편집` 탭 > `새표시목록`
2. `추가`로 항목(행) 추가. `삭제`, `↑`/`↓`(순서 이동), `복제`로 목록 정리
3. 항목 내용 채우기 — 두 가지 방법
	- 행 오른쪽 `편집` 버튼 > `콘텐츠 편집` 창에서 문구·이미지를 만들고 `표시파일에 적용`
	- `표시파일명` 더블클릭 > 파일 종류 선택(`이미지`/`동영상 (GIF)`/`페이지문구`)
		- `이미지`·`동영상 (GIF)`: 파일 선택 창에서 파일 선택
		- `페이지문구`: 파일 선택 없이 선택 즉시 항목에 등록
4. 화면 아래 `표시파일 보기`에서 콘텐츠 표출 모습 미리 보기 — 전송 전 점검 상세는 [[7.1. 미리보기와 전광판 화면]]
- 이미지(.dat)와 동영상(.ani)을 한 목록에 섞어 넣기 가능 — [[7.9. 영상과 이미지 혼합 스케줄]]

#### 저장 — pla와 bgp
- `저장` 또는 `다른이름저장` > 파일 형식 선택 (기본 폴더 `Data\Playlist`)
	- 메인스케줄: `스케줄 파일 (*.pla)` — 컨트롤러가 항목을 효과·속도·유지시간대로 순서대로 자동 표출
	- 배경이미지: `배경 파일 (*.bgp)` — 컨트롤러 메모리에 담아 두고 표출신호(번호 명령)로 골라서 표출
- 마지막에 연 표시목록은 프로그램을 다시 시작해도 자동 복원

#### 전송
1. `편집` 탭 > `전송`
	- 저장하지 않은 목록이면 저장 확인 창이 먼저 표시. 저장한 확장자(.pla/.bgp)에 따라 전송 방식 결정
2. 전송 전 자동 검사 — 참조한 .dat/.ani 파일이 없거나 전광판보다 큰 이미지가 있으면 팝업으로 알리고 전송 중단 ([[7.4. 전송 전 안전장치]])
3. 연결되어 있지 않으면 현재 통신 설정으로 자동 연결
4. 진행률 창 표시, `취소` 가능. 완료되면 "전송 완료" 알림 표시

### 다빛채

#### 표시목록 만들기
- 표시목록 > 표시파일명 > `이미지` 또는 `동영상` > Select file > .dat 또는 .ani 선택 > `열기`
- `+` 버튼을 눌러 최대 255개 이미지와 애니메이션 파일 추가 가능
- `파일` > `저장` > Save as > 파일형식 > 
	- 메인스케줄:  `Playlist File (*.pla)`> .pla 파일이름 입력 > `저장`
	- 배경이미지: `BG Playlist(*.bgp)` > .bgp 파일이름 입력 > `저장`
- `컨트롤러 접속` > `업로드`
