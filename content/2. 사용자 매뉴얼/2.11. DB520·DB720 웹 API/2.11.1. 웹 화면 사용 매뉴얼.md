> [!abstract] 폰 브라우저로 DB520·DB720 전광판의 문구·밝기·화면 크기를 바꾸는 방법을 안내합니다
> 사장님이 문구를 바꾸는 순서를 앞에, 설치기사가 연결·크기를 잡는 절차를 뒤에 두었습니다.

## 1. 먼저 알아둘 것 5가지

1. **폰과 전광판이 같은 Wi‑Fi(공유기)에 있어야** 합니다. 인터넷은 필요 없습니다.
2. **내가 보낸 문구는 미리보기가 선명**하고, 다른 프로그램이 띄운 화면은 흐리게 보입니다. 고장이 아닙니다.
3. **밝기는 최소 1%**입니다. 0%는 "자동 밝기"라는 뜻이지 꺼짐이 아니라서 이 화면에서는 쓰지 않습니다.
4. **화면 크기를 적용하면 전광판이 약 10초 재시작**합니다. 그동안 연결이 잠깐 끊깁니다.
5. **`배경이미지` 버튼은 지금 펌웨어에서 동작하지 않습니다.** 10절을 보세요.

## 2. 지원 대상

- **컨트롤러**: DB520·DB720 계열 모두 됩니다 (DIBD520S·DIBD720U 실기 확인)
- **펌웨어**: V3.8.5 이상에서 확인했습니다 (V3.8.5·V4.2.0 실기 확인)
- **폰 브라우저**: 아이폰 Safari, 안드로이드 Chrome
- **접속 주소**: `http://<컨트롤러 IP>/` — 지금 접속한 주소는 `설정` 시트의 `컨트롤러 주소`와 홈 맨 아래에 표시됩니다

## 4. 문구 보내기

![[db720-web-02-compose.png|300]]

1. 홈에서 `문구 작성`을 누릅니다.
2. **종류를 고릅니다.** `실시간 메시지`는 저장되지 않고 바로 떴다가 다음 문구가 오면 사라집니다. `페이지 메시지`는 전광판에 저장되어 전원을 껐다 켜도 남고, 페이지 수만큼 번갈아 표시됩니다.
3. `글 내용`에 문구를 적습니다. 최대 200자입니다.
4. `글자색`에서 8색 중 하나를 고릅니다. 검정·빨강·초록·노랑(기본)·파랑·분홍·하늘·흰색 순입니다.
5. `입장효과`와 `방향`을 고릅니다. 기본은 `정지`·`방향없음`이고, 효과는 정지·이동·와이프·블라인드·커튼 등 12가지입니다. 효과에 따라 방향 목록이 바뀝니다.
6. `퇴장효과`는 기본이 `사용 안 함`입니다. 그대로 두면 문구가 **계속 켜져** 있습니다.
7. `효과속도`(아주 빠름~아주 느림)와 `유지시간`(0초~40초)을 고릅니다. 기본은 `보통 (20)`·`1초`입니다.
8. `글자 크기`를 고릅니다. `12×12`부터 `64×64`까지 있고 기본은 `16×16 (기본)`입니다.
9. `전광판으로 전송`을 누릅니다. 페이지 메시지는 "페이지 N에 저장합니다 … 진행할까요?" 확인창이 한 번 더 뜹니다.

![[db720-web-03-after-send.png|300]]

- 성공하면 **"실시간 메시지를 전송했습니다"** 또는 **"저장했어요"** 알림이 뜹니다. 실패하면 붉은 알림이 이유와 함께 뜹니다.
- 글이 화면 폭보다 길면 **"글이 길어요 — 이동/와이프 계열 효과로 하면 전체가 보여요"** 안내가 뜹니다.
- 이모지 등 전광판이 못 그리는 글자가 있으면 입력칸 아래에 **깨지거나 빈칸이 될 수 있다는 경고**가 뜹니다.

> [!tip]
> 마지막에 보낸 문구와 옵션은 이 폰에 기억됩니다. 다음에 `문구 작성`을 열면 그대로 복원됩니다.

## 5. 미리보기 읽는 법

![[db720-web-03b-preview.png|300]]

- **내가 보낸 문구는 선명하게** 보입니다. 전광판과 같은 도트 글꼴로 폰이 직접 그리기 때문입니다.
- **다른 프로그램이 보낸 화면·저장된 페이지·특수문자 문구는 흐리게** 보입니다. 전광판 실물 영상을 그대로 받아 오기 때문이며, 흐려도 그것이 진짜 화면입니다.
- 미리보기 아래 **"실시간 화면"** 은 영상이 정상으로 오고 있다는 뜻이고, 오른쪽 **"96×32px"** 는 지금 전광판 크기(가로×세로 픽셀)입니다.
- 캡션이 **"미리보기 일시 중단"** 이면 영상이 잠시 끊긴 상태, **"오프라인 — 연결을 확인해 주세요"** 면 전광판과 연결이 끊긴 상태입니다.

## 6. 전원·밝기·페이지·점검 패턴

![[db720-web-04-control.png|300]]

- **전원**: 홈 카드의 `켜기`/`끄기`입니다. 성공하면 "화면을 켰어요"/"화면을 껐어요"가 뜹니다.
- **밝기**: `전광판 제어` > `밝기`에서 `100%`·`75%`·`50%`·`25%`·`최소` 중 하나를 누릅니다. `최소`는 1%입니다.
- **페이지 수**: `페이지 수 / 초기화`에서 1~10개를 고르고 `전송`을 누릅니다. 저장된 페이지가 이 수만큼 번갈아 표시됩니다.
- **초기화**: 지울 페이지(`전체 (페이지 1~10)` 또는 페이지 1~10)를 고르고 `초기화`를 누릅니다.
- **점검 패턴**: `화면 점검 패턴`에서 8종(전면 적색·녹색·청색·백색, 컬러바, 격자, 가로 줄무늬, 모듈 경계) 중 하나를 고르고 `켜기`를 누릅니다. `끄기`를 누르면 원래 화면으로 돌아옵니다.

> [!warning] 초기화는 되돌릴 수 없습니다
> 확인창에 "지운 문구는 되돌릴 수 없습니다 (보드 영구 반영)"이 뜹니다. 페이지 수 변경도 전광판에 영구 저장됩니다.

## 7. 화면 크기

![[db720-web-05-size.png|300]]

- 단위는 **16px 모듈 개수**입니다. `세로` 2 × `가로` 6이면 32px × 96px이고, 칸 아래에 픽셀 수가 바로 계산되어 보입니다.
- 각 칸은 1~60까지 넣을 수 있습니다. 시트를 열면 지금 전광판 값이 채워져 있습니다.
- `적용`을 누르면 "세로 2(32px) x 가로 6(96px)로 바꿀까요?" 확인창이 뜹니다.
- 적용 뒤 **"적용했어요 — 보드가 재시작 중입니다(약 10초)"** 가 뜨고 연결 점이 잠깐 빨강이 됩니다. 10초쯤 지나면 저절로 돌아옵니다.
- 전광판이 못 받는 크기면 **"이 보드는 6열×4단을 다 못 해요 — 6열×2단으로 적용됐어요"** 처럼 실제 적용된 값을 알려 줍니다.

> [!note] 설치기사용
> 화면 크기는 설치할 때 실제 모듈 수에 맞춰 한 번만 잡습니다. 사장님은 손대지 않아도 됩니다.

## 8. 설정

![[db720-web-06-settings.png|300]]

- `이름`: 가게 이름 등 최대 20자입니다. 홈 왼쪽 위 제목(`내 전광판`)이 이 이름으로 바뀌며, 이 폰에만 저장됩니다.
- `컨트롤러 주소 (고급)`: 지금 접속한 전광판 주소입니다. 여기서는 표시만 되고 바꿀 수 없습니다. 다른 전광판에 접속하려면 브라우저 주소창에 그 주소를 입력합니다.
- `API 키`: 보통 **"키 없음"** 으로 표시되며 입력할 수 없습니다. 키가 설정된 전광판이면 "설정됨 (마스킹)"으로 보입니다.

## 9. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| 연결 점이 초록이 아님(빨강·회색) | 폰과 전광판이 다른 Wi‑Fi에 있거나 전광판 전원이 꺼짐 | 폰 Wi‑Fi를 전광판과 같은 공유기로 바꾸고 전원을 확인한 뒤 새로고침 |
| 문구를 보냈는데 전광판이 안 바뀜 | 실패 알림을 놓쳤거나, 다른 프로그램이 카메라 영상을 송출 중 | 다시 보내서 알림 문구 확인. "카메라 영상 송출 중" 확인창이 뜨면 그 프로그램에서 저장 콘텐츠로 전환 |
| 미리보기가 흐림 | 다른 프로그램이 보낸 화면이거나 저장된 페이지 | 정상입니다. 내가 문구를 보내면 그 문구는 선명하게 보입니다 |
| 미리보기가 검정이거나 "미리보기 일시 중단" | 영상이 잠시 끊김 | 몇 초 기다립니다. 계속되면 새로고침 |
| `100%`를 눌렀는데 "밝기 99%"라고 뜸 | 전광판이 받는 최대치가 99 | 정상입니다. 99%가 가장 밝은 값입니다 |
| 화면 크기 적용 뒤 잠깐 끊김 | 전광판이 새 크기로 재시작(약 10초) | 기다린 뒤 `화면 크기`를 다시 열어 값을 확인 |
| 특수문자·이모지가 안 나옴 | 전광판 글꼴에 없는 글자 | 한글·영문·숫자·기본 기호로 바꿉니다 |
| 다른 폰에서 바꾼 문구가 내 `문구 작성` 칸에 없음 | 작성 칸은 이 폰이 마지막에 보낸 내용만 기억 | 지금 화면은 미리보기로 확인합니다. 홈은 새로고침하면 최신 상태가 됩니다 |
| 폰이 "인터넷 없음"이라며 Wi‑Fi를 끊음 | 인터넷이 안 되는 Wi‑Fi를 폰이 스스로 끊거나 데이터로 바꿈 | 폰 Wi‑Fi 설정에서 그 네트워크를 계속 유지하도록 두고, 모바일 데이터 자동 전환을 끕니다 |

## 10. 아직 안 되는 것

> [!warning] 확정 전에는 되는 것으로 안내하지 마세요
> 아래는 확인 중이거나 지금 구조로는 안 되는 항목입니다. 되는 것처럼 안내하면 현장에서 불신이 생깁니다.

- **배경이미지**: `전광판 제어` > `배경이미지` > `전송`을 눌러도 "웹에서는 아직 배경이미지를 지원 준비 중이에요 (펌웨어 확인 중)"만 뜹니다. 펌웨어 쪽에 확인을 요청한 상태입니다.
- **가게 밖 원격 접속**: 같은 Wi‑Fi 안에서만 됩니다. 밖에서 쓰려면 별도 중계 서비스가 필요합니다.
- **폰 직접 연결**: 전광판에 폰을 블루투스나 Wi‑Fi로 바로 붙이는 기능은 없습니다. 반드시 공유기를 거칩니다.
- **웹으로 화면 파일 올리기**: API 키가 필요한 기능이라 이 화면에서는 제공하지 않습니다.
