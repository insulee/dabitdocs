>[!abstract] How to set the display signal — display signal, Color Order, and Scan Order settings, and how to match the Color Order when the colors look different
### Where to set the display signal

#### DabitOne
- `설정` (Settings) > `표출신호 설정` (Display signal settings)

#### DBPS
- `설정` (Settings) > `표출신호 설정` (Display signal settings)

#### DabitChe
- `환경설정` (Preferences) > `표출신호 설정` (Display signal settings)


### How to set the display signal
- Display signal: `the display signal of the module` 
- Color Order: `RGB` (change it if necessary — see «When the colors look different» below)
- Scan Order: `138 IC` (default value)
- `전송` (Send)

### When the colors look different — match the Color Order

If the LED display shows a color that is different from the color that you sent, the **Color Order** does not match the module. The color code such as `/C` or the text is not wrong. Each module has a different order of R · G · B signal lines.

- These are the symptoms: you entered the color code from the manual, but a different color shows · you sent red, but blue or another color shows · the text colors are swapped

1. Send text that has red, green, and blue. ASCII example: `![000/C1빨강/C2초록/C4파랑!]` («red», «green», «blue») — in DabitOne, use `전송` (Send) > `HEX 프로토콜` (HEX protocol) with text color `1234567` and text `적녹노파분청흰` («red, green, yellow, blue, pink, cyan, white») to see 7 colors at once
2. In `설정` (Settings) > `표출신호 설정` (Display signal settings), change `Color Order` one at a time, starting from `RGB`, and click `전송` (Send) each time. Order: RGB → RBG → GRB → GBR → BRG → BGR
3. The order that shows red, green, and blue correctly, as you sent them, is the Color Order of that module. Keep that value

- For how the Color Order maps to the `C` parameter of the display signal string (RGB=C1 … BGR=C6), see [[2.3.2. Display Signal String Pattern Protocol Settings]]

### When the program does not have the display signal

- Check whether the drive IC is supported
- Set the display signal with [[2.3.2. Display Signal String Pattern Protocol Settings]]


### DabitOne display signal screen functions (as of V4.6.0)

You can use the functions below on the `설정` (Settings) > `표출신호 설정` (Display signal settings) screen.

#### View two signal systems

- You can view the signal list in two systems: **string pattern** (for example: `S16D1T1C0I0W16P0_a16`) and **legacy signal** (for example: `16D-P16D1S11`). The list is sorted from the largest duty (1/32 → 1/1)
- Switch with the `이전 신호 보기` (Show legacy signals) / `문자열 패턴 보기` (Show string patterns) buttons below the list
- Even if an old document gives only the legacy signal name, you can find it and use it as is

#### Display signal filter — select only the conditions that you know to narrow the list

- When you click the `표출신호 필터` (Display signal filter) button below the list, the filter window opens, attached to the left side of the program
- When you select duty · data lines · drive type (BCM / S-PWM / EPWM) · driver IC · decoder IC, the list gets shorter **immediately**
- If you select several items in one row, signals that match any of them stay — "if you are not sure whether it is 1/8 or 1/16", select both
- If you select nothing, all signals show. For details, see [[7.7. Display Signal Filter]]

#### Check the module information

- When you select a signal in the list, `모듈 정보` (Module information) on the right shows the modules that use the signal
- It shows Dabit Solution product names and compatible modules of other companies (HUB75 type) together. This helps when you search for the signal from the model name on the back of a module

#### Register frequently used signals with ★

- Select a signal and click `★ 등록` (★ Register). The signal is pinned at the top of the list with a ★ mark
- Select it again and click `★ 해제` (★ Unregister) to unpin it. Use this to collect the signals that you often use at each site at the top

#### Memo

- You can leave a memo for each signal (for example: "OO site P10 module")
- When you write a memo and click `메모 저장` (Save memo), it stays even after you restart the program

#### When you do not know the display signal — auto send

- When you click `자동전송` (Auto send), the program sends the signals in the list one by one at the set interval (default 3 seconds)
- **The signal at the moment the screen shows correctly is the display signal of that module.** Click `중지` (Stop), and confirm that signal with `전송` (Send)
- With a wrong signal, the text looks mixed or squashed, or the screen does not show anything

#### A signal that is not in the list — enter the display signal

- When you click the `표출신호 입력` (Enter display signal) button, a window opens where you enter the code directly
- `전송` (Send): applies the code to the LED display right away / `등록 후 전송` (Register and send): saves it to the list and applies it — a registered code stays even after you restart the program
- Manage registered signals with `선택 전송` (Send selected) · `삭제` (Delete) in the same window
- For the code rules, see [[2.3.2. Display Signal String Pattern Protocol Settings]]. Supported on controller firmware V3.8.3 or later

> [!tip] New controllers (firmware V3.8.3 or later) can read and set the display signal with the ASCII command `![00H2!]` — see [[2.9.2. New and Legacy Command Mapping Table]]

> [!info] For the display signals of Dabit Solution modules and modules of other companies, see [[3.1. LED Module Information and Display Signals]]
