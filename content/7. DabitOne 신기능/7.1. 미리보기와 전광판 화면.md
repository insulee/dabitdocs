> [!abstract] 미리보기와 전광판 화면 (DabitOne 신규)
> DabitOne은 화면을 두 가지로 표시 — 보내기 **전** 점검용 *미리보기*와, 보낸 **후** 실제 표출을 비추는 *전광판 화면*.

#### 한눈에 비교

| 구분 | 전송 전 미리보기 | 전광판 화면 |
|------|-----------------|------------|
| **시점** | 보내기 **전** | 보낸 **후** (실시간) |
| **성격** | 연습(리허설) | 실제 표출 |
| **실제 전송** | 안 함 — 점검만 | 보낸 내용 그대로 비춤 |
| **위치** | `전송` 탭 안 미리보기 패널 | 모니터 (0,0) 무테두리 전체 창 |
| **용도** | 오타·색·잘림 사전 점검 | 보낸 내용의 실제 표출 확인 |

#### 전송 전 미리보기 — 보내기 전 점검

보내기 전에 표출 모습을 미리 보는 연습용 화면. 실제 전송 안 함.

1. `전송` 탭에서 보낼 메시지나 이미지 선택
2. 오른쪽 미리보기 창에 표출 모습이 실시간 표시 — 입장·유지·퇴장 효과까지 움직이는 그대로 재생
   〔전송 탭 + 미리보기 화면 캡처 1장〕
3. 오타·색·잘림 확인 후 `전송`

#### 전광판 화면 — 보낸 후 실제 표출

컨트롤러에 보낸 내용을, 연결된 PC 모니터에 전광판과 똑같이 거울처럼 띄우는 실제 표출 화면. 레거시의 별도 프로그램(`DIBD_Display.exe`)을 앱 안에 내장.

1. `전송` 탭 오른쪽 `전광판 화면`에서 `전광판 화면 열기` 클릭 (배율과 `항상 위` 선택 가능)
2. 전광판과 같은 비율의 검은 창 표시
   〔전광판 화면 창 캡처 1장〕
3. 이후 보내는 문구·이미지·효과가 실시간 표시. 창 아래 제어 바에서 화면채우기·배경이미지·켜기/끄기도 가능

> [!note] 헷갈리지 마세요
> **미리보기 = 보내기 _전_ 연습**(전송 안 함), **전광판 화면 = 보낸 _후_ 실제 표출**. 이름은 비슷해도 목적이 다름.
