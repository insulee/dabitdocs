---

> [!abstract] Easier IP address entry (improved in DabitOne)
> An input box that adds the dots (.) automatically when you type only the digits of an IP address

#### What is better

- In the legacy programs, you type the dots yourself
- In DabitOne,
  - the box accepts only digits and **adds a dot automatically** after every 3 digits
  - when you press `.`, the cursor moves to the next box
  - each box accepts only the range 0–255

#### Where is it used

- Client TCP/IP · UDP input in the `통신` (Communication) tab and the dbNet settings (IP · subnet · gateway · server IP) — 6 places in total
