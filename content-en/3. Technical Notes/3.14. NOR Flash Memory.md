>[!abstract] The difference between NOR flash memory and ROM
#### NOR flash memory vs. ROM

- NOR flash memory and ROM (Read-Only Memory) are both non-volatile memory types. They keep the data when the power goes off
- The two memory types differ in purpose, functions, and how data is changed and accessed

#### 1. NOR flash memory

- The structure and operation of NOR flash memory are similar to a "NOR gate" in digital logic
	- A NOR gate is a logic gate whose output is '0' if either input is '1', and '1' only when all inputs are '0'
	- **Read**: to read data from NOR flash, an address line selects a cell, and the controller checks whether the transistor of that cell is ON or OFF
	- **Write and erase**: 
		- To write or erase data, a high voltage on the transistor gate changes the charge state of the cell 
		- To store data, the transistor blocks the charge (logic '1') or lets it in (logic '0') to set the data to '0' 
		- In this process, the NOR structure can target and write or erase each cell separately. This relates to how a NOR gate outputs '1' only under a specific condition
- **Read/write**: 
	- NOR flash memory stores data, and you can erase or change it again and again as needed
	- This lets users update applications or systems
- **Execute in Place (XIP)**: NOR flash lets the CPU run code directly from the memory. Because of this, NOR flash is often used to store firmware
- **Speed**: NOR flash usually allows random access and reads fast, but it writes and erases more slowly than NAND flash
- **Uses**: firmware storage, boot code, real-time data processing in small devices

#### 2. ROM

- **Read-only**: 
	- ROM is mainly designed to be written once and read many times
	- The data is programmed during manufacturing, and normal users cannot change it
- **Types**: 
	- PROM (programmable ROM): programmed only once
	- EPROM (erasable programmable ROM): with special equipment, you can erase the data with electrical signals and program it again
- **Speed**: ROM usually reads very fast, but changing or updating the data is limited or not possible
- **Uses**: storing the basic input/output system (BIOS), supporting the first boot process of a device, storing fixed data, and so on

#### Conclusion

NOR flash memory and ROM both have important roles. NOR flash is used mainly when you need to change data and need flexibility. ROM is suitable when the data must not change and fast reads are needed
