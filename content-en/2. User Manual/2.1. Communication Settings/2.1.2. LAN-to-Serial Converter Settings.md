title: 2.1.2. LAN-to-Serial Converter Settings
---

> [!abstract] How to connect and set up the network of the LAN-to-Serial converter (DB300E) in dbNet
> How to set up the DB300E, a converter that adds Ethernet communication to a controller that has only a serial port


### Features
- Client TCP/IP, Server TCP/IP, and UDP connections are possible
- The steps below are for a Client TCP/IP connection. For the other connections, see [[2.1.4. Server TCP-IP and UDP Settings]]
- The converter and the controller connect by serial (TTL or RS232)

### Check the IPv4 address of the network adapter
- Windows search > Command Prompt > `ipconfig /all`
- Check the IPv4 address of the Ethernet adapter or the wireless LAN adapter..... : `***.***.***.***`

### Enter the network values of the converter
- 통신 (Communication) > dbNet > `Search` in the common button row at the bottom (`Search`/`Set`/`Add`/`Reset`)
- Select the MAC address of the converter that you want to connect — `Board Name` shows `DB300E`
- **Change the network information**: IP Address, Subnet Mask, Gateway, Port, and so on
	- IP Address: enter a value whose **fourth octet is different** from the IPv4 address of the connected network adapter
	- For example
		- IPv4 address of the network adapter: 169.254.121.210
		- IP Address of the converter: 169.254.121.*** (a value from 1 to 255, except 210)
		- Subnet Mask, Gateway: **the same values** as the network adapter
- `Set`

### Check the converter information (DB300 group)
- Select the MAC, then click `Read` in the `DB300` group to read the converter information
	- `Version`: firmware version (for example: Ethernet V2.0.4)
	- `Port`: the serial type that connects the converter to the controller — **default value `TTL`**
	- `Baud Rate`: communication speed (default 115200)

> [!tip] When it does not connect — check Port
> The default value of the converter `Port` is `TTL`. If you **wired the converter to the controller with RS232** and Port is `TTL`, communication does not work.
> 1. Select the MAC > `Read` in the `DB300` group
> 2. Check that `Port` matches the wiring type (RS232 wiring with `TTL` is a mismatch)
> 3. If they are different, change `Port` to `RS232` (or `TTL`) and click `Write`

### (Exception) Set the IP address of the network adapter manually for a 1:1 Ethernet connection
- Windows search > click `View network connections` to open the Network Connections folder
- Right-click the Ethernet icon > `Properties`
- `Internet Protocol Version 4 (TCP/IPv4)` > `Properties`
	- Use the following IP address
		- IP address: enter a value whose **fourth octet is different** from the IP Address of the converter
		- Subnet Mask, Gateway: **the same values** as the converter
