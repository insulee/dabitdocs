
> [!important] 꼭 확인하세요!
> 다빛솔루션의 전광판 컨트롤러와 LED 모듈 연결에 관한 가장 기초적인 가이드로, 최적의 학습효과 달성을 위해 실제 장비를 연결하고 가이드의 각 단계를 **DabitOne**으로 따라하기를 권장합니다.


### 1. 전원 및 연결 확인
- 컨트롤러와 LED 모듈에 전원 연결
- 컨트롤러와 LED 모듈 연결
- 컨트롤러와 PC/노트북/PLC를 연결 (TTL, RS232, RS485, Ethernet, WiFi, BLE 등)
- [[소프트웨어 다운로드]]에서 최신 버전의 DabitOne 다운로드

### 2. 통신 설정

#### TTL/RS232 연결

1. `통신` 탭
2. `Serial` 체크
3. 통신 포트 설정: `포트` (장치관리자 > 포트에서 연결된 포트 확인)
4. 통신 속도 설정: `속도` (기본 속도는 115200, 통신 속도 찾기에서 설정된 속도 확인)

#### 이더넷 연결

> [!note] dbNet 진입 경로
> - DabitOne: `통신` > `dbNet`
> - DBPS: `설정` > `통신설정` > `dbNet`

- 컨트롤러의 네트워크 정보 확인 및 컨트롤러 연결
	1. 통신 > dbNet
	2. Search
	3. 목록에서 연결하려는 컨트롤러의 MAC 주소 선택
	4. IP Address, Subnet Mask, Gateway, IP Port 등 **네트워크 정보 확인**
	5. Add
	6. Client TCP/IP 체크 여부와 IP Address, IP Port 확인
- 컨트롤러의 네트워크 정보 변경 후 컨트롤러 연결
	1. 통신 > dbNet
	2. Search
	3. 목록에서 연결하려는 컨트롤러의 MAC 주소 선택
	4. IP Address, Subnet Mask, Gateway, Port 등 **네트워크 정보 변경**
	5. Set
	6. Search
	7. 목록에서 연결하려는 컨트롤러의 MAC 주소 선택
	8. 네트워크 정보 변경 확인
	9. Add
	10. Client TCP/IP 체크 여부와 IP Address, IP Port 확인
#### 참고
- **통신 연결 상태는 연결 테스트 버튼을 눌러 확인**할 수 있으며,
	- DBPS에서는 `포트열기` > `연결확인`으로 확인
- 설정값은 입력 즉시 자동 저장됨. 별도 저장·닫기 불필요. 물리적 연결과 설정이 정상이라면 통신 항목 체크 및 Serial 포트, IP Address 등만 확인하면 통신 연결이 완료

> [!note] 이더넷 연결관련 추가 내용은 [[2.1.1. 이더넷 통신 설정]]를 참고

### 3. 전광판 크기 설정

- 설정 > 전광판 화면 구성
- 설정하려는 전체 LED 모듈의 `세로`, `가로`, `배열`, `BPP` 입력
- 전송
	- DBPS에서는 `설정` 버튼으로 적용

> [!note] 자세한 사항은 다음의 내용을 참고
> - LED 모듈: [[2.6.1. LED 모듈 가이드]], [[2.6.2. LED 모듈 배열방법]]
> - 전광판 크기 설정 방법: [[2.2.1. 전광판 크기 설정]]

### 4. 표출신호 설정

> [!important] 꼭 확인하세요!
> 표출신호 설정 전 모듈의 표출신호를 [[3.1. LED 모듈정보와 표출신호]]에서 확인
> 타 업체의 모듈은 컨트롤러 구입전에 컨트롤러와 호환이 가능한지 [[다빛솔루션 소개#연락처|다빛솔루션]]에 문의, 또는 모듈을 보내서 호환성 테스트를 요청


- 설정 > 표출신호 설정 
- 표출신호: `해당 모듈의 표출신호`
- Color Order: `RGB` (필요시 변경)
- Scan Order: `138 IC` (기본값)
- 전송
### 5. 표출 테스트
- 테스트 모듈: DABIT P3 2R6C 16S
- 전송 > HEX 프로토콜 > 문자색: `1234567`, 문구: `적녹노파분청흰Aa12!@`
	- DBPS에서는 `프로토콜 전송` > `헥사 프로토콜 체크`
- 표출화면
	![[guide2.png|350]]
- 모듈이 2단 6열보다 작은 경우 이동하기 효과를 이용해 확인
	- 입장효과: `이동하기`
	- 퇴장효과: `이동하기`
