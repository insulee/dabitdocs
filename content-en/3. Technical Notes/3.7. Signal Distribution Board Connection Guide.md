### 3-color

- LED modules: modules from Korean economy LED display sellers (Corun, Yangjae, Gapo, Seoul LED, Ledis — 코런, 양재, 가포, 서울엘이디, 레디스)

	- SEOUL JUNKWANG 70614 3COLOR_1/4DUTY DRIVER

	- BUF21-HUB75-OUT34P => BUF51-3C34-3C20-6Y => SEC410-SD-GP => module

- DB500 (up to 2 rows)

#### 1/8 Duty
- Display signal: `08D-P16D2S23-1^2`
- LED modules: modules from Korean economy LED display sellers (Corun, Yangjae, Gapo, Seoul LED, Ledis — 코런, 양재, 가포, 서울엘이디, 레디스)
	- Gapo (가포): GMS3CD8-91209

- (Discontinued) The former setup with DIBD-SEC840-8D-GP — SEC840 is discontinued, and the BUF27 above replaces it
	- DB600: BUF21-HUB75-OUT34P => BUF51-3C34-3C20-6Y => DIBD-SEC840-8D-GP => module

	- DB500: BUF20-HUB75-3C20P => DIBD-SEC840-8D-GP => module

#### 3-color modules on DB520 · DB720
- On DB520 · DB720, 1/4 duty · 1/8 duty 3-color display signals show correctly even when you send them with the DabitOne HEX method or the old ASCII. Other models such as DB500 · DB600 work the same after you upgrade them to the official V4.5.4 (with earlier versions, the text broke or did not show)
- When you upgrade another model to V4.5.4, a board that saved this signal with HEX · old ASCII changes to the lamp method with no command. If a site used that signal for a panel other than this module, the display can change, so send the display signal of the actual module again
- **DB520 · DB720 + BUF20 adapter + Gapo 1/4 duty lamp module does not show** — a hardware limit (the 3.3V direct output cannot drive the module through an adapter with no buffer. The same setup works on DB502). A dedicated buffer board is being made — contact us if you need it
