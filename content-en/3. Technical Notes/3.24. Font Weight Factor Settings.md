---
title: 3.24. Font Weight Factor Settings
---

> [!abstract] Font weight factor settings
> - This document describes the function that adjusts the horizontal and vertical weight of fonts. When you enlarge a 16x16 font, the strokes become thin. Adjust the weight to make the text easier to read

### Path to the font weight factor settings

#### DabitOne
- `고급` (Advanced) > `폰트 두께 배율` (Font weight ratio) (the button and the window are both named `폰트 두께 배율`)

#### DBPS
- `Setting` > `Additional Function`

### Main functions
1. Font weight adjustment
	- Adjusts the horizontal and vertical weight of the font separately, based on the weight factor
	- The weight factor goes from the default `1.0x` (default weight) up to `3.0x`
2. Setting with communication packets
	- Set the weight factor with a send packet, and check the result in the response packet
3. Setting range
	- You can set the horizontal and vertical weight factors each from `10` to `30`

### Font weight factor rules
1. Initial setting value: `10`
2. Weight adjustment rules
    - Weight factor ≤ 10: weight adjustment is off (the font uses its default weight)
    - Weight factor 10 ~ 30: weight adjustment is on
        - `thickness_factor = 10`: weight ratio `1.0` (default)
        - `thickness_factor = 15`: weight ratio `1.5`
        - `thickness_factor = 20`: weight ratio `2.0`

### Packet communication protocol
#### 1. Send packet structure
- Format: `![0056 XX YY!]`
    - XX: horizontal weight factor (10 ~ 30)
    - YY: vertical weight factor (10 ~ 30)
- Firmware V3.6.0 or later gets the new `![00J4XXYY!]` packet first (XX·YY together, no space). Only old firmware falls back to `![0056 XX YY!]`
- Examples:
    - `![0056 00 00!]`: turns off the weight factor adjustment — V4.4.0 or earlier. **The official V4.5.4 or later returns an error for values outside 10~30** (default weight = `10 10`)
        - But the combo box in the DabitOne app selects only `1.0`~`3.0`, so you cannot send `00 00` (off) from the app. You can send it only as a direct packet
    - `![0056 12 20!]`: applies 1.2 times the horizontal weight and 2.0 times the vertical weight

#### 2. Response packet structure
- Format:
    - `![00560!]`: setting succeeded
    - `![0056F!]`: setting failed

### Usage examples
1. Turning on the weight adjustment
    - Send: `![0056 15 20!]`
        - Horizontal weight: 1.5 times
        - Vertical weight: 2.0 times
    - Response: `![00560!]` (setting succeeded)
2. Turning off the weight adjustment
    - Send: `![0056 00 00!]`
    - Response: `![00560!]` (setting succeeded)
