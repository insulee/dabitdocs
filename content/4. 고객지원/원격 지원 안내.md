
#### 원격 지원이란?

원격 지원은 RustDesk 프로그램을 통해 고객님의 화면을 공유받아 실시간으로 문제를 진단하고 해결하는 서비스입니다. 현장 방문 없이도 신속하게 기술 지원을 받으실 수 있습니다.

#### RustDesk 다운로드 및 설치

1. **RustDesk 다운로드**
   - [RustDesk 공식 다운로드 페이지](https://rustdesk.com/ko/)로 이동
   - 사용 중인 운영체제(Windows, macOS, Linux)에 맞는 버전 다운로드
   - Windows의 경우: "Windows용 다운로드" 버튼 클릭

2. **설치 및 실행**
   - 다운로드한 설치 파일 실행
   - 설치 완료 후 RustDesk 프로그램 실행
   - 별도의 회원가입이나 로그인 없이 바로 사용 가능

#### 원격 지원 연결 방법

RustDesk를 실행하시면 화면 왼쪽에 **고유 ID**와 **임시 비밀번호**가 표시됩니다. 원격 지원을 받으시려면 다음 정보를 담당자에게 알려주세요.

1. **고유 ID** (9자리 숫자)
   - 예: 123 456 789
2. **임시 비밀번호** (6자리)
   - 예: abc123
   - 비밀번호는 매번 프로그램 실행 시 자동으로 생성됩니다

#### 원격 지원 요청 절차

1. **사전 준비**
   - RustDesk 프로그램 다운로드 및 실행
   - 고유 ID와 임시 비밀번호 확인
   - 문제가 발생한 상황 재현 가능한 상태 유지

2. **지원 요청**
   - 다빛솔루션 기술팀에 전화 또는 이메일로 원격 지원 요청
   - 담당자에게 고유 ID와 임시 비밀번호 전달
   - 연결 요청이 오면 **"수락"** 버튼 클릭

3. **원격 지원 진행**
   - 담당자가 화면을 공유받아 문제 진단 및 해결
   - 필요 시 담당자가 직접 마우스/키보드 제어 (고객님의 허용 필요)
   - 실시간으로 문제 해결 과정 확인 가능

#### 보안 안내

고객님의 정보 보호를 위해 다음 사항을 안내드립니다.

- 연결은 고객님의 **"수락"** 없이는 절대 이루어지지 않습니다
- 세션이 종료되면 연결이 자동으로 끊어집니다
- 임시 비밀번호는 프로그램을 종료하면 무효화됩니다
- 원격 지원 중 언제든지 연결을 끊으실 수 있습니다
