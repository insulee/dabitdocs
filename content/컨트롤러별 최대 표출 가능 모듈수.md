
# 다빛솔루션 컨트롤러별 최대 표출 가능 모듈수 (AI 챗봇 학습용)

## 중요: 배열 방식 이해하기

### 가로형 배열 (Horizontal Layout)
- 전광판을 일반적으로 가로로 놓았을 때의 배열
- **행(row) × 열(column)** 로 표기
- 예: 2행 × 20열 = 2단으로 쌓고, 각 단마다 20개 모듈
- 가로형에서 "단"은 세로로 쌓은 개수를 의미

### 1줄세로형/2줄세로형 배열 (Vertical Layout)
- 전광판을 세로로 세웠을 때의 배열
- **단(tier) × 열(column)** 로 표기
- 예: 20단 × 2열 = 세로로 20개 쌓고, 옆으로 2줄
- 세로형에서 "단"은 세로로 쌓은 높이를 의미
- **중요**: 최대 단 수 이내에서 자유롭게 설정 가능 (예: 20단 × 2열이 최대라면 6단 × 2열, 10단 × 2열 등 모두 가능)

# 파트 1: 가로형 배열 (Horizontal Layout)

## 컨트롤러 선택 가이드

### Ethernet 통신이 필요한 경우
- **지원 모델**: DB500S, DB600S, DB500T, DB600T, DB600U
- **미지원 모델**: DB502S, DB600V
- **참고**: Ethernet이 없는 제품은 DB300E(LAN to Serial 컨버터)를 사용하여 TCP/IP 통신 가능

### 무선 인증이 필요한 경우
- **지원 모델**: DB502S, DB600S, DB600T, DB600U, DB600V
- **미지원 모델**: DB500S, DB500T

### 대형 전광판 구성 시
- **많은 단 수 필요**: DB600U (최대 8단)
- **많은 모듈 수 필요**: DB600V (최대 112개)
- **일반적인 중대형**: DB600T (최대 4단 80개)

### 소형 전광판 구성 시
- **Ethernet 필요**: DB500S 또는 DB600S
- **무선 인증 필요**: DB502S 또는 DB600S
- **둘 다 필요**: DB600S
- **둘 다 불필요**: DB500S 또는 DB502S

### 중형 전광판 구성 시 (3~4단)
- **Ethernet만 필요**: DB500T
- **둘 다 필요**: DB600T

## 중요 참고사항

1. **모듈 배열 자유도**: 컨트롤러별 최대 표출 가능 모듈 수 이내에서 단과 열을 자유롭게 설정 가능합니다.
   - 예: DB600T는 2단 40열 외에도 2단 30열, 2단 25열 등 다양한 구성 가능

2. **모듈 배열 방법**:
   - **가로형**: 일반적인 가로 방향 배열 (행 × 열)
   - **1줄세로형**: 세로 방향 1줄 배열 (단 × 열)
   - **2줄세로형**: 세로 방향 2줄 배열 (단 × 열)
   - **가로형양면**: 양면 가로 배열
   - **1줄세로형양면**: 양면 세로 1줄 배열
   - 배열 방법에 따라 최대 표출 가능 모듈 수가 다릅니다

3. **가로형 vs 세로형**:
   - 가로형: 행(row) × 열(column) 표기 (예: 2행 × 20열)
   - 세로형: 단(tier) × 열(column) 표기 (예: 20단 × 2열)
   - 세로형은 전광판을 세로로 세웠을 때의 배열입니다

3. **Ethernet 대안**: Ethernet이 없는 모델(DB502S, DB600V)은 DB300E(LAN to Serial 컨버터)를 사용하여 TCP/IP 네트워크 통신 가능

4. **시리얼 통신**: 모든 컨트롤러는 기본적으로 RS232, TTL 시리얼 통신을 지원하며, RS485는 옵션으로 추가 가능

5. **프로토콜**: 모든 컨트롤러는 다빛 프로토콜(ASCII, HEX) 지원

## 모델별 주요 용도

- **DB500S**: 소형 전광판, Ethernet 통신 필요, 인증 불필요
- **DB502S**: 소형 전광판, 무선 인증 필요, Ethernet 불필요
- **DB600S**: 소형 전광판, Ethernet + 무선 인증 모두 필요
- **DB500T**: 중형 전광판(3~4단), Ethernet 필요, 인증 불필요
- **DB600T**: 중형 전광판(3~4단), Ethernet + 무선 인증 필요
- **DB600U**: 대형 전광판(6~8단), Ethernet + 무선 인증 필요
- **DB600V**: 초대형 전광판(최대 모듈 수), 무선 인증 필요, Ethernet은 컨버터 사용
