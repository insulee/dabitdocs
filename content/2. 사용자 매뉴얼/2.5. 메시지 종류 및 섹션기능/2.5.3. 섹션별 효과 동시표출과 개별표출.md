
> [!abstract] 효과 동시표출 vs 효과 개별표출
> 2개 이상의 섹션에서 서로 다른 속도의 효과를 사용할 때, 섹션 간 효과 사이클을 **동기화할지 독립시킬지** 결정하는 설정. 가장 느린 섹션에 맞춰 전 섹션이 같이 움직이게 할지(동시표출), 각 섹션이 자기 속도대로 따로 움직이게 할지(개별표출) 선택.

#### 1. 설정 개요

- **효과 동시표출 (E0)**
	- 모든 섹션의 효과 사이클을 동기화
	- 가장 느린 섹션의 효과가 끝날 때까지 빠른 섹션은 대기
	- 마지막 섹션이 완료되는 순간 → **전 섹션이 동시에** 다음 사이클 시작
- **효과 개별표출 (E1)**
	- 각 섹션이 자기 속도대로 **독립된** 사이클을 진행
	- 빠른 섹션은 효과가 끝나자마자 즉시 다음 사이클로 진입
	- 다른 섹션의 진행 상태와 무관하게 반복

#### 2. 설정 위치

- 메뉴 경로
	- DabitOne: `전송` 탭 오른쪽 `섹션별 효과` 그룹 > 콤보에서 `효과 동시 표출` 또는 `효과 개별 표출` 선택 > `전송`
	- 레거시(DBPS): **실시간 문구 설정 > 효과 동시표출** 또는 **효과 개별표출**
- ASCII 프로토콜 명령
	- `![0062N!]` : 효과 **동시표출** (E0)
	- `![0062Y!]` : 효과 **개별표출** (E1)
	- 응답: `![00620!]` (정상 처리)
	- 표출 방식을 먼저 전송해 두고, 이어서 섹션 패킷을 전송합니다
- 펌웨어 정보 표시값
	- `E0` : 효과 동시표출
	- `E1` : 효과 개별표출
	- 펌웨어 정보 확인 방법은 [[20_Marketing_Team/22_Area/dabitdocs/3. 전문자료/3.21. 컨트롤러 펌웨어 정보 해석]] 참고

#### 3. 동작 예시

> [!example] 조건
> - 화면: 2단 6열
> - 섹션1 (1단): 입·퇴장 효과 = 왼쪽 이동, 속도 = `10` (빠름)
> - 섹션2 (2단): 입·퇴장 효과 = 왼쪽 이동, 속도 = `30` (느림)

##### 효과 동시표출 (E0)

| 시간 구간 | 섹션1 (속도 10) | 섹션2 (속도 30) |
|---|---|---|
| 사이클 시작 ~ 섹션1 완료 | 왼쪽 이동 진행 | 왼쪽 이동 진행 |
| 섹션1 완료 ~ 섹션2 완료 | **대기 (정지)** | 왼쪽 이동 계속 진행 |
| 섹션2 완료 시점 | **동시 시작** → 다음 사이클 왼쪽 이동 | **동시 시작** → 다음 사이클 왼쪽 이동 |

- 섹션1이 먼저 완료되어도 섹션2가 끝날 때까지 **대기**
- 가장 늦은 섹션이 완료되는 순간 → 모든 섹션이 **함께** 다음 사이클 시작
- 여러 섹션을 **하나의 연출 단위**처럼 통일감 있게 보여줌

##### 효과 개별표출 (E1)

| 시간 구간 | 섹션1 (속도 10) | 섹션2 (속도 30) |
|---|---|---|
| 사이클 시작 ~ 섹션1 완료 | 왼쪽 이동 진행 | 왼쪽 이동 진행 |
| 섹션1 완료 직후 | **즉시** 다음 사이클 왼쪽 이동 시작 | 왼쪽 이동 계속 진행 (1사이클 중) |
| 섹션2 완료 시점 | 자기 사이클 진행 중 | 다음 사이클 왼쪽 이동 시작 |

- 섹션1은 대기 없이 **자기 속도대로** 계속 반복
- 섹션2 역시 섹션1과 무관하게 자기 속도대로 진행
- 각 섹션이 **독립된 정보판**처럼 각자의 리듬으로 동작

#### 4. ASCII 실측 예시

펌웨어 검증에서 실제 보드(96×32)로 확인한 패킷 그대로입니다.

```
![0062Y!]
![000/P0000/Y0004/F0003/S1000/E0606/D1001/C6가나다라!]
![000/P0001/Y0408/F0003/S3000/E0606/D1001/C11234!]
```

- 1행: 효과 개별표출 설정 (동시표출로 바꾸려면 `![0062N!]`)
- 2행: 섹션0 = 1단(`/Y0004`), 하늘색 `가나다라`, 오른쪽→왼쪽 이동(`E0606`), 속도 10(빠름)
- 3행: 섹션1 = 2단(`/Y0408`), 빨간색 `1234`, 같은 효과, 속도 30(느림)
- 실측 결과
	- **동시표출(N)**: 빠른 1단이 사이클을 마치면 **빈 화면으로 대기**, 느린 2단이 끝나는 순간 두 단이 **함께** 재시작
	- **개별표출(Y)**: 1단은 기다리지 않고 자기 속도로 계속 반복 — 두 단의 출발 시점이 점점 어긋남

#### 5. 실전 예시 — 갱신되는 값과 흐르는 안내문구

1단에 수시로 바뀌는 값(차량번호, 온도 등), 2단에 흐르는 안내문구를 함께 쓰는 구성입니다.

```
![000/P0000/D9901/X0000/Y0004/E0101/S1000/T0/C1123가 4567!]
![000/P0001/D9901/X0000/Y0408/E0606/S2000/T0/C2지금즉시이동해주세요!]
```

이대로면 1단 값을 갱신(재전송)할 때마다 2단 문구가 처음부터 다시 흐릅니다.
**값을 갱신해도 2단이 계속 흐르게 하려면** 두 가지를 바꿉니다.

1. 효과 개별표출을 먼저 전송: `![0062Y!]`
2. 1단 패킷의 `/D9901`(즉시 표시)을 `/D9900`(일반 표시)으로 변경

```
![0062Y!]
![000/P0000/D9900/X0000/Y0004/E0101/S1000/T0/C1456나 7890!]
```

- `/Dxxyy`의 `yy=01`(즉시 표시)로 재전송하면 표출 중인 다른 섹션 효과까지 재시작됩니다
- `yy=00`(일반 표시) + 개별표출 조합이면 1단 값만 바뀌고 2단 문구는 이어서 흐릅니다
- `/D` 속성 정의는 [[2.8.1. ASCII 프로토콜 매뉴얼#2.2.2. /Dxxyy|2.8.1 /Dxxyy]] 참고

#### 6. 선택 기준

| 상황 | 권장 설정 |
|------|----------|
| 여러 섹션을 하나의 통일된 연출로 묶고 싶을 때 | 효과 동시표출 (E0) |
| 각 섹션을 독립된 정보 영역처럼 운영할 때 | 효과 개별표출 (E1) |
| 속도 차가 큰 효과를 같이 쓸 때 (빠른 섹션이 자주 반복되길 원함) | 효과 개별표출 (E1) |
| 실시간 문구 출력 시 미세한 떨림이 발생할 때 | 효과 개별표출 (E1) |

> [!tip] 문구 떨림 해결 사례
> 실시간 문구 출력 시 미세한 떨림·깜빡임 현상이 발생하는 경우, 효과 개별표출로 설정을 변경하면 섹션 간 사이클 동기화 과정에서 발생하는 간섭이 제거되어 증상이 완화되는 경우가 있음.
