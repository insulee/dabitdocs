
> [!abstract] 다빛솔루션 표출신호 문자열 패턴 프로토콜의 부분별 의미와 설정방법 안내


### 기본 사항
#### 모듈 및 컨트롤러 버전 확인
- 모듈의 Drive IC가 다빛솔루션 컨트롤러에서 지원이 가능한지 여부 확인
- 컨트롤러 V3.8.3 이상: `H2` 명령으로 설정 (이 문서 기준)
- 컨트롤러 V3.8.3 미만: 구버전 명령 `0044` 사용 — [[#구버전 펌웨어(V3.8.3 미만) 참고]]
#### 설정 패킷 기본 구조
- 쓰기: `![00H2S헤더_패턴!]`
	- `H2` 바로 뒤에 **공백 없이** 패턴 문자열(`S`로 시작)을 붙임
	- 공백을 넣으면 오류(`F5`)로 거부됨
	- 헤더 형식: `SnnDnTnCnInWnnPn`
	- 패턴 형식: [[#패턴 예시]] 참고
- 읽기: `![00H2!]` — 현재 설정된 패턴 확인
- 응답: `![00H2 S헤더_패턴!]` — 적용된 값을 그대로 돌려줌 (`H2` 뒤 공백 1칸)
#### 문자열 크기 제한
- 패턴 문자열 전체(헤더+패턴): 최대 **49바이트**
- 그룹(언더스코어 구분): 최대 2개
- 그룹당 세그먼트: 최대 6개
- 세그먼트당 행 문자: 최대 2개
- 제한을 넘으면 컨트롤러가 경고 없이 뒷부분을 잘라내므로 의도대로 동작하지 않음
#### 설정 방법
- 아래의 설정 순서를 참고하여 직접 표출신호 설정 패킷을 작성
- 또는, DabitOne의 표출신호 입력 창에서 패턴 문자열만 입력 — [[#DabitOne에서 입력]]
- 또는, [[소프트웨어 다운로드]]의 표출신호 설정 프로그램을 다운로드하여 패킷 작성

> [!note] 다빛채를 쓰신다면
> 내장 목록에서 표출신호를 골라 보내는 것은 다빛채에서도 됩니다 — `환경설정` > `표출신호 설정` ([[2.3.1. 표출신호 설정]] 참고). 대부분의 다빛솔루션 모듈은 이 목록으로 해결됩니다.
>
> 다만 이 문서처럼 **패턴 문자열을 직접 만들어 넣는 기능은 다빛채에 없습니다.** 목록에 없는 모듈을 쓰셔야 한다면 DabitOne을 쓰시거나, [[소프트웨어 다운로드]]에서 표출신호 설정 프로그램을 따로 받아 패킷을 만드시면 됩니다.

### 설정 순서

#### 1. 기본 표출신호 전송
```
![00H2S16D1T1C0I0W16P0_a16!]
```


#### 2. 전광판 크기 전송
- 2단 이상의 모듈이라도 1단 4열로 전송하여, 패턴스캔(![0046!]) 전송 이후 패턴을 보고 열 조정
	- 1단 2열: `![004001020!]`
	- 1단 4열: `![004001040!]` (Default)
	- 1단 6열: `![004001060!]`
	- 1단 8열: `![004001080!]`
	- 1단 12열: `![004001120!]`

#### 3. 패턴 스캔 전송 
```
![0046!]
```
- 정상적인 패턴은 한번에 한 픽셀만 표출
- 패턴 이상하게 나올 때 - [[#패턴 예외]]
	- 두개가 나란히 출력
		1. 디코더 IC(`Tn`) 변경
		2. 기본 표출신호 전송
	- 패턴이 일정 시간 지난 후 출력
		1. 전광판크기 열 줄여서 전송
		2. 패턴 스캔 전송
	- 어긋나게 동시에 패턴 출력
		1. 전광판크기 열 늘려서 전송
		2. 패턴 스캔 전송

#### 4. 패턴 입력
- 패턴문자 + 반복
- 패턴 문자
	- 소문자, 숫자, 언더스코어(`_`)만 이용 (반복 표시 `X`만 대문자)
	- 행(소문자) - a=1행, b=2행, ... , q=17행 — 행 문자는 소문자 `a`~`q`만 사용
	- 열(숫자) - 1=1열, 2=2열, ...
	- 언더스코어(`_`)
		- 역방향표시
		- 그룹구분자
- 반복
	- 대문자 X 뒤에 숫자를 적어 반복 표시
	- 16x16픽셀 이내 반복을 표시
- [[#패턴 예시]]

#### 5. 헤더 입력

`SnnDnTnCnInWnnPn`

- `Snn`: 스캔 종류(1, 2, 4, 8, 16, 32), 기본값: S16
- `Dn`: 데이터라인(1, 2), 기본값: D1
- `Tn`: 디코더 IC 종류(0~4), 기본값: T1
- `Cn`: Color Order(0~7), 기본값: C0
- `In`: Drive IC 종류, 기본값: I0
- `Wnn`: 스캔 한번에 동시 제어하는 픽셀 수
	- 패턴값 숫자의 합 x 반복값
	- 예
		- i64a64 = W128
		- a_8e8X2 = W32
- `Pn`: 모듈 식별자, 생략가능
	- P0: 표준 HUB75(생략시 기본값)
	- P1~P9: 비표준, 필요시 지정

#### 6. 패킷 전송
`![00H2S헤더_패턴!]` — `H2`와 패턴 문자열 사이 공백 없음

#### DabitOne에서 입력
- `설정` > `표출신호 설정` > `표출신호 입력` 버튼으로 입력 창을 엶
- 패턴 문자열(예: `S16D1T1C0I0W16P0_a16`)을 입력하고 `전송` 또는 `등록 후 전송`
- 등록한 코드는 목록에 남아 재사용 가능 (프로그램을 다시 켜도 유지)
- 규칙 위반(49바이트 초과, 대문자 행 문자 등)이 있으면 경고를 표시 — 경고 후에도 전송은 가능하지만 컨트롤러가 잘라내거나 무시할 수 있음
- 패킷(`![00H2...!]`) 조립은 프로그램이 하므로 패턴 문자열만 입력하면 됨 — [[2.3.1. 표출신호 설정]] 참고
- 목록이 길어 찾기 어려우면 `표출신호 필터` 버튼으로 듀티·데이터 라인·구동 방식·드라이버 IC 등 아는 조건만 골라 좁힐 수 있음 (V4.6.0 이상) — [[7.7. 표출신호 필터]] 참고


#### 헤더 파라미터별 상세 설명

| 파라미터    | 의미                | 값 범위                   | 예시  | 설명                                      |     |
| ------- | ----------------- | ---------------------- | --- | --------------------------------------- | --- |
| **Snn** | 스캔 비율 (1/nn 스캔)   | 01, 02, 04, 08, 16, 32 | S16 | 1/16 스캔 방식                              |     |
| **Dn**  | 데이터 라인 수          | 1, 2                   | D1  | D1단일 데이터 라인<br>D2는 이중 데이터 라인            |     |
| **Tn**  | 디코더 IC 타입         | 0–4                    | T1  | 디코더 IC 타입 선택(아래 T 파라미터 표 참조)            |     |
| **Cn**  | RGB 색상 순서         | 0–7                    | C0  | 색상 순서 선택(아래 C 파라미터 표 참조). C0은 미설정 = RGB   |     |
| **In**  | 드라이버 IC 타입        | 0–9                    | I0  | 드라이버 IC 종류 선택(아래 I 파라미터 표 참조)          |     |
| **Wnn** | 단일 데이터 라인 제어 픽셀 수 | 16–128                 | W32 | 1스캔에 제어하는 픽셀 수                          |     |
| **Pn**  | 비표준 모듈 식별자        | 0–9 (선택)               | P0  | P0: 표준 HUB75P1~P9: 스캔 방식/커넥터가 완전히 다른 모듈 |     |

#### T 파라미터 상세 (디코더 IC 종류)

| 값   | IC 타입               | 적용 사례                   |
| --- | ------------------- | ----------------------- |
| T0  | 디코더 IC 없음           | 1/4 duty와 1/2 duty      |
| T1  | 74HC138 정방향         | 일반적인 디코더 IC             |
| T2  | 74HC138 역방향         | Vissem 3Color 1/16 duty |
| T3  | 74HC595 (SUM2017TD) | 1/8 duty 적용             |
| T4  | L800                | 1/4 duty 적용             |

#### C 파라미터 상세 (Color Order)

C 값은 프로그램 `Color Order` 콤보의 순서와 같습니다(RGB=C1 … BGR=C6). **C0은 미설정**으로 C1(RGB)과 같게 동작합니다.

| 값   | Color Order | 화면에 나오는 색 순서 (R·G·B 신호를 보냈을 때) |
| --- | ----------- | ------------------------------ |
| C0  | 미설정 (= RGB) | 빨강 · 초록 · 파랑                 |
| C1  | RGB         | 빨강 · 초록 · 파랑                 |
| C2  | RBG         | 빨강 · 파랑 · 초록                 |
| C3  | GRB         | 초록 · 빨강 · 파랑                 |
| C4  | GBR         | 파랑 · 빨강 · 초록                 |
| C5  | BRG         | 초록 · 파랑 · 빨강                 |
| C6  | BGR         | 파랑 · 초록 · 빨강                 |
| C7  | 예약         | –                              |

> [!tip] 모듈 색이 바뀌어 나올 때
> 예를 들어 빨강 글자가 파랑으로 나오면 색상 순서가 맞지 않는 것입니다. `Color Order`를 바꿔 가며 전송해 빨강·초록·파랑이 제자리에 나오는 값을 찾으세요. 표출신호 문자열을 직접 쓸 때는 위 표의 C 값을 헤더에 넣습니다.

#### I 파라미터 상세 (드라이버 IC 종류)

드라이버 IC는 **구동 방식**에 따라 세 갈래로 나뉩니다. 방식이 다르면 밝기·전송 동작이 달라지므로 모듈에 실린 IC를 확인해 고르세요.

| 값   | 구동 방식 | 드라이버 IC        | 비고                                   |
| --- | ------ | -------------- | ------------------------------------ |
| I0  | BCM    | 표준 (범용)        | 대부분의 HUB75 모듈. ICN2037BP·FM6124DJ·MBI5120GM·SM16208 등 |
| I1  | BCM    | FM6126A        |                                      |
| I2  | BCM    | FM6124         |                                      |
| I3  | BCM    | ICN2038S       |                                      |
| I4  | BCM    | MBI5153        |                                      |
| I5  | BCM    | MBI5042        |                                      |
| I6  | BCM    | ICN2053        |                                      |
| I7  | S-PWM  | SM16380SA      | 펌웨어 V4.1.5 이상. 전송 후 전광판이 스스로 재시작함(정상) |
| I8  | S-PWM  | IT1504         | 전송 후 전광판이 스스로 재시작함(정상)             |
| I9  | EPWM   | FM6363C        | BCM·S-PWM과 다른 제3의 방식. 전송 후 전광판이 스스로 재시작함(정상) |

> [!note] 전송 뒤 화면이 잠깐 꺼지는 경우
> I7·I8·I9 모듈은 표출신호를 받으면 전광판이 스스로 다시 켜집니다. 몇 초간 화면이 비는 것은 정상이며 곧 표출됩니다.

## 패턴 예시
#### 기본 사항
- 정상적인 패턴은 한 번에 한 픽셀만 표출
- 패턴은 행 기준으로 열 이동
#### 정방향이동
- 행 `a`에서 **왼쪽→오른쪽(1→16)** 순으로 16픽셀을 한 번에 점등하는 기본 패턴
- 정방향은 **언더스코어(`_`) 없이** `(행문자)(열수)` 형태로 작성
- a16
- ![[패턴_정방향.png|500]]

#### 역방향이동
- 행 `a`에서 **오른쪽→왼쪽(16→1)** 순으로 16픽셀을 점등
- 역방향은 **행 문자 뒤에 언더스코어**를 붙여 `(행문자)_(열수)` 형태로 표기
- a_16
- ![[패턴_역방향.png|500]]
#### 쌍으로 이동
- **두 개 이상의 행 문자를 조합**하여, 해당 행들이 **교대로 동작**
- 구문: `(행문자)(행문자)(열수)`
	- 역방향 이동시 `_`를 행문자뒤에 붙여서 표기
- ac16
- ![[패턴_쌍이동.png|500]]
- ia_16
- ![[패턴_쌍이동역방향.png|500]]
#### 반복(최소단위 16x16)
- `Xn` 표기로 같은 형태를 **n회 반복**
- 최소 단위인 **16×16 픽셀** 기준으로 표기
- a_8e8X2
	- `a`행 역방향 8픽셀 + `e`행 정방향 8픽셀을 **2번 반복**
	- ![[패턴_반복x2.png|500]]
- ac_4eg4X4
	- `a,c`행 4픽셀 + `e,g`행 4픽셀을 **4번 반복**
	- ![[패턴_반복x4.png|500]]
#### 16x16픽셀 기준으로 패턴 작성
- 1단2열(16x32픽셀) 모듈에서 16x16 픽셀 기준으로 패턴이 2번 반복된다면 16x16픽셀 패턴만 표기
- i16a16![[패턴_16x16_1.png]]
- i32a32![[패턴_16x16_2.png]]

#### 패턴 예외
- 두 개가 동시에 나란히 출력 - T0(No decoder IC)로 선택
- ![[패턴_예외1.png|500]]
- 어긋나게 동시에 패턴 출력 -> 전광판크기 열 늘려서 전송 > 패턴 스캔 전송
- ![[패턴_예외2.png|500]]
