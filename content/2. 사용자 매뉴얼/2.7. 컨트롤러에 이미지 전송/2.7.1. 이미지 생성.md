
> [!abstract] 이미지 생성
> - DabitOne: 그림판 없이 프로그램 안에서 이미지 제작 — `이미지 편집`(픽셀 드로잉), 외부 이미지 불러오기, `GIF 편집`
> - 다빛채(레거시): 그림판으로 2단6열 크기의 bmp 이미지 생성하는 방법 안내

### DabitOne

DabitOne은 이미지 제작 도구 내장 — 그림판 등 외부 프로그램 불필요

#### 전광판 크기 설정 (공통 준비)
- 이미지를 만들기 전에 `설정` > `전광판 화면 구성`에서 전광판 크기를 먼저 설정
- 상세: [[2.2.1. 전광판 크기 설정]]

#### 이미지 편집 창에서 픽셀로 그리기
1. `편집` 탭 > `이미지 편집`
2. `도구:` 행에서 `이동`/`펜`/`스포이드` 토글 중 선택 (기본 `펜`)
	- `펜`: `색상`에서 색을 고르고 캔버스를 클릭·드래그하여 픽셀 단위로 그리기
	- `스포이드`: 캔버스의 색을 집어 현재 색으로 지정 — 1회 사용 후 자동으로 `펜` 복귀
	- 선택한 색은 `현재색:` 스와치에 표시
	- 캔버스 크기 = 설정한 전광판 크기
	- `확대` 값으로 작업 배율 조절, `전체지우기`로 초기화
	- 검정 펜으로 칠하면 이미지 위를 지우개처럼 지울 수 있음
3. `+ 이미지 추가` 또는 `열기`로 외부 이미지(.bmp/.png/.jpg)를 불러오기 (그린 픽셀과 합성)
	- 불러온 이미지의 드래그 이동은 `이동` 도구 선택 후 가능 — 기본 `펜` 상태에서 드래그하면 그려짐
	- `이미지 고정`: 불러온 이미지를 픽셀로 굳힘 / `- 이미지 삭제`: 불러온 이미지 제거
4. `실행취소`/`다시실행`(Ctrl+Z/Ctrl+Y)으로 최대 50단계까지 되돌리기 가능
5. `저장` 또는 `다른이름저장` > 이미지 파일(.bmp/.png/.jpg)로 저장

저장한 이미지는 [[2.7.2. 이미지 또는 문자를 dat 또는 ani 파일로 변환]]의 DabitOne 절차로 전광판 콘텐츠(.dat)로 변환

#### 외부 이미지 준비
- 그림판·포토샵 등 어떤 도구로 만들었든 .bmp/.png/.jpg 파일이면 바로 사용 가능 (다빛채와 달리 .png도 지원)
- 이미지는 전광판 크기(가로 = 열수 × 16픽셀, 세로 = 단수 × 16픽셀)에 맞춰 만드는 것 권장
	- 크기가 다르면 불러오는 경로에 따라 잘리거나 강제로 늘어남

#### 움직이는 이미지(GIF) 만들기
1. `편집` 탭 > `GIF 편집`
2. 프레임 단위로 그리기 — `+ 프레임`/`복제`/`- 삭제`로 프레임 관리, `delay`(ms)로 프레임 시간 조절, `▶ 재생`으로 미리 확인
3. `저장` > .gif 파일로 저장 (기본 폴더 `Data\Video`)
	- 〔캡처 1장〕
- 상세: [[7.3. 내장 GIF 편집기]]
- 저장한 GIF는 [[2.7.2. 이미지 또는 문자를 dat 또는 ani 파일로 변환]]에서 .ani로 만들어 사용

### 다빛채

#### 전광판 크기 설정
- `환경설정` > `화면설정` 
	- 세로: `2`
	- 가로 `6`
	- 픽셀당 비트수: `3BPP(8color)`
	- `전송`
- 모듈의 종류가 3컬러, 풀컬러에 상관없이 **픽셀당 비트수는 3BPP(8Color)**로 설정하는 것을 권장
#### 그림판으로 배경 이미지 생성
1. 그림판 프로그램 열기
	- `표시파일작성` > `그래픽 이미지`
2. 그림판에서 이미지 그리기
	- 화면크기를 최대로 확대
	- 도구 > `연필`
	- 픽셀 > `1px`
	- 색 > 색상을 지정하여 마우스를 클릭하여 이미지를 픽셀로 생성
3. `파일` > `다른이름으로 저장` > `BMP 그림` > Image 폴더 선택 > `저장`

#### 이미지 파일을 .dat 파일로 변환
- 저장한 .bmp /.jpg 파일을 다빛채에 적용시키기 위해서는 [[2.7.2. 이미지 또는 문자를 dat 또는 ani 파일로 변환]]을 통해 .dat 파일로 변환
- (참고) .gif (애니메이션 이미지)를 다빛채에 적용시키기 위해서는 [[2.7.2. 이미지 또는 문자를 dat 또는 ani 파일로 변환]]을 통해 .ani 파일로 변환

> [!note] 상세한 Bmp파일 제작은 [다빛채 매뉴얼 > 첨부2](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf)
