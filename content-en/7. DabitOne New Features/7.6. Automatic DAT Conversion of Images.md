---
title: 7.6. Automatic DAT Conversion of Images
---

> [!abstract] When you put a BMP · PNG · JPG image into the playlist as it is, DabitOne automatically converts it to a .dat file for the LED display
> The converted file name follows the original image name automatically, so you can recognize it in the list at once.

#### Overview

- The LED display shows only images in **.dat format**. Before, you had to make the .dat file first through a separate conversion process.
- In DabitOne, when you select a normal image in `표시파일명` (Display file name), **DabitOne converts it to .dat at once and adds it to the list.** You do not need a separate conversion program.

#### How to use

1. `편집` (Edit) tab > double-click `표시파일명` (Display file name) > `이미지` (Image)
2. The file selection window **shows .dat files and normal images (.bmp/.png/.jpg/.jpeg) together** — select the file that you want as it is
3. When you select a normal image, DabitOne converts it automatically to fit the LED display screen size and adds it to the list. When it is complete, the «변환 완료» (Conversion complete) notification shows.

> [!tip] Image ratio
> DabitOne converts the image to fill the LED display screen. An image with a width-to-height ratio very different from the LED display can look stretched. For the best result, use an image made for the LED display size (example: 96×32).

#### File name rules

- The converted file uses **the original name as it is**: `photo.bmp` → `photo.dat` — the list also shows this name
- When a file with the same name already exists, DabitOne adds a number automatically, like `photo_2.dat`
- When a name is very long, DabitOne shortens it automatically to fit the transfer format, and tells you in the completion notification
- DabitOne saves converted files in `Data\Image` in the program folder

> [!note]
> When you select a file that cannot be read as an image (a damaged file and others), a notification shows, and the list does not change.
