> [!abstract] How to make the images that the LED display shows
> DabitOne has a built-in image tool, so you can make images without an external program such as Paint. You can also use image files made elsewhere (.bmp/.png/.jpg) right away.

> [!note] If you use the old DabitChe, see [[2.7.6. Sending Images from DabitChe]].

### Preparation — set the LED display size

- Before you make an image, **set the LED display size first** in `설정` (Settings) > `전광판 화면 구성` (LED display screen configuration)
- Details: [[2.2.1. Screen Size Settings]]

### Draw pixels in the image editing window

1. `편집` (Edit) tab > `이미지 편집` (Image editing)
	- Canvas size = the LED display size that you set

<!-- TODO: DabitOne screenshot — the whole image editing window (toolbar + canvas) -->

2. In the `도구:` (Tool:) row, select `이동` (Move)/`펜` (Pen)/`스포이드` (Eyedropper) (default `펜` (Pen))
	- `펜` (Pen): select a color in `색상:` (Color:), and click or drag on the canvas to draw pixel by pixel
	- `스포이드` (Eyedropper): picks a color from the canvas and makes it the current color — after one use, it goes back to `펜` (Pen) automatically
	- The selected color shows in the `현재색:` (Current color:) box
	- Change the work scale with the `확대` (Zoom) value, and clear the canvas with `전체지우기` (Clear all)
	- Painting with the black pen erases, like an eraser
3. Load an external image (.bmp/.png/.jpg) with `+ 이미지 추가` (+ Add image) or `열기` (Open) (it is combined with the pixels that you drew)
	- To move the loaded image by dragging, select the `이동` (Move) tool — if you drag with the default `펜` (Pen), you draw
	- `이미지 고정` (Fix image): fixes the loaded image into pixels / `- 이미지 삭제` (- Delete image): removes the loaded image
4. You can go back **up to 50 steps** with `실행취소` (Undo)/`다시실행` (Redo)
5. `저장` (Save) or `다른이름저장` (Save as) > save it as an image file (.bmp/.png/.jpg) (default folder `Data\Image`)

Make the saved image into LED display content (.dat) with the steps in [[2.7.2. Converting Images or Text to dat or ani Files]].

### Prepare an external image

- Whatever tool you used, such as Paint or Photoshop, **you can use a .bmp/.png/.jpg file right away**
- We recommend that you make the image the same size as the LED display (width = number of columns × 16 pixels, height = number of rows × 16 pixels)
	- If the size is different, the image is cut or stretched, depending on how you load it

### Make a moving image (GIF)

1. `편집` (Edit) tab > `GIF 편집` (GIF editing)
2. Draw frame by frame — manage frames with `+ 프레임` (+ Frame)/`복제` (Duplicate)/`- 삭제` (- Delete), set the frame time with `delay:` (ms), and preview with `▶ 재생` (▶ Play)
3. `저장` (Save) > save it as a .gif file (default folder `Data\Video`)
