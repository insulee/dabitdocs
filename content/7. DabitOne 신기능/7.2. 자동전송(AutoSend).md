> [!abstract] 자동전송 (AutoSend) — 별도 앱 (DabitOne 신규)
> 미리 정한 프리셋으로 설정부터 콘텐츠까지 한 번에 자동 전송하는 자매 앱

#### 어떤 점이 좋아졌나요

- 레거시에는 없던 도구로, DabitOne과 함께 배포
- 같은 설정을 여러 전광판에 반복할 때, 항목을 하나씩 보내지 않고 **체크 → 자동 전송** 한 번으로 완료
- 현장 초기 설치나 여러 대 일괄 세팅에서 시간을 크게 단축

#### 무엇을 보낼 수 있나요

- 펌웨어, 화면 구성, 표출신호, 스케줄 파일, 폰트
- 실시간 메시지·실시간 문구 설정, 페이지 메시지(개수·내용), 기타 패킷, 보드기능설정 — 전송 항목 11개
- 12번째 항목 `전송 후 정보확인`을 켜면, 전송 전후 컨트롤러 정보를 읽어 비교 — 제대로 들어갔는지 자동 확인

#### 사용 방법

1. DabitOne AutoSend 실행 (DabitOne과 함께 배포되는 별도 프로그램)
2. 통신 방식 선택 (Serial 또는 TCP)
3. 보낼 항목 체크 후, 각 항목의 `설정` 버튼에서 내용 지정
4. `자동 전송` 클릭 시 체크한 항목이 순서대로 전송되고, 진행 상황과 로그 표시
   〔AutoSend 메인 화면 캡처 1장〕
5. 자주 쓰는 조합은 **프리셋**으로 저장해 두고, 다음 현장에서 불러 사용
