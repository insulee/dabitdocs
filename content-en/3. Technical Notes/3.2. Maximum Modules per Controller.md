title: 3.2. Maximum Modules per Controller

>[!abstract] Maximum modules per Dabit Solution controller, with Ethernet and certification status
> The maximum screen size **depends on the firmware version**. The first table is for the official version **V4.5.4 or later** (256 colors on all models). The second table is for the old versions **before the V4.5.4 upgrade (V4.0.3 or earlier)** (DB400 · DB402 · DB500 · DB502 · DB600 — DB520 and DB720 never shipped with an old version, so see only the first table). You can also upgrade DB400 and DB402 boards that shipped earlier to V4.5.4 (256 colors) with the `_legacy_v1` · `_legacy_v2` files (only DB502 boards that shipped earlier stay on V4.0.3). After the upgrade, the first table applies. Check the version of the board with `![0081!]` — [[3.21. Reading Controller Firmware Information]]

#### V4.5.4 or later (official · 256 colors · DB720 16-bit color option: 65,536 colors)

Based on 16×16 modules. The number of rows and columns in the firmware file name is the **row limit · column limit** of that variant (for example: `DIBD600T_08B_04R016C` = 4 rows × 16 columns). You can set rows and columns freely within these limits.

> [!warning] The column limit is fixed — you cannot add columns by using fewer rows
> The old versions (V4.0.3 or earlier) counted the total number of modules. So you could use 1 row × 40 columns instead of 2 rows × 20 columns. **From V4.5.4, the number of columns is fixed to the column limit in the file name** — for example: DB520S allows up to 32 columns even with 1 row, DB720T up to 32 columns, DB720U up to 14 columns, DB725T up to 16 columns, DB725U up to 12 columns, DB500S · DB600S · DB600T up to 16 columns, and DB600U up to 8 columns. If you saved a screen wider than the limit in an old version, the screen shrinks to the limit at boot after the upgrade to V4.5.4.

| --- | :--: | :--: | --- | :--: | --- |
| DB400S | 2 × 10 | 20 | 256 colors | O | Pre-test passed |
| DB402S | 2 × 10 | 20 | 256 colors | X | Pre-test passed |
| DB500S | 2 × 16 | 32 | 256 colors | O | Not certified |
| DB502S | 2 × 16 | 32 | 256 colors | X | Certified |
| DB600S | 2 × 16 | 32 | 256 colors | O | Certified |
| DB600T | 4 × 16 | 64 | 256 colors | O | Certified |
| DB600U | 8 × 8 | 64 | 256 colors | O | Certified |
| DB520S | 2 × 32 | 64 | 256 colors | O (built-in web server) | Planned |
| DB720T | 4 × 32 | 128 | 256 colors | O (built-in web server) | Planned |
| DB720U | 8 × 14 | 112 | 256 colors | O (built-in web server) | Planned |
| DB725T (DB720 16-bit color option) | 4 × 16 | 64 | 65,536 colors | O (built-in web server) | Planned |
| DB725U (DB720 16-bit color option) | 8 × 12 | 96 | 65,536 colors | O (built-in web server) | Planned |

- Variants that V4.5.4 does not have: DB500T · DB520T · DB520U · DB600V · DB720S
- DB720 16-bit color option (DB725T · DB725U): we ship DB720 boards with 16-bit firmware (`DIBD725T_16C_04R016C` · `DIBD725U_16C_08R012C`). It shows 65,536 colors with 32 levels of red, 64 levels of green, and 32 levels of blue. This firmware is not in the public downloads — contact us if you need to change it
- The double-sided layout (horizontal row, double-sided) uses up to half of the column limit on each side — see [[2.6.2. LED Module Layout]]
- DB400S · DB402S: boards that shipped earlier use the `_legacy_v1` · `_legacy_v2` files (same V4.5.4 · 256 colors · 2 rows × 10 columns). New boards use the standard file — [[2.10.1. Reading Firmware Information and Uploading Firmware]]
- DB520 · DB720 communication: Ethernet TCP (5000) · HTTP (80, built-in web server and web UI) · MQTT · RS485/RS232 · USB · SD
- DB502 boards that shipped earlier keep V4.0.3, so the old table below (2 rows × 20 columns) applies
- DB520 supports direct connection only. Use the DBS540 hub only with DB720 — [[3.33. DBS540 Hub Connection Guide]]
- If you saved a screen wider than the maximum in an old version, the screen shrinks to the maximum number of columns after the upgrade to V4.5.4 — [[2.10.1. Reading Firmware Information and Uploading Firmware]]
- For the number of modules for each layout (horizontal · vertical · double-sided), see [[2.6.2. LED Module Layout]]
- With the Dabit Solution LAN-to-serial converter (DB300E), products without Ethernet can communicate over TCP/IP
