> [!abstract] The connection diagram of the RS485 board and how to connect it to the controller
#### How to connect the RS485 board
- Connect the RS485 board (DB230-RS485-DIPSW5P) with a USB-to-RS485 converter as shown below
- For multiple connections, continue on the same port, and set a different address on each board with the DIP switches
	- For an RS485 connection, we recommend a **twisted pair cable** to reduce noise and electromagnetic interference (EMI: Electro-Magnetic Interference)
	- ![[rs485_1.png]]

#### Connect the controller
- (Important) For an RS485 connection, short **JP3 to 3.3V** on the controller
- The controller **default value** of `BH1(10핀) 모드` (BH1 (10-pin) mode) **is `TTL/RS485`** — usually it connects right away without other settings
- With the DIP switches of the RS485 board attached to the controller, you can set 32 addresses in total (0~31)

> [!tip] When it does not connect — check the BH1 mode
> If the BH1 mode is set to a different value (for example `8Pin Input` for the discrete signal input board), the RS485 connection does not work.
> 1. Connect to the controller first with a different communication method (RS232, TTL, Ethernet, and so on)
> 2. `고급` (Advanced) > `보드기능설정` (Board settings) > `읽기` (Read)
> 3. Check that `BH1(10핀) 모드` (BH1 (10-pin) mode) is `TTL/RS485` — if not, select `TTL/RS485` and click `전송` (Send)
>
> In DBPS, check the same item in `보드 기능 설정` (Board settings) > `BH1(TTL/RS485) Function`
- When the DIP switch address is 01, set the RS-485 Address
	- DabitOne: `통신` (Communication) > `Serial` > `RS-485 Address` : `1`
	- DBPS: `통신 설정` (Communication settings) > `Serial` > `RS-485 Address` : `DABIT 01`

#### (Reference) RS485 Address
- The 5 DIP switches of the RS485 board can set 32 addresses in total, from 0 to 31
- The new DB520 · DB720 also use a separate RS485 board and set the address with its DIP switches (except the DB402, which has built-in DIP switches)
- The DB402S controller uses its 8 built-in DIP switches[^2]
	- Switches 1 and 2: communication speed
	- Switches 4\~8: RS485 Address (32 in total, from 0 to 31)
- The old DB501/DB600 controllers can set 16 addresses in total, from 0 to 15, with 4 built-in switches (switches 5\~8[^1])
