title: 2.4.2. Font Options
---

> [!note] Same in DabitOne and DabitChe
> Font groups and font options are controller concepts, so DabitChe uses them in the same way. In the font transfer window of DabitChe, you also set `폰트그룹` (Font group), font options such as `16x16/16x16`, and the English, Hangul combination type, and user font slots — see the legacy section of [2.4.4. Vertical Font Settings](https://docs.dabitsol.com/2.4.4) (Korean).
>
> However, **only DabitOne can use the system fonts installed on the PC and any text size**. DabitChe uses only the FNT fonts uploaded to the controller and fixed sizes (08x16, 16x16).

#### Font groups
- A font group has 3 parts: English, Hangul, and user font
- If you combine fonts and set a font group, you can show many different fonts
	- You can set 4 font groups in total, from font group 1 (default) to font group 4

#### Font options
- 08x16, 16x16, 16x32, and 32x32 are sizes in module pixels (in DabitOne, the font file name shows the size)
- Number of characters for each font option
- To show 16x16 fonts, see [2.4.5. 16x16 Font Settings (Latin Letters and Digits)](https://docs.dabitsol.com/2.4.5) (Korean)

| Option          | Module               | English/digits | Hangul/user font |
| ----------- | ---------------- | :---: | :------: |
| 8x16/16x16  | 1 row × 1 column module (16x16 pixels) |  2 characters  |   1 character    |
| 16x16/16x16 | 1 row × 1 column module (16x16 pixels) |  1 character  |   1 character    |
| 16x32/32x32 | 2 rows × 2 columns module (32x32 pixels) |  2 characters  |   1 character    |
- Display for each font option
	![[폰트옵션1.png]]

#### Hangul combination type
- Option names in DabitOne
- `한글조합형` (Hangul, combination type)
	- A font that shows Korean characters by combining consonants and vowels. It is smaller than Unicode fonts
- `유니코드 한글` (Unicode Hangul) — also called Unicode complete-syllable type
	- A font with only the Korean part of Unicode
- `유니코드 가나` (Unicode Kana) — also called Unicode Japanese
	- A font with only the Kana (Hiragana + Katakana) part of Unicode
- `유니코드 한자` (Unicode Hanja) — also called Unicode Chinese
	- A font with only the Hanja (Chinese characters) part of Unicode
- `유니코드 전체` (Unicode, all)
	- A font with all of Unicode. It is very large

#### Selecting the character encoding/font for a test in DabitOne
- If you select `한글조합형` (Hangul, combination type) -> character encoding/font: `EUC-KR/한글조합형` (Hangul, combination type)
- If you select Unicode -> character encoding/font: `UTF16/유니코드` (Unicode)
- For details, see section 2.2.3 (`/Fxxyy`) of [2.8.1. ASCII Protocol Manual](https://docs.dabitsol.com/2.8.1) (Korean)

> [!info]  To use special characters, custom characters, and so on, see [2.4.3. Entering User Fonts](https://docs.dabitsol.com/2.4.3) (Korean)
