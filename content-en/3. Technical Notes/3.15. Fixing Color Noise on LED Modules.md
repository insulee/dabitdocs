---
title: 3.15. Fixing Color Noise on LED Modules
---

> [!abstract] What to do when the colors of uploaded content look wrong on the LED modules
> The cause is a Windows setting, not the program. So the fix is the same, whichever program you used to make the display file

## Symptom

When you upload text from the PC to the LED modules, **the colors show differently from what you intended** (example: text that should be yellow shows red and green dots mixed in)

![[LED잡티_3.jpg|300]]

## How to fix it

### Step 1: Change a Windows setting
1. This PC > Properties > Advanced system settings
2. System Properties
   - `Advanced` > Performance > `Settings`
     - ![[LED잡티_1.png]]
3. Performance Options > `Visual Effects` > `Adjust for best performance`
     - ![[LED잡티_2.png]]
4. Click the `OK` button

### Step 2: Make the text again and upload it (important!)

> [!warning] Important
> Changing the setting alone does **not** remove the noise!  
> The files that are already uploaded to the LED controller still have the noise.

1. Start the program that you used (**DabitOne** or **DabitChe**) again
2. **Write** the text **again**
3. **Make** the display file **again**
4. **Upload** it to the LED modules **again**

## Why?

When the Windows screen effects (the function that makes text look smooth) are on, the display file gets unneeded dots.

To turn text into a display file, the program copies the screen that Windows draws as it is. So **even with a different program, the same symptom can occur if the Windows setting stays the same.** That is why you must change the Windows setting first, not the program.

**Make the files again after you change the Windows setting**, and you get clean display files that show on the LED with no noise.

> [!tip] Note
> - This setting changes only how the PC screen shows things. It does not cause problems for other programs.
> - Keep this setting each time you make LED text, so that no noise occurs.
