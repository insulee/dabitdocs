> [!abstract] 내장 GIF 편집기 (DabitOne 신규)
> 점멸, 순환 텍스트처럼 여러 장면(프레임)으로 된 콘텐츠를 앱 안에서 직접 만드는 도구

#### 어떤 점이 좋아졌나요

- 레거시는 GIF를 외부 프로그램으로 만들어 **불러오기만** 가능
- DabitOne은 **앱 안에서 바로 제작·편집** — 현장에서 간단한 움직이는 콘텐츠를 직접 제작 가능
- 픽셀 캔버스 + 16색 팔레트 + 프레임 타임라인(추가·복제·삭제·재생)으로 작업

#### 사용 방법

1. `편집` 탭에서 `GIF 편집` 버튼 클릭
2. 캔버스에 그림을 그리고, 아래 타임라인에서 프레임 추가
   〔GIF 편집기 창 캡처 1장〕
3. 프레임마다 표시 시간(delay) 지정
4. `저장`으로 GIF 파일 생성

> [!note] 참고
> GIF 편집기는 독립 도구. 만든 파일은 스케줄에 따로 불러와서 사용 — 편집기에서 바로 전송 안 됨.
