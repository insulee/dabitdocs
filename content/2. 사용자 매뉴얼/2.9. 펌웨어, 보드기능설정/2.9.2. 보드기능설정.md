
>[!abstract] 컨트롤러의 보드 기능(포트 설정, 센서 연결 등) 설정 방법 안내

## 설정 항목 설명

#### 디버깅 여부
- 컨트롤러 디버깅을 위한 설정
- 기본값: `Disable`

#### BH1(TTL/RS485) Function
- 컨트롤러 BH1 포트의 기능 설정
- 기본값: `TTL/RS485`
- **접점보드 연결 시**: 반드시 `8pin Input`으로 설정 필요 - [[3.8. 접점보드를 이용하여 표시목록 표출]] 참고
- 기타 옵션: `CAN`, `I2C`, `SPI`

#### Baud Rate 설정
- BH1(TTL/RS485), J2(RS232), J3(TTL) 포트의 통신 속도 설정
- 각 포트별 개별 설정 가능
- (참고) DB402S는 딥스위치 1, 2번으로 Baud Rate를 설정하므로, 이 보드기능설정의 Baud Rate 값은 적용되지 않음

#### J4(Relay) Function
- J4 포트의 기능 설정
- 기본값: `Relay Out`
- 센서 연결 옵션:
	- `CDS`: 조도센서 - [[3.10. 조도센서 연결 및 설정방법]] 참고
	- `DS1302`: RTC 모듈 - [[3.12. 배터리를 이용한 정확한 시간 표시 방법]] 참고
	- `SHT31`: 온습도센서 - [[3.28. 온습도센서 연결 및 표시방법]] 참고

#### RS485 Address
- RS485 통신으로 연결된 경우 컨트롤러 주소 확인 가능

## DabitOne

#### 보드기능설정 진입
- `고급` > `보드기능설정` 섹션

#### 현재 설정값 읽기
1. 통신 연결 후 `읽기` 버튼 클릭
2. 현재 컨트롤러에 설정된 값이 각 항목에 표시됨
	- 처음 창을 열었을 때는 비어있음

#### 설정 변경 및 적용
1. 변경할 옵션 선택
2. `저장` 버튼 클릭
3. 설정이 컨트롤러에 적용됨
