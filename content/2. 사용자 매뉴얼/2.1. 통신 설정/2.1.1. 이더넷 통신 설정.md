>[!abstract] dbNet에서 RJ45(이더넷포트)가 내장되어 있는 컨트롤러(DB400시리즈/DB500시리즈/DB520시리즈/DB600시리즈/DB720시리즈)의 통신 설정 안내

#### 네트워크 어댑터의 IPv4 주소 확인
- 윈도우 검색 > 명령프롬프트 > `ipconfig /all`
- 이더넷 어댑터 또는 무선 LAN 어댑터의 IPv4 주소..... : `***.***.***.***` 확인

#### 컨트롤러의 네트워크 값 입력

> [!note] 다빛채·DBPS를 쓰신다면
> 컨트롤러에 IP·서브넷·게이트웨이를 넣는 기능은 다빛채와 DBPS에도 있습니다. 아래 값을 정하는 방법(특히 네번째 옥텟 규칙)은 프로그램과 상관없이 같고, 메뉴 위치만 다릅니다. 다빛채 메뉴 위치는 [다빛채 매뉴얼](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf)을 참고하세요.

- DabitOne `통신` 탭의 `dbNet`에서 진행
- 통신 > dbNet > 하단 공통 버튼 행(`Search`/`Set`/`Add`/`Reset`)의 `Search`
- 연결하려는 컨트롤러의 Mac address 선택
- IP Address, Subnet Mask, Gateway, Port 등 **네트워크 정보 변경**
	- IP Address: 연결되어 있는 네트워크 어댑터 IPv4 주소와 **네번째 옥탯(Octet)은 다른 값**으로 입력
	- 예를 들어
		- 네트워크 어댑터의 IPv4 주소: 169.254.121.210
		- 컨트롤러의 IP Address: 169.254.121.*** (1~255 중 210을 제외한 값)
		- Subnet Mask, Gateway: 네트워크 어댑터와 **동일한 값**
- `Set` — 변경한 네트워크 값을 컨트롤러에 적용
- `Add` — 선택한 컨트롤러의 IP·포트를 왼쪽 통신 설정(`Client TCP/IP`·`UDP`·`Server TCP/IP`)에 한 번에 채우고, 통신방식을 자동 전환한 뒤 **바로 연결까지 시도** (간단한 연결 테스트). `Search` → MAC 선택 → `Add` 세 번이면 연결 완료
- 자주 쓰는 IP는 `IP 저장` 버튼으로 PC에 저장하고, `IP 채우기` 버튼으로 위 칸에 다시 채울 수 있음 (장비 적용은 `Set`)
#### (예외) 이더넷으로 1:1 연결시 네트워크 어댑터의 수동 IP 주소 설정
- 컨트롤러의 IP Address에 맞춰 수동으로 네트워크 어댑터의 IP를 설정하면 1:1 연결이 가능
- 윈도우 검색 > `네트워크 연결 보기`를 눌러 네트워크 연결 폴더 열기
- 이더넷 아이콘 > 우측버튼 클릭 >` 속성` 
- `인터넷 프로토콜 버전 4(TCP/IPv4) `> `속성`
	- 다음 IP 주소 사용
		- IP 주소: 컨트롤러의 IP Address와 **네번째 옥텟(Octet)은 다른 값**으로 입력
		- Subnet Mask, Gateway: 컨트롤러와 **동일한 값**

#### DHCP로 연결
- Dynamic Host Configuration Protocol(DHCP)는 네트워크 상의 장치들이 IP 주소 및 기타 네트워크 설정(서브넷 마스크, 기본 게이트웨이, DNS 서버 등)을 자동으로 할당받을 수 있도록 지원하는 프로토콜
	1. dbNet > Network 그룹의 `DHCP` 라디오 버튼 선택 (`Static`/`DHCP` 중 선택) > `Set`
	2. 컨트롤러의 전원을 다시 공급
	3. dbNet > 하단 버튼 행의 `Search`
	4. 자동으로 할당 받은 네트워크 값 확인

> [!note] 펌웨어 V4.5.4 이상 — MAC 주소와 DHCP 이름
> - **랜선 MAC = 보드에 기록된 회사 MAC(`54:FF:82…`)**(DB400 · DB402 · DB502 · DB520 · DB720). V4.5.4로 올리면 그 보드의 랜선 MAC이 바뀌므로, 공유기에서 MAC으로 IP를 예약했거나 ARP 테이블에 MAC을 묶어 둔 현장은 다시 등록하십시오. IP로만 관리하는 현장은 영향이 없습니다. 확인: `![0081!]`의 `mac:`과 공유기 DHCP 목록의 MAC이 같으면 정상
> - 공유기 · DHCP 서버 목록에 보드가 `DABIT-{모델}-{MAC 뒤 4자리}`(예 `DABIT-DB720T-0003`)로 보입니다

> [!note] DB300E, DB300WB, DB320WB의 설정은 [[2.1.2. LAN to Serial 컨버터 통신 설정]] 참고
