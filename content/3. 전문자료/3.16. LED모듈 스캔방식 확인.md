
#### 용어 정의 및 설명
- **픽셀**
	- 하나의 **빛을 내는 단위**로 픽셀 수와 배치 밀도에 따라 화면의 해상도와 선명도가 결정
- **LED칩**
	- 전류가 흐르면 빛을 방출하는 반도체 소자로 **하나의 픽셀은 3개의 칩 (RGB)** 으로 구성
- **드라이브 IC**
	- LED 모듈에 전류를 공급하고 제어하는 역할을 하는 반도체 칩으로 일반적으로 24개 핀이 입력, 출력, 그리고 제어 신호를 관리
		- GND (1번): 접지
		- SDI (2번): 직렬 데이터 입력 (Serial Data Input)
		- CLK (3번): 데이터 클럭 입력 (Clock Input)
		- LE (4번): 데이터 래치 입력 (Latch Enable)
		- OE (21번): 출력 활성화 (Output Enable)
		- SDO (22번): 직렬 데이터 출력 (Serial Data Output)
		- VDD (24번): 전원 공급 핀
		- R-EXT (23번): 외부 저항을 연결하여 전류를 조정
		- **OUT 0~OUT 15: 각 LED 칩을 구동하는 출력 핀**
			- 하나의 핀이 하나의 LED 칩을 구동
			- 하나의 드라이브 IC(총 16개의 출력핀)가 16개의 LED 칩을 제어
		- ![[20_Marketing_Team/23_Resource/Attachment/pin_configuration.png|200]]
- **스캔방식**
	- 스캔은 LED 디스플레이에서 한 번에 구동되는 행(row)의 수
	- 예를 들어, 1/8 스캔은 8개의 행 중 1개의 행만 동시에 켜지는 방식

#### 스캔방식에 따라 필요한 드라이브 IC 개수 설정 방법


|     | 순서                              | 계산식        | 예(2단2열)          | 설명                                 |
| --- | ------------------------------- | ---------- | ---------------- | ---------------------------------- |
| 1   | 총 픽셀수                           | a          | 1024 = 32 x 32   | 1단 1열은 <br>16x16픽셀                 |
| 2   | LED칩 개수                         | b = a x 3  | 3072 = 1024 x 3  | 1개의 픽셀에 <br>3개(RGB)의 칩             |
| 3   | 모든 LED칩을 제어하기 위해<br>필요한 드라이브 IC | c = b / 16 | 192 = 3072 / 16  | 하나의 드라이브 IC가 <br>16개 칩을 제어         |
| 4   | 스캔방식                            | d          | 1/8              |                                    |
| 5   | 스캔방식에 필요 드라이브 IC                | e = c x d  | 24 = 192 x (1/8) | 1/8스캔은 <br>8개 드라이브 IC 중 <br>한개만 필요 |

#### 스캔방식을 모를때, 실제 드라이브 IC 개수로 파악하는 방법

|     | 순서                              | 계산식        | 예(2단2열)         | 설명                                                  |
| --- | ------------------------------- | ---------- | --------------- | --------------------------------------------------- |
| 1   | 총 픽셀수                           | a          | 1024 = 32 x 32  | 1단 1열은 <br>16x16픽셀                                  |
| 2   | LED칩 개수                         | b = a x 3  | 3072 = 1024 x 3 | 1개의 픽셀에 <br>3개(RGB)의 칩                              |
| 3   | 모든 LED칩을 제어하기 위해<br>필요한 드라이브 IC | c = b / 16 | 192 = 3072 / 16 | 하나의 드라이브 IC가 <br>16개 칩을 제어                          |
| 4   | 내장된 드라이브 IC 개수                  | e          | 24              |                                                     |
| 5   | 스캔방식                            | d = e / c  | 1/8 = 24 / 192  | 모든 LED칩을 제어하기 <br>위해 필요한 드라이브 IC <br>192개 중 24개만 내장 |

#### 1단 1열 기준으로 스캔방식을 간단하게 확인하는 방법
- 모듈 1단1열 기준으로 
	- 모든 LED칩을 제어하기 위해 필요한 드라이브 IC는 48개(c11)
		- 1단1열 = 16x16픽셀 = 256픽셀 = LED칩 768(= 256 x 3)개
		- 768/16 = 48개
	- 1단1열의 드라이브 IC 개수(e)를 세서 48(c11)로 나누면 스캔방식(d) 확인 가능
- 예시
	- DABIT_P8_1R2C_4S_6500cd =12개, 12/48 = 1/4 Scan
	- DABIT_P6_2R2C_8S_6500cd = 6개, 6/48 = 1/8 Scan
	- DABIT_P3_1R4C_16S_900cd = 3개, 3/48 = 1/16 Scan
	- DABIT_P3_2R6C_16S_2700cd = 3개, 3/48 = 1/16 Scan
	- DABIT_P3_4R4C_32S_900cd = 1.5개, 1.5/48 = 1/32 Scan
- (예외) 3컬러 모듈은 픽셀당 LED칩이 2개(RG)이므로 1단1열의 LED칩은 512(= 256 x 2)개
	- 모든 LED칩을 제어하기 위해 필요한 드라이브 IC는 32(= 512 / 16)개 
	- 1단1열의 드라이브 IC 개수(e)를 세서 32(c11_3)로 나누면 스캔방식(d) 확인 가능
