---
title: 2.1.1. Ethernet Communication Settings
---
>[!abstract] How to set up communication in dbNet for controllers with a built-in RJ45 (Ethernet) port (DB400 series/DB500 series/DB520 series/DB600 series/DB720 series)

#### Check the IPv4 address of the network adapter
- Windows search > Command Prompt > `ipconfig /all`
- Check the IPv4 address of the Ethernet adapter or the wireless LAN adapter..... : `***.***.***.***`

#### Enter the network values of the controller

> [!note] If you use DabitChe or DBPS
> DabitChe and DBPS can also enter the IP, subnet, and gateway into the controller. The way to choose the values below (especially the rule for the fourth octet) is the same in every program. Only the menu locations are different. You can find the DabitChe menu locations in the [DabitChe manual](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf) (Korean).

- Use `dbNet` on the DabitOne `통신` (Communication) tab
- 통신 (Communication) > dbNet > `Search` in the common button row at the bottom (`Search`/`Set`/`Add`/`Reset`)
- Select the MAC address of the controller that you want to connect
- **Change the network information**: IP Address, Subnet Mask, Gateway, Port, and so on
	- IP Address: enter a value whose **fourth octet is different** from the IPv4 address of the connected network adapter
	- For example
		- IPv4 address of the network adapter: 169.254.121.210
		- IP Address of the controller: 169.254.121.*** (a value from 1 to 255, except 210)
		- Subnet Mask, Gateway: **the same values** as the network adapter
- `Set` — applies the changed network values to the controller
- `Add` — fills the IP and port of the selected controller into the communication settings on the left (`Client TCP/IP` · `UDP` · `Server TCP/IP`) at once, switches the communication type automatically, and **tries to connect right away** (a simple connection test). `Search` → select the MAC → `Add`: these three steps complete the connection
- Save frequently used IPs on the PC with the `IP 저장` (Save IP) button. You can fill them into the fields above again with the `IP 채우기` (Fill IP) button (to apply them to the device, use `Set`)
#### (Exception) Set the IP address of the network adapter manually for a 1:1 Ethernet connection
- If you set the IP of the network adapter manually to match the IP Address of the controller, a 1:1 connection is possible
- Windows search > click `View network connections` to open the Network Connections folder
- Right-click the Ethernet icon > `Properties`
- `Internet Protocol Version 4 (TCP/IPv4)` > `Properties`
	- Use the following IP address
		- IP address: enter a value whose **fourth octet is different** from the IP Address of the controller
		- Subnet Mask, Gateway: **the same values** as the controller

#### Connect with DHCP
- Dynamic Host Configuration Protocol (DHCP) is a protocol that lets the devices on a network get an IP address and other network settings (subnet mask, default gateway, DNS server, and so on) automatically
	1. dbNet > select the `DHCP` radio button in the Network group (choose `Static` or `DHCP`) > `Set`
	2. Supply power to the controller again
	3. dbNet > `Search` in the button row at the bottom
	4. Check the network values that were assigned automatically

> [!note] Firmware V4.5.4 or later — MAC address and DHCP name
> - **LAN MAC = the company MAC written on the board (`54:FF:82…`)** (DB400 · DB402 · DB502 · DB520 · DB720). When you update to V4.5.4, the LAN MAC of the board changes. If a site reserves the IP by MAC on the router or binds the MAC in the ARP table, register it again. Sites that manage only by IP are not affected. Check: it is normal if the `mac:` of `![0081!]` and the MAC in the DHCP list of the router are the same
> - The board shows as `DABIT-{model}-{last 4 digits of the MAC}` (for example `DABIT-DB720T-0003`) in the router or DHCP server list

> [!note] For the DB300E settings, see [[2.1.2. LAN-to-Serial Converter Settings]] (DB300WB · DB320WB are discontinued)
