
> [!abstract] 영문 및 숫자의 16x16 폰트로 표출방법 안내
> DABIT 컨트롤러에서 8x16 픽셀로 표출되는 영문과 숫자를 16x16픽셀 폰트로 표출하는 방법을 안내  

#### 설정환경
- 컨트롤러: DABIT500S
- 모듈: DABIT P3 2R6C 16S
#### 16x16 폰트 전송

1. 폰트 설정 메뉴 열기
	- DabitOne: `설정` > `폰트전송`
	- DBPS: `설정` > `폰트 전송`
2. 폰트 그룹2를 체크한 뒤, 아래 16x16 폰트 파일을 선택
	- 영어: `ENG 16x16-ASCII-Roman.fnt`
	- 한글조합형: `KOR 16x16-DABIT(표준).fnt`
	- 사용자폰트: `USER 16x16-Special(표준).fnt`
3. 폰트파일 전송 버튼을 눌러 업로드

#### 16x16 폰트 적용 확인

1. 아스키 프로토콜 전송 메뉴 열기
	- DabitOne: `전송` > `ASCII 프로토콜`
	- DBPS: `프로토콜 전송` > `아스키 프로토콜`
2. `전송` 탭 ASCII 프로토콜 영역의 `기본값 설정` 버튼 클릭 > `기본 표시 속성 설정` 창에서 속성 지정 후 `기본값으로 설정` 클릭
3. `![000/T2/C7가나다라마바123ABC!]`
4. 전송 → 전광판에 적용된 세로형 폰트 확인
5. 표출내용
	- ![[16픽셀폰트.png|300]]

#### (참고1) 구버전(다빛채, 프로토콜시뮬레이터)에서 폰트 전송시
- 폰트 전송 창에서 다음의 설정
	- 폰트그룹 1 체크
	- 폰트: `16x16/16x16`
	- 영어: `ENG 16x16-ASCII-Roman.fnt`
	- 한글조합형: `KOR 16x16-DABIT(표준).fnt`
	- 사용자폰트: `USER 16x16-Special(표준).fnt`
- 전송 버튼을 눌러 업로드
#### (참고2) 다빛채 어플에서 전송시
- 한글표출을 하려면 `/F0203` 패킷을 삽입하여 UTF8로 인코딩해서 전송
