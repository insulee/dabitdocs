> [!abstract] POS·키오스크·자체 앱에서 DB520·DB720 전광판을 HTTP로 제어하는 연동 개발자용 안내입니다.
> 호출 규약·명령 32개·문안 조립·미리보기·업로드·문제 해결을 실측 응답(V4.2.0, 2026-09-04) 기준으로 정리했습니다.

## 1. 먼저 알아둘 것 6가지

- **오류도 HTTP 200으로 옵니다** — `/api/v1/command`의 성공 판정은 본문 `code === 0` 하나뿐입니다. HTTP 상태만 보면 실패를 성공으로 처리합니다
- **명령 간격 100ms(초당 10회)** — 전 경로 공통. 넘기면 HTTP 429 + `{"code":429,"message":"Rate limit exceeded"}`. 호출은 단일 큐로 직렬화하고 120ms 이상 벌리세요
- **밝기는 단위가 셋** — 쓰기 `set_brightness` value는 **0~99 percent**(0=자동 센서, 100 이상 거부). 레거시 `/status`의 `brightness`는 **0~255 바이트**(실측 127 = 50%). `/api/v1/status`는 V4.2.0 실측 50 — 단위는 §11 참조. 읽은 값을 그대로 다시 쓰지 마세요
- **동시 연결 한도** — 소켓 7개, MJPEG 스트림 슬롯 2개, 수신·송신 타임아웃 60초. 폴링 클라이언트가 여럿이면 금방 고갈됩니다
- **보드 IP·모델·펌웨어는 바뀝니다** — 앱 시작 시 `GET /api/v1/info`로 `board_type`·`version`을 읽고 화면 크기는 `/status`의 `panel_w`·`panel_h`로 맞추세요. 하드코딩 금지
- **공장 기본은 API 키 미설정(무인증)** — `reboot`·`factory_reset` 포함 32개 명령이 LAN 전체에 열려 있고 HTTPS도 없습니다. LAN 밖(공인망)에 노출하지 마세요

## 2. 지원 대상

- **컨트롤러**: DIBD520·720 계열 (ESP32-P4 보드). 기종이 아니라 **펌웨어 기준**입니다
- **펌웨어**: **V3.8.5·V4.2.0 실측** (이 문서의 예시 응답은 V4.2.0 2026-09-03). 명령 목록은 버전마다 다를 수 있으니 `GET /api/v1/actions`로 확인하세요
- **통신**: HTTP/1.1 평문, 포트 80, HTTPS 없음, 같은 LAN. HEAD 메서드는 전역 405. CORS 헤더가 없어 브라우저 JS가 다른 출처에서 직접 부르려면 프록시가 필요합니다. `get_network`의 `port: 5000`은 별도 TCP ASCII 명령 포트로 이 문서 범위 밖입니다

## 4. 명령 호출 규약

- **요청**: `POST /api/v1/command`, `Content-Type: application/json`, 본문 `{"action":"이름","params":{...}}`. params가 없는 명령은 `params` 자체를 생략합니다
- **응답**: `{"code":0,"result":{...}}`. 실패면 `code ≠ 0` + `message`, 거부 원문이 `result`에 같이 올 수 있습니다. 성공인데 `result`가 없는 명령도 있습니다
- **`code` 값**: `0` 성공 · `-1` 보드가 명령 거부 — 실측 `{"code":-1,"result":{"data":"J0F1","raw":"![00J0F1!]"},"message":"command failed"}` · `400` action 누락·JSON 오류 · `404` 미등록 action · `429` 레이트리밋(이때만 HTTP도 429)
- **route** (`/api/v1/actions`의 `route` 필드): `cat` = ASCII 명령으로 변환, 응답 `{data, raw}` 원문 통과 / `direct` = 구조화 JSON / `msg` = 문안 전송(`send_*`) / `special` = JSON 직접 처리(`reboot`·`factory_reset`·`schedule_apply_v2`)
- **cat 응답 읽는 법**: `data` 앞 두 글자가 명령 코드, 그 뒤가 값. 공백 한 칸 뒤 `{...}`면 JSON(`K1 {"date":...}`). 거부는 말미 `F`+숫자(`J0F1`) — 문안 속 `/F02`는 거부가 아닙니다

실측 예시 (V4.2.0, 요청 → 응답, 오류도 전부 HTTP 200):
```text
{"action":"get_network"}
→ {"code":0,"result":{"ip":"192.168.1.225","netmask":"255.255.255.0","gateway":"192.168.1.1","mac":"54:FF:22:00:00:02","port":5000,"is_dhcp":true,"device_name":"DB720U_08B          ","dns":"                             "}}
{"action":"get_brightness"}
→ {"code":0,"result":{"data":"J1/P0000/D9901/F0003/E0101/S2002/X0000/Y0000/B000/C3/G0/T0","raw":"![00J1/P0000/D9901/F0003/E0101/S2002/X0000/Y0000/B000/C3/G0/T0!]"}}
{}
→ {"code":400,"message":"Missing action field"}
{"action":"no_such_action"}
→ {"code":404,"message":"unknown action"}
```

## 6. 문안 텍스트 조립

- 속성은 `/문자+숫자` 형태로 **문구 앞에** 붙입니다. 권장 순서 `/P /D /E /S /F /C`. 예: `{"action":"send_realtime","params":{"text":"/P0000/E0100/S2002/F0203/C3어서오세요"}}`
- `/Pxxyy` 페이지(00부터)·섹션 / `/Dxxyy` 반복(99=무한)·표시 방법(00 일반, 01 즉시) / `/Exxyy` 입장·퇴장 효과 — **퇴장 `00` = 무퇴장(계속 표시)**, `01` 정지 / `/Sxxyy` 효과 속도·유지 시간(×0.5초)
- `/Fxxyy` 인코딩·글자 크기 — **한글은 `/F02` 필수**(JSON은 UTF-8로 나가는데 지시가 없으면 보드가 EUC-KR로 읽어 깨짐) / `/Cx` 문자색 0~7, `/Gx` 배경색 0~7, `/Knn` 64색 — 효과 코드·색 팔레트 전체는 [[2.9.1. 신 ASCII 프로토콜 소개]] · [[2.8.1. ASCII 프로토콜 매뉴얼]] 참조

## 7. 미리보기 영상

- **스트림**: `GET /panel_stream?src=pgm&fps=15&q=70` — `multipart/x-mixed-replace`(MJPEG). `<img src>`에 바로 넣으면 됩니다. 슬롯 2개를 `/stream`(카메라)과 공유하니 앱당 1개만 여세요. 사용량은 `/status`의 `stream_clients`로 확인 — `2`면 추가 스트림이 거부됩니다
- **스냅샷**: `GET /panel.jpg?t=<timestamp>` — 캐시버스터 `?t=` 필수(`Cache-Control: no-store`), 폴링 간격 **500ms 이상**(하드웨어 JPEG 인코딩 부하). 실측 96×32 보드 1087바이트
- `q`(품질) 파라미터는 실측상 무시됩니다. JPEG 압축이라 **색 번짐**이 있으니 색·색심도 판정은 실물 촬영으로만 하세요

## 8. 화면 파일 업로드 (고급)

- `POST /api/v1/system/www_upload` — `multipart/form-data`, 필드명 `files[]`, 파일마다 별도 part(zip 불가). **`X-API-Key` 헤더 필수** — 키 미설정 보드는 HTTP 500 `auth not configured`(text/plain)
- **첫 키는 시리얼 케이블로만** — `![00WK={키}!]`(8~32자). 네트워크로는 첫 설정을 거부합니다. 이후 변경은 `api_key_rotate {"new_key":"..."}`
- 한도 **480KB**(초과 413 `max 480KB`), 파일명은 영문·숫자 ASCII만, `..` `/` `\` `:` 포함 시 400. 예약 URL(`/detect /stream /panel_stream /apply /status /test_pattern /panel.jpg /api/v1/*`)은 파일명으로 못 씁니다
- **비원자 기록** — 파일 단위로 바로 flash에 씁니다. 중간에 끊기면 부분 상태가 남으므로 **`index.html`을 마지막에** 올리세요. 업로드 중 다른 클라이언트의 `/`는 503

> [!warning] 펌웨어 갱신(OTA)은 화면을 빌드 내장본으로 되돌립니다 — 갱신 뒤 재업로드가 필요합니다. 또한 현행 펌웨어는 `index.html` 외 추가 파일 요청이 404로 떨어지는 사례가 있어(펌웨어 제한) JS·CSS는 HTML 한 파일에 인라인하는 것이 안전합니다.

## 9. 연동 체크리스트 — 3줄 왕복

```text
# curl (bash) — 각 줄 사이 100ms 이상

curl -s http://<보드IP>/api/v1/info
curl -s -X POST http://<보드IP>/api/v1/command -H "Content-Type: application/json" -d '{"action":"send_realtime","params":{"text":"/P0000/E0100/S2002/F0203/C3어서오세요"}}'
curl -s http://<보드IP>/api/v1/status

# PowerShell 7

Invoke-RestMethod http://<보드IP>/api/v1/info
Invoke-RestMethod http://<보드IP>/api/v1/command -Method POST -ContentType 'application/json; charset=utf-8' -Body '{"action":"send_realtime","params":{"text":"/P0000/E0100/S2002/F0203/C3어서오세요"}}'
Invoke-RestMethod http://<보드IP>/api/v1/status
```

- **기대 응답**: ① `{"code":0,"result":{"board_type":"DIBD720U_08B_08R020C","dibd_type":72,"version":"V4.2.0 2026-09-03"}}` 형태로 `board_type`이 내 보드와 일치 ② `code` 0 + LED에 "어서오세요" 표출(응답 `result` 형식은 yaml 참조) ③ `code` 0 + `result.brightness`·`h_mdu`·`v_mdu`·`uptime_s` 존재
- 셋 중 하나라도 `code ≠ 0`이면 §10으로. 두 번째가 429면 첫 호출과 간격이 100ms 미만입니다

## 10. 문제 해결

| 증상 | 원인 | 조치 |
| --- | --- | --- |
| HTTP는 항상 200인데 동작하지 않음 | 오류도 200으로 옴 | 본문 `code` 판정. `message`·`result.data` 말미 `F`+숫자 확인 |
| HTTP 429 `Rate limit exceeded` | 100ms 간격 위반(초당 10회) | 단일 큐 직렬화, 120ms 이상 간격, 429면 잠시 뒤 재시도 |
| `set_brightness` 100이 `code -1`(`J0F1`) | percent 범위는 0~99 | 99 이하로. 0은 자동 센서(꺼짐 아님) |
| `display_power {"on":1}`이 꺼짐 | JSON boolean만 인식, 숫자·문자열은 false | `{"on":true}` / `{"on":false}` |
| `send_page` 문구 앞에 "00"이 붙음 | `page` 파라미터 결함(`code 0`인데 깨짐) | `page` 빼고 text에 `/Pxxyy` 인라인 |
| 연결 거부·스트림이 안 열림 | 소켓 7·스트림 슬롯 2 초과, 60초 타임아웃 | 폴링 클라이언트 줄이기, 스트림 1개, `/status` `stream_clients` 확인 |
| `bridge_ascii` H4(배경이미지)가 `F3` 거부 | HTTP 브릿지의 펌웨어 제한 — TCP:5000만 성공 | 문구 속성 `/Bnnn`으로 대신 (`send_realtime {"text":"/B001"}` = 배경만, `"/B001어서오세요"` = 배경+글자, V4.2.0 실물 확인). 단 `/panel.jpg` 미리보기에는 배경이 안 나옴 |
| `display_power`가 `code -1`(`M5F3`) | V4.1.0에서 M5 폐지, 브릿지 미갱신 | `bridge_ascii P3 1/0`으로 전원 제어 |
| `get_brightness`가 percent를 안 줌(`J1/P0000/...`) | V4.2.0은 기본 속성 프레임을 회신 | 밝기는 `/status` `brightness` 바이트로 환산. 프레임 속 `/B000`은 배경이미지 번호이지 밝기가 아님 |

## 11. 아직 확정되지 않은 것 (격리)

- **배경이미지 H4의 HTTP 경로** — `bridge_ascii` H4는 `F3`으로 거부됩니다(V3.8.5·V4.2.0 실측). 문구 속성 `/Bnnn`은 정상이나, 미리보기(`/panel.jpg`·`/panel_stream`)에 배경 레이어가 빠지는 것은 펌웨어 확인 중
- **문구 읽기(readback) 명령** — 지금 표출 중인 문구를 돌려주는 명령이 없습니다. 연동 앱이 마지막 전송값을 직접 보관하세요
- **원격(LAN 밖) 접속 경로** — 평문·무인증 전제라 정해진 경로가 없습니다. VPN 등은 현장 네트워크 정책 확인 후 결정
- **API 키 설정 후 "선택" 인증 경로의 동작** — `command` 등이 키를 요구하게 되는지, 화면이 계속 동작하는지 미확정
- **실시간 문구 삭제** — `delete_realtime`·`bridge_ascii` L2 모두 `L2F1` 거부(V4.2.0). 지우는 정식 경로 미확정 — 덮어쓰기로 운용
- **`/api/v1/status` brightness 단위** — V3.7.0 실측 바이트(50% → 127) vs V4.2.0 실측 50. 레거시 `/status`는 127(바이트)로 일관. 버전별 확인 필요

> [!note] 위 항목은 확정 전까지 고객 안내·제안서·견적에 쓰지 마세요. 확정되면 이 절에서 본문으로 옮깁니다.
