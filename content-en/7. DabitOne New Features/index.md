> [!abstract] New features in DabitOne
> Features that DabitOne added or greatly improved, which the legacy programs (DBPS · DabitChe) did not have. Click an item to go to its detailed instructions

- [[7.1. Preview and LED Display Screen]] — preview before sending + the actual display screen after sending
- [[7.2. Built-in GIF Editor]] — make content with several scenes (frames), such as blinking and cycling, directly in the app
- [[7.3. Two-Level Factory Reset]] — select content-only clear (soft) / complete reset (full)
- [[7.4. Easier IP Address Entry]] — type only the digits, and the dots (.) appear automatically
- [[7.5. Color Mode Switching]] — check and switch the color mode (advanced)
- [[7.6. Automatic DAT Conversion of Images]] — select a normal image, and DabitOne converts it to .dat at once and adds it to the list
- [[7.7. Display Signal Filter]] — check only the conditions that you know, such as duty, drive method, and IC, to narrow the display signal candidates
- [[7.8. Sending HEX Protocol Messages]] — select items in the Send tab, and DabitOne makes and sends the packet; the meaning of each item and its ASCII match
