
> [!abstract] 컨트롤러 전원 차단 시에도 정확한 시간을 유지하기 위한 RTC 모듈(DS3231) 연결 및 설정 방법

## 1. 개요

- 컨트롤러(DB500, DB600, DB502)는 전원이 차단되면 내부 시간이 초기화됨
- **DS3231 RTC 모듈**을 연결하면, 전원 차단 후 재공급 시에도 정확한 시간이 유지됨
- 실시간 시간 데이터가 필요한 경우 [[3.13. GPS 수신기 설정 및 테스트|GPS 수신기]]를 연결하는 것이 가장 정확하지만, 실내 등 GPS를 사용할 수 없는 환경에서는 DS3231 RTC 모듈을 사용

> [!tip] DB400, DB402 시리즈
> DB400, DB402는 자체 RTC가 정확하여 PC 시간 동기화만 하면 시간 오차 없이 유지됩니다. 다만 전원을 껐다 켜면 다시 시간 동기화가 필요합니다. 시계 기능이 중요한 경우 DB500, DB600, DB502와 DS3231 조합을 권장합니다.

## 2. 지원 펌웨어

- **v3.4.9 이상** 필요
- DBPS > 설정 > `펌웨어 정보 읽기`에서 버전 확인 가능

## 3. 연결 배선도

컨트롤러의 **RELAY 포트**를 이용하여 DS3231 모듈을 연결합니다.

| **DS3231 모듈** | **컨트롤러 연결 핀** |
| ------------- | ------------- |
| **GND**       | RELAY GND     |
| **VCC**       | RELAY 5V      |
| **SDA**       | RELAY D1      |
| **SCL**       | RELAY D2      |

> [!note] DB500, DB600, DB502 모두 동일한 배선입니다.

## 4. 보드 기능 설정

1. DBPS > 설정 > `보드 기능 설정` > `읽기`
2. **J4(4Pin) Function** 항목을 **DS1302**로 선택
3. `설정` > `닫기`

## 5. 시간 설정 및 확인

1. **최초 시간 설정**: DBPS > 설정 > `PC 시간 동기화`
2. **시간 확인**: DBPS > 설정 > `컨트롤러 시간읽기` 또는 [[2.8.1. ASCII 프로토콜 매뉴얼|ASCII 프로토콜]] `![0031!]`을 전송하여 응답으로 확인
3. **동작 확인**: 컨트롤러 전원 차단 후 전원 재공급 시, 리셋 없이 시간이 정상적으로 표시되는지 확인
