---

> [!abstract] Support for changing the BLE name and password of DB300WB has ended
> For a wireless connection, use the DBW320 wireless option board

> [!warning] End of support for BLE connection
> - **DB300WB · DB320WB are discontinued**
> - The BLE function was removed from the controller firmware
> - Support for the BLE menu of DabitOne has also ended. You can still see it in the version that you download now, but it will be removed in the next version
> - **For a wireless connection, use the DBW320 wireless option board** — [2.1.6. Using the DBW320 Wireless Option Board](https://docs.dabitsol.com/2.1.6) (Korean)
> - To change the settings of a DB300 that is already installed on site, use **DabitChe**, as before
