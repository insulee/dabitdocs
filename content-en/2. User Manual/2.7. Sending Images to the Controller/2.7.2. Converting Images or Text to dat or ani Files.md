---
title: 2.7.2. Converting Images or Text to dat or ani Files
---

> [!abstract] How to make images, text, and GIFs into LED display content files (.dat/.ani)
> DabitOne does not have a separate conversion menu. When you make content in the `콘텐츠 편집` (Content editing) window and `저장` (Save) it, the .dat (image) or .ani (moving image) file is made automatically.

> [!note] If you use the old DabitChe, see [[2.7.6. Sending Images from DabitChe]].

### Image (bmp/png/jpg) to a dat file

1. `편집` (Edit) tab > `콘텐츠 편집` (Content editing)
2. In the image row of `메인 블록` (Main block), `찾기` (Find) > select an image file (.bmp/.png/.jpg)
	- The image keeps its original size and is placed at the block position (X, Y). The part outside the block area (W, H) is cut
	- You can also load a .dat file that you made before in the same way
3. `저장` (Save) or `다른이름저장` (Save as) > the .dat file is made (default folder `Data\Image`)

> [!tip] Convert directly in the playlist
> In the playlist of the `편집` (Edit) tab, double-click `표시파일명` (Display file name), select `이미지` (Image), and then select a .bmp/.png/.jpg file. The program converts it to .dat automatically and adds it to the list.

### Text to a dat file

1. `편집` (Edit) tab > `콘텐츠 편집` (Content editing)
2. Enter text in `메인 블록` (Main block), and select the font, size, and color
3. `저장` (Save) or `다른이름저장` (Save as) > the .dat file is made

### GIF animation to an ani file

1. `편집` (Edit) tab > `콘텐츠 편집` (Content editing)
2. `GIF 찾기` (Find GIF) > select an image file (.gif)
3. `저장` (Save) or `다른이름저장` (Save as) > the file type changes to `ANI 파일 (*.ani)` (ANI file (*.ani)) automatically, and the file is saved (default folder `Data\Video`)
- To make or edit the GIF itself, see [[7.2. Built-in GIF Editor]]

### Select the color depth — 256 colors and 16-bit

- Select it in `색심도:` (Color depth:) at the top of the `콘텐츠 편집` (Content editing) window
	- `256색 (기본)` (256 colors (default)) — works on all controllers. **If you are not sure, keep this value**
	- `16비트 (16C 보드 전용)` (16-bit (16C boards only)) — shows correctly only on controllers that support 16-bit color (DB720 16-bit color option · DB725T/DB725U). Suitable for images with many colors, such as photos
- Moving images (.ani) are saved with 256 colors.

<!-- TODO: DabitOne screenshot — the color depth combo (256 colors/16-bit) at the top of the content editing window -->

> [!warning] Caution
> - If you send an image made in 16-bit to a normal (256-color) controller, the colors can look different. If you do not know the controller type, use `256색 (기본)` (256 colors (default)).

### Files that are saved together

- When you save a .dat/.ani file, a `.blocks.json` file with the same name is saved with it.
- You need it when you load the file again with `콘텐츠 편집` (Content editing) > `열기` (Open) to edit it. When you move the files to another PC, copy it too.

Put the saved .dat/.ani files into a playlist (.pla/.bgp) and send them in [[2.7.3. Making a Playlist]].
