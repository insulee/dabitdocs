> [!abstract] Server TCP/IP and UDP settings
> The detailed setup steps for Server TCP/IP and UDP connections in different network environments

### Communication types
- Dabit Solution LED display controllers and LAN-to-Serial converters support four communication types for different industrial environments and user requirements
-  Serial communication
	- Serial communication over TTL or RS232/485
	- Suitable for short-distance one-to-one communication
- Client TCP/IP (default setting)
	- The controller acts as the server, and the program (PC, PLC, server) acts as the client
	- The most common and stable communication type
	- For the detailed connection steps, see the documents below
		- [[2.1.1. Ethernet Communication Settings]]
		- [[2.1.2. LAN-to-Serial Converter Settings]]
- Server TCP/IP
	- The controller acts as the client
	- Use it when you build a central server system
- UDP
	- A connectionless protocol
	- Suitable when you need fast data transfer
### How to set up
#### Server TCP/IP settings
- Devices that support Server TCP/IP settings
	-  Controllers that support TCP/IP communication (DB500, DB520, DB600, DB720)
	- LAN-to-Serial converters
		- Ethernet version
		- Wi-Fi (station mode) version
- dbNet > `Search` in the common button row at the bottom (`Search`/`Set`/`Add`/`Reset`)
	- Select the MAC address of the controller or converter that you want to connect
	- Select Controller Client Mode (Server TCP/IP)
	- Enter Server IP and Server Port
	- `Set`
	- `Search` > check that the network information changed
	- `Add`
	- Select Server TCP/IP and check the information

- (Reference) When it does not connect
	- The server and the device (controller or converter) must have matching network information to connect
	- If they do not match, change IP Address (first 3 octets), Subnet Mask, Gateway, and Port to match the server


#### UDP settings
- Devices that support UDP settings
	- Controllers that support TCP/IP communication (DB500, DB520, DB600, DB720)
	- LAN-to-Serial converters
		- Ethernet version
		- Wi-Fi (station mode) version

- dbNet > `Search` in the common button row at the bottom (`Search`/`Set`/`Add`/`Reset`)
	- Select the MAC address of the controller or converter that you want to connect
	- Change IP Address (first 3 octets), Subnet Mask, Gateway, and Port to match the server
	- **(Important) Port: 5108 (Ethernet connection), 5107 (Wi-Fi connection)**
	- `Set`
	- `Search` > check that the network information changed
	- `Add`
	- Select UDP
		- IP Address: the `IP Address` of the controller or converter
		- IP Port: the `IP Port` of the controller or converter (Ethernet: `5108`, Wi-Fi: `5107`)
