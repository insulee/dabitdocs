title: 2.10.2. Board Function Settings

>[!abstract] How to set the board functions of the controller (port settings, sensor connections, and so on)

## Setting items

#### Debugging
- A setting for debugging the controller
- Default value: `Disable`

#### BH1 (10-pin) mode
- Sets the function of the BH1 port of the controller
- Default value: `TTL/RS485`
- **When you connect a discrete signal input board**: you must set the option that fits the use, one of `8Pin Input(HEX)`/`8Pin Input(BCD)`/`8Pin Input(Number)`/`8Pin Input(BIT BGSch)` - see [[3.8. Showing Playlists with the Discrete Signal Input Board]]
- Other options: `CAN`, `I2C`, `SPI`

#### Baud Rate settings
- Sets the communication speed of the BH1 (10-pin), J2 (RS232), and J3 (TTL) ports
- You can set each port separately
- (Reference) The DB402S sets the Baud Rate with DIP switches 1 and 2, so the Baud Rate value in these board settings does not apply

#### J4 (4-pin) mode
- Sets the function of the J4 port
- Default value: `Relay Out`
- Sensor connection options:
	- `CDS`: brightness sensor - see [[3.10. Connecting and Setting Up the Brightness Sensor]]
	- `DS3231`: RTC module - see [[3.12. Keeping Time with the RTC Module (DS3231)]]
	- `SHT31(DB502)`: temperature/humidity sensor - see [[3.28. Connecting and Showing a Temperature-Humidity Sensor]]
- Other options: `DHT22(ONLY NoLAN)`, `2Port Input`, `Relay Out & NoRTC`, `Relay 4Port`

#### RS485 address
- When the controller is connected by RS485, you can check the controller address
- Read-only item — you cannot edit it on this screen

## DabitOne

#### Open the board settings
- `고급` (Advanced) > `보드기능설정` (Board settings)

#### Read the current settings
1. Connect, and then click the `읽기` (Read) button
2. The values set in the controller now show in each item (they are empty at first)

#### Change and apply the settings
1. Select the options to change
2. Click the `전송` (Send) button
3. The settings are applied to the controller

## dbPS

#### Open the board settings window
- Select `설정` (Settings) > `보드기능설정` (Board settings)

#### Read the current settings
1. Connect, and then click the `읽기` (Read) button
2. The values set in the controller now show in each item
	- They are empty when you open the window for the first time

#### Change and apply the settings
1. Select the options to change
2. Click the `설정` (Set) button
3. The settings are applied to the controller

## Dabit Protocol Simulator

#### Open the board settings window
- Select `설정 및 제어` (Settings and control) > `보드기능설정` (Board settings)

#### Read the current settings

> [!warning] The values that show when you open the window for the first time are not the actual settings of the controller

1. Connect, and then select `읽기` (Read) in **2. Sub Command**
2. Click the `전송` (Send) button
3. The values set in the controller now show in each item

#### Change and apply the settings
1. Select `설정` (Set) in **2. Sub Command**
2. The option area at the bottom becomes active
3. Select the options to change
4. Click the `전송` (Send) button
5. The settings are applied to the controller
