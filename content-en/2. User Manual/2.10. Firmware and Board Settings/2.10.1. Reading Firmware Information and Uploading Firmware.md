title: 2.10.1. Reading Firmware Information and Uploading Firmware
---

>[!abstract] How to check the firmware information of the controller and update the firmware

> [!warning] Before you upload — check the model, the identification, and the file name (official release V4.5.4)
> - **From V4.5.4, all models are 256-color.** There is no 8-color (08C) edition. For lamp-type panels (display types P3~P7), the firmware shows 8 colors
> - **DB400 · DB402 boards shipped earlier** (boards with secure boot on) accept only the files whose names end with `_legacy_v1` (DB400) · `_legacy_v2` (DB402) (these files are also V4.5.4 · 256-color). Identify the board by the `secure` value in the `![00NK!]` response — `v1` → `_legacy_v1`, `v2` → `_legacy_v2`, `none` → the standard file with no suffix. Do not decide by the letters (`c` · `d`) in the variant name. For an old board with no `secure` value, contact us before you upload. Do not upload a standard file to these boards
> - **DB502 boards shipped earlier**: keep using V4.0.3. Newly shipped DB502 boards use the standard file
> - Before you upload, check the current model · variant string · screen size with `펌웨어 읽기` (Read Firmware) (`![0081!]`) — see [[3.21. Reading Controller Firmware Information]]

### Which file to use (V4.5.4 or later)

- Use the file with **the same name** as the variant string in the `![0081!]` response (for example: `DIBD720U_08B_08R014C`). How to read the file name: `DIBD720U_08B_08R014C_V4.5.4.bin` = DB720 · U variant · 256-color · up to 8 rows and 14 columns
- **The number of columns in the file name is the maximum number of columns of that variant.** If a screen was saved wider than that in an earlier version, after you upload this version, **it is reduced to the maximum number of columns at boot, and that value is fixed at the next save** (for example: DB500 · DB600 S 2 rows 20 columns → 16 columns, DB600 U 8 rows 10 columns → 8 columns). For a DB600 site that needs 4 rows and 16 columns, use `DIBD600T`
- Variants not in V4.5.4: `DIBD520T` · `DIBD520U` · `DIBD600V` · `DIBD720S`. The DB520 is for direct connection only (the DBS540 hub is for the DB720 only)
- The firmware for the DB720 16-bit color option (`DIBD725T_16C_04R016C` · `DIBD725U_16C_08R012C`) is not in the public downloads. If you need to change the firmware of these boards, contact dabit@dabitsol.com
- For the maximum screen of each model, see [[3.2. Maximum Modules per Controller]]

### Check after the upload

- Check that the version shows `4.5.4 2026-10-14`. For ESP models (DB400 · DB402 · DB502 · DB520 · DB720), check **after 1 minute, when the new version is confirmed**
- If the update fails in DabitOne, increase **the response wait time to 3~5 seconds** (1 second is too short)
- **The LAN MAC changes to the company MAC (`54:FF:82…`)** (DB400 · DB402 · DB502 · DB520 · DB720). If a site reserves the IP by MAC on the router or binds the MAC in the ARP table, register it again — see [[2.1.1. Ethernet Communication Settings]]
- On the DB520 · DB720, **the board web interface is uploaded separately from the firmware**. Read the web interface version with `![00W5!]` — see [[2.11.1. Web Interface User Manual]]

### OTA safety functions (V4.5.4 or later · DB400 · DB402 · DB502 · DB520 · DB720)

- **Automatic rollback**: if the new version uploaded by OTA restarts abnormally 3 times in a row within 60 seconds of boot, the board goes back to the previous version by itself and boots it. If it works normally for 60 seconds, the new version is confirmed
- **Two-slot read · switch**: read the versions in the two slots of the board with `![00U4!]`, and select one with `![00U4 0!]` · `![00U4 1!]` to boot it (reboot)
- **「저장만」 (Save only) OTA**: the board receives and verifies the new version, but keeps running the current version. Run the new version later with a switch. If the current version is not confirmed yet, it is rejected
- OTA rejects a firmware file that does not match (a file for a different model or a different flashing generation)

### DabitOne

#### Open the firmware update
- `고급` (Advanced) > `펌웨어 업데이트` (Firmware Update)

#### Check the firmware information
1. Connect, and then click the `펌웨어 읽기` (Read Firmware) button
2. The current firmware information shows in the **컨트롤러 펌웨어 정보** (Controller firmware information) area

#### Upload the firmware
1. Click the `열기` (Open) button
2. Select the firmware file (.bin) to upload in the firmware folder
3. Check the selected firmware information in the **펌웨어 파일 정보** (Firmware file information) area
4. Click the `전송` (Send) button
5. The firmware upload runs and completes

> [!note] Legacy program paths
> Below is how to do the same work in dbPS · Dabit Protocol Simulator · DabitChe. The names of the menus, buttons, and information areas are different in each program.

### dbPS (DBPS)

#### Open the firmware upload window
- Select `설정` (Settings) > `펌웨어 업로드` (Firmware upload)

#### Check the firmware information
1. Connect, and then click the `펌웨어 읽기` (Read Firmware) button
2. The current firmware information shows in the **컨트롤러 펌웨어 정보** (Controller firmware information) area

#### Upload the firmware
1. Click the `불러오기` (Load) button
2. Select the firmware file (.bin) to upload in the firmware folder
3. Check the selected firmware information in the **업로드 펌웨어 정보** (Upload firmware information) area
4. Click the `파일 전송` (Send file) button
5. The firmware upload runs and completes
