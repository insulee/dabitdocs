> [!abstract] How to change fonts, add a font group, and use the added fonts

### Change fonts and add a font group

#### Where to send fonts

##### DabitOne
- `설정` (Settings) > `폰트전송` (Font transfer)

##### DBPS
- `설정` (Settings) > `폰트 전송` (Font transfer)

#### How to add a font group

- In DabitOne
	- `폰트그룹 1` (Font group 1) is selected by default (you cannot clear it)
		- `영어` (English) > `···` > `ENG 08x16-DABIT(표준).fnt` > `열기` (Open)
		- `한글조합형` (Hangul combination type) > `···` > `KOR 16x16-DABIT(표준).fnt` > `열기` (Open)
		- `사용자폰트` (User font) > `···` > `USER 16x16-Special(표준).fnt` > `열기` (Open)
	- `폰트파일 전송` (Send font file)

> [!info] For font groups and the drop-down options, see below.
> Font groups: [[2.4.2. Font Options#Font groups]]
> 8x16/16x16: [[2.4.2. Font Options#Font options]]
> Hangul combination type: [[2.4.2. Font Options#Hangul combination type]]


### Use the applied fonts

#### HEX protocol
- Character encoding/font: `EUC-KR/한글조합형` (EUC-KR/Hangul combination type)
- Font size: `16픽셀` (16 pixels), font group: `폰트그룹1` (Font group 1)


#### ASCII protocol
- `/F0003/T0` (`/T0` = font group 1)
- When you send from the DabitChe app, insert the `/F0203` packet and send the text encoded in UTF-8

> [!info] To use special characters, custom characters, and so on, see [[2.4.3. Entering User Fonts]]
