title: 3.21. Reading Controller Firmware Information
---

> [!abstract] How to read the firmware information of Dabit Solution controllers
> The firmware information of a Dabit controller is important data when you check the controller state, find faults, and upgrade the firmware. This document tells how to read and interpret the firmware information of Dabit Solution controllers

#### How to read the firmware information

- Use one of the methods below to check the firmware information
	1. DabitOne
	    - `고급` (Advanced) > `펌웨어 업데이트` (Firmware Update) > `펌웨어 읽기` (Read Firmware)
	2. DabitChe (legacy)
	    - DabitChe program > in the menu, `정보 > 버전 읽기` (Info > Read Version)
	3. DABIT Protocol Simulator (DBPS, legacy)
	    - DBPS > `Setting > FirmwareUpload > Read FW`
	4. Send the ASCII or hex protocol
	    - ASCII protocol: `![0081!]`
	    - Hex code: `10 02 00 00 02 6F F1 10 03`

> [!tip] New controllers (firmware V3.6.0 or later) can read the model, version, color capability, and screen size at one time as JSON with the ASCII command `![00NK!]` — see [[2.9.2. New and Legacy Command Mapping Table]]. For DB400 · DB402 with the official V4.5.4 or later, the `secure` value (v1/v2/none) in this response decides the legacy firmware file — see [[2.10.1. Reading Firmware Information and Uploading Firmware]]

#### Example: interpreting the firmware information

```
<32> DIBD600T_08C_04R020C V3.0.6 2024-12-13 
02x006-L0-F0U0-D1-S4P05_0_E1-blV0
R-180MHz-16D_D1S11_11-C0-G-W 
mac:54-ff-82-01-2d-c3 ip:192.168.000.201 port:05000 
Addr:00-115200bps
```

> [!tip] On DB720 (official V4.5.4), the hub mode state is added at the end of the response in the form `HB=a1s1`
> The fields before it keep the same order and form. A firmware version that does not use the hub mode shows `HB=-` — see [[3.33. DBS540 Hub Connection Guide]]

| **Item**                  | **Description and options**                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------ |
| `<32>`                  | Firmware type number                                                                            |
| `DIBD600T`              | Model name of the controller                                                                        |
| `08C`                   | Display colors<br>`08C`: 8 colors, `08B`: 256 colors, `16C`: 65,536 colors, `02B`: 3 colors<br>From the official V4.5.4, all models are `08B` (256 colors). Only the DB720 16-bit color option (`DIBD725T` · `DIBD725U`) is `16C`                       |
| `04R020C`               | Maximum display screen size<br>`4` rows (vertical), `20` columns (horizontal)                                                     |
| `V3.0.6`                | Firmware version                                                                               |
| `2024-12-13`            | Firmware build date                                                                            |
| `02x006`                | Screen size that is set now<br>`2` rows (vertical), `6` columns (horizontal)                                                     |
| `L0`                    | Module layout<br>`L0`: horizontal, `L1`: vertical (1 row), `L2`: vertical (2 rows), <br>`L3`: double-sided horizontal, `L4`: double-sided vertical  |
| `F0U0`                  | External memory state<br>`F`: flash ROM, `S`: SD memory, `U`: USB memory<br>`0`: not connected, `1`: connected          |
| `D1`                    | Debugging mode value<br>`0`: Disable, `1`: Enable1 ..... `8`: Enable8                            |
| `S4`                    | Number of sections<br>You can split the screen into up to `4` sections                                                              |
| `P05`                   | Number of page messages that are set<br>`5` page messages are registered                                                     |
| `0`                     | Storage location of page messages<br>`0`: Flash ROM, `1`: RAM                                            |
| `E1`                    | Real-time message setting<br>`E0`: the effects of all sections start at the same time, `E1`: the effect of each section starts separately                               |
| `blV0`                  | Bootloader version<br>`blV0`: bootloader V8.0, `blV1`: bootloader V3.0.0                                    |
| `R`                     | Firmware mode<br>`R`: Release mode, `D`: Debugging mode                                         |
| `180MHz`                | CPU clock frequency                                                                           |
| `16D_D1S11_11`          | Display signal setting value                                                                            |
| `C0`                    | Brightness sensor state<br>`C0`: manual mode, `C1`: auto mode                                                 |
| `G W`                   | Applied options<br>`G`: GPS, `W`: Watchdog Reset, `B`: Bluetooth (shown only in earlier firmware), <br>`M`: Modbus (used in earlier firmware), `K`: encryption ROM applied |
| `mac:54-ff-82-01-2d-c3` | MAC address                                                                               |
| `ip:192.168.000.201`    | IP address that is set                                                                            |
| `port:05000`            | Port number that is set                                                                            |
| `Addr:00`               | RS485 communication address                                                                          |
| `115200bps`             | RS485 baud rate                                                                          |
| `HB=a1s1`               | Hub mode state (DB720 · official V4.5.4)<br>`a`: the value applied now, `s`: the saved value<br>`0`: direct connection, `1`: through the DBS540 hub<br>A firmware version without the hub mode shows `HB=-`  |
| `SB=1`                  | Boot-loop self-recovery flag (firmware **V4.5.4 or later** · DB400·DB402·DB502·DB520·DB720)<br>If the saved settings make the controller reboot 3 times in a row right after boot, the next boot shows the screen at the minimum size to keep LAN access (the settings are kept)  |

> [!note] Color notation of the 8-color ↔ 256-color switchable firmware (V3.8.3 ~ V4.4.0)
> Some versions stay at `08C` even after you change to 256 colors with a command, so this notation can differ from the actual mode. Check the current color mode with `![00H3!]`. **From the official V4.5.4, all models use 256 colors (`08B`)**, and there is no switch command — see [[7.5. Color Mode Switching]]
