
> [!abstract] RS485보드의 연결도와 컨트롤러 연결 방법 안내
#### RS485 보드 연결 방식
- 아래와 같이 USB to RS485 컨버터를 이용해 RS485 보드(DB230-RS485-DIPSW5P)와 연결
- 다중연결시 동일한 포트로 계속 이어가고, 딥스위치로 주소를 다르게 설정
	- RS485연결시 잡음(Noise)과 전자파 간섭(EMI: Electro-Magnetic Interference)을 줄이기 위해 **꼬임쌍선(Twisted Pair) 케이블**로 구성하는 것을 권장
	- ![[rs485_1.png]]

#### 컨트롤러 연결
- (중요) RS485 연결시 컨트롤러의 **JP3는 3.3V**로 단락
- `BH1(10핀) 모드`는 컨트롤러 **기본값이 `TTL/RS485`** — 보통은 별도 설정 없이 바로 연결됨
- 컨트롤러에 별도로 부착한 RS485의 딥스위치 통해서 총 31개의 주소로 설정 가능

> [!tip] 연결이 안 될 때 — BH1 모드 확인
> BH1 모드가 다른 값(예: 접점보드용 `8Pin Input`)으로 바뀌어 있으면 RS485 연결이 되지 않습니다.
> 1. 다른 통신 방법(RS232, TTL, 이더넷 등)으로 컨트롤러에 먼저 연결
> 2. `고급` > `보드기능설정` > `읽기`
> 3. `BH1(10핀) 모드`가 `TTL/RS485`인지 확인 — 아니면 `TTL/RS485` 선택 후 `전송`
>
> DBPS에서는 `보드 기능 설정` > `BH1(TTL/RS485) Function`에서 동일하게 확인
- 딥스위치 주소가 01번 일 때, RS-485 Address 설정
	- DabitOne: `통신` > `Serial` > `RS-485 Address` : `1`
	- DBPS: `통신 설정` > `Serial` > `RS-485 Address` : `DABIT 01`

#### (참고) RS485 Address
- RS485 보드는 5개의 딥스위치로 0부터 31까지 총 32개의 Address 설정 가능
- 신제품 DB520·DB720도 동일하게 별도 RS485 보드를 부착해 딥스위치로 주소 설정 (내장 딥스위치 방식인 DB402 제외)
- DB402S 컨트롤러는 내장된 8개의 딥스위치로 설정 가능[^2]
	- 1, 2번: 통신속도 설정
	- 4\~8번: RS485 Address 설정 (0부터 31까지 총 32개)
- 구형 DB501/DB600 컨트롤러는 내장된 4개의 스위치(5\~8번[^1])로 0부터 15까지 총 16개의 Address 설정 가능
