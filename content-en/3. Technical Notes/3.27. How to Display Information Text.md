> [!abstract] How to display information text
> How to display information text with the ASCII protocol and in DabitOne (DabitChe)

#### ASCII protocol
- Use protocol codes in the `/ixx` form to show various information text, such as the date, time, temperature/humidity, and fine dust level
- Choose the display content from the code table, and mix it with other ASCII protocol codes (section 2.1 of [[2.8.1. ASCII Protocol Manual]])
- Temperature/humidity and fine dust need separate firmware

#### Information text settings

##### Synchronizing the PC time
- To show the correct date and time, first send the PC time to the controller
	- DabitOne: `고급` (Advanced) > `시간설정` (Time settings) > `PC 시간 전송` (Send PC time)
	- DabitChe: `컨트롤러 접속` (Connect to controller) > `PC시간으로 동기화` (Sync with PC time)

##### Opening the information text settings
- DabitOne: `고급` (Advanced) > `정보문구설정` (Information text settings)
- DabitChe: `표시파일작성` (Create display file) > `정보문구설정` (Information text settings)

##### Common settings
- Split the information text into up to 4 sections
	- Enter the 4 fields `X시작`/`X종료`/`Y시작`/`Y종료` (X start/X end/Y start/Y end, in px) to set the position and range of each section
	- From DB500S v3.0.8, only 2 sections are supported (for 4 sections, make a separate request)
- The default font size is 16. Set the font size to show the text correctly
- Choose the display content from the code table
- You can choose the code color from 8 colors ([[2.2.2. Bits per Pixel]])
- `Clear`: deletes all information text
- `초기값 Load` (Load defaults): applies the default values that include year-month-day and hour:minute:second

#### Example
- 2 rows × 6 columns (96x32 pixels)

2. 정보문구설정 (Information text settings), DabitOne / DabitChe
	- You can enter up to 6 items in one section
	- Row 2 of the example has 7 items in total, as below
		- `AM/PM`, `'' Space`, `24H-HH`, `':' On`, `NN`, `':' On`, `SS`
		- Only the 6 items from `AM/PM` to `':' On` can be entered
	- So set the position of section 3 to X시작 (X start): `72` and Y시작 (Y start): `16`, then enter `SS`
