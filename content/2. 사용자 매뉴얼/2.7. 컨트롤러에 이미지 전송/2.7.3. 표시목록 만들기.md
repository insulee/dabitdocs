
> [!abstract] 콘텐츠 파일(.dat/.ani)을 표시목록(.pla/.bgp)으로 묶어 컨트롤러에 전송하는 방법 안내
> `편집` 탭에서 표시목록 작성 > `저장` > `전송` 버튼 한 번으로 컨트롤러에 올라갑니다.

> [!note] 구버전 다빛채 사용자는 [[2.7.6. 다빛채에서 이미지 전송]]을 참고하세요.

### 표시목록 작성

1. `편집` 탭 > `새표시목록`
2. `추가`로 항목(행) 추가. `삭제`, `↑`/`↓`(순서 이동), `복제`로 목록 정리
3. 항목 내용 채우기 — 두 가지 방법
	- 행 오른쪽 `편집` 버튼 > `콘텐츠 편집` 창에서 문구·이미지를 만들고 `표시파일에 적용`
	- `표시파일명` 더블클릭 > 파일 종류 선택(`이미지`/`동영상 (GIF)`/`페이지문구`)
		- `이미지`: .dat 또는 .bmp/.png/.jpg/.jpeg 선택 (일반 이미지는 자동으로 .dat 변환 — [[7.6. 이미지 자동 DAT 변환]])
		- `동영상 (GIF)`: .ani 파일 선택
		- `페이지문구`: 파일 선택 없이 선택 즉시 항목에 등록
4. 화면 아래 `표시파일 보기`에서 표출 모습 미리 보기 — 전송 전 점검 상세는 [[7.1. 미리보기와 전광판 화면]]
- 이미지(.dat)와 동영상(.ani)을 한 목록에 섞어 넣을 수 있습니다

### 저장 — pla와 bgp

- `저장` 또는 `다른이름저장` > 파일 형식 선택 (기본 폴더 `Data\Playlist`)
	- 메인스케줄: `스케줄 파일 (*.pla)` — 컨트롤러가 항목을 효과·속도·유지시간대로 **순서대로 자동 표출**
	- 배경이미지: `배경 파일 (*.bgp)` — 컨트롤러 메모리에 담아 두고 **번호로 골라서 표출**
- 마지막에 연 표시목록은 프로그램을 다시 시작해도 자동 복원됩니다.

### 전송

1. `편집` 탭 > `전송`
	- 저장하지 않은 목록이면 저장 확인 창이 먼저 표시됩니다. 저장한 확장자(.pla/.bgp)에 따라 전송 방식이 정해집니다.
2. 전송 전 자동 검사 — 참조한 .dat/.ani 파일이 없거나 전광판보다 큰 이미지가 있으면 안내 창이 뜨고 전송을 중단합니다
3. 연결되어 있지 않으면 현재 통신 설정으로 자동 연결
4. 진행률 창이 표시되고 `취소`할 수 있습니다. 완료되면 "전송 완료" 알림이 표시됩니다.
