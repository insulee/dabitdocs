> [!abstract] Message types
> Features of real-time (urgent) messages and page (normal) messages, and how they differ 

#### Real-time messages

1. Features:
    - Shows data that changes often, at once
    - Saved temporarily in RAM. The data is deleted when the power goes off
    - Has high priority: if a real-time message comes while a page message shows, it shows at once
    - Used mainly to show urgent information or to update real-time data
2. Example:
    - ASCII packet: `![000/P0000/실시간메시지!]` (the text means "real-time message")
    - `000`: a real-time message packet
3. Advantages:
    - Immediate response
    - Good for one-time messages
    - Fast processing

#### Page messages

1. Features:
    - Shows text that rarely changes, such as guidance, promotions, and cautions, page by page, repeating without end
    - Saved in flash memory, so the data stays when the power goes off
    - Flash memory can be damaged after about 100,000 writes, so send messages that change in real time as real-time messages
    - Register up to 10 messages in advance
2. Example:
    - ASCII packet: `![001/P0100/페이지메시지!]` (the text means "page message")
    - `001`: a page message packet
    - `P0000`: page message 1, `P0100`: page message 2 ... `P0900`: page message 10
3. Advantages:
    - The data stays when the power goes off
    - Good for ongoing guidance text or ads
    - Reduces the system load
4. **Caution**
	- To make sure that the display is correct, always send protocol packets one at a time. Check the response from the controller before you send the next packet (we recommend an interval of at least 200ms)

> [!warning] Page messages and flash memory life
> Page messages are saved in flash memory (ROM). Flash memory can be damaged after about 100,000 writes, so **do not use page messages for data that changes often (parking counts, sensor values, live counts, and so on).**
> - Example: an update every 10 seconds is about 8,640 writes per day → about 100,000 writes in about 12 days
> - For data that changes often, always use **real-time messages (000 packets)**. Real-time messages are saved in RAM, so there is no limit on the number of writes.

#### Main differences

| Item       | Real-time message                    | Page message                    |
| -------- | -------------------------- | -------------------------- |
| Storage    | RAM (volatile memory)              | Flash memory (non-volatile)             |
| Display priority | Shows before page messages            | Real-time messages show first              |
| Use       | Urgent data, shown at once          | Repeated display of regular guidance, ads, and so on         |
| Data retention   | Data is lost at power OFF            | Data stays at power OFF          |
| Response speed    | Fast, because it is saved in RAM        | A little slower, because it must be written to flash memory |
| Example uses    | Real-time data such as license plates and urgent warnings | Parking guidance, ad text, static information    |

#### Recommended uses

- Real-time messages: emergencies (example: no entry), dynamic data (example: free parking spaces, license plates)
- Page messages: fixed guidance text (example: Welcome) and repeated ad messages

#### How to send in DabitOne
1. Real-time message
	- HEX protocol 
		- `메시지종류` (Message type) > `실시간` (Real-time)
		- Enter the text color and the text, then send
	- ASCII protocol
		- `![000/P0000/실시간메시지!]`
2. Page message
	- 전송 (Send) > 페이지메시지 (Page message) > select `1`~`10` in the 페이지 수 (Page count) combo > `전송` (Send)
	- HEX protocol
		- `메시지종류` (Message type) > `페이지` (Page) > select in the page number combo
		- Enter the text color and the text, then send
	- ASCII protocol
		- `![001/P0100/페이지메시지!]`

#### How to send in DBPS
1. Real-time message
	- HEX protocol 
		- `Msg Type` > `RealTimeMsg`
		- Enter the text color and the text, then click Send
	- ASCII protocol
		- `![000/P0000/실시간메시지!]`
2. Page message
	- `Setting` > `Page Msg settings` > `SetTotalCount` > `**개` (number of pages) > `Send` > `Close`
	- HEX protocol
		- `Msg Type` > `Page Msg` > page > `**번` (page number)
		- Enter the text color and the text, then click Send
	- ASCII protocol
		- `![001/P0100/페이지메시지!]`
