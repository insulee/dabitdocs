
>[!abstract] 컨트롤러의 펌웨어 정보 확인 및 업데이트 방법 안내

> [!warning] 기종에 맞는 펌웨어인지 먼저 확인하십시오
> - **DB400 · DB402 · DB502**는 **V4.0.3(안전버전)까지만** 지원합니다. V4.1 이후 판본은 호환되지 않고, 한 번 올리면 **되돌릴 수 없습니다**
> - **DB500 · DB600 · DB520 · DB720**은 이런 제약이 없습니다
> - 올리기 전에 `펌웨어 읽기`로 현재 기종과 버전을 확인하십시오 — [[3.21. 컨트롤러 펌웨어 정보 해석]] 참고

### DabitOne

#### 펌웨어 업데이트 진입
- `고급` > `펌웨어 업데이트`

#### 펌웨어 정보 확인
1. 통신 연결 후 `펌웨어 읽기` 버튼 클릭
2. **컨트롤러 펌웨어 정보** 영역에 현재 펌웨어 정보 표시

#### 펌웨어 업로드
1. `열기` 버튼 클릭
2. 펌웨어 폴더에서 업로드할 펌웨어 파일(.bin) 선택
3. **펌웨어 파일 정보** 영역에 선택한 펌웨어 정보 확인
4. `전송` 버튼 클릭
5. 펌웨어 업로드 진행 및 완료

> [!note] 레거시 프로그램 경로
> 아래는 dbPS·다빛프로토콜시뮬레이터·다빛채에서 같은 작업을 하는 방법입니다. 메뉴·버튼·정보영역 명칭이 프로그램마다 다릅니다.

### dbPS(DBPS)

#### 펌웨어 업로드 창 열기
- `설정` > `펌웨어 업로드` 선택

#### 펌웨어 정보 확인
1. 통신 연결 후 `펌웨어 읽기` 버튼 클릭
2. **컨트롤러 펌웨어 정보** 영역에 현재 펌웨어 정보 표시

#### 펌웨어 업로드
1. `불러오기` 버튼 클릭
2. 펌웨어 폴더에서 업로드할 펌웨어 파일(.bin) 선택
3. **업로드 펌웨어 정보** 영역에 선택한 펌웨어 정보 확인
4. `파일 전송` 버튼 클릭
5. 펌웨어 업로드 진행 및 완료

### 다빛프로토콜시뮬레이터

#### 펌웨어 업그레이드 창 열기
- `설정 및 제어` > `펌웨어 업그레이드` 선택

#### 펌웨어 정보 확인
1. 통신 연결 후 `읽기` 버튼 클릭
2. **Controller firmware information** 영역에 현재 펌웨어 정보 표시

#### 펌웨어 업로드
1. `열기` 버튼 클릭
2. 펌웨어 폴더에서 업로드할 펌웨어 파일(.bin) 선택
3. **Firmware file information to be updated** 영역에 선택한 펌웨어 정보 확인
4. `전송` 버튼 클릭
5. 펌웨어 업로드 진행 및 완료
