DABIT SOLUTION
LED MODULE

LED module — pixels and character size

One pixel = RGB LEDs

One pixel is a set of Red·Green·Blue LEDs. Mixing the three colors makes the color of each pixel.

Character size

1 Korean character = 16 × 16 pixels. Digits and Latin letters are 8 × 16, half the width, so 2 of them fit in the space of one Korean character.

A pixel is one set of RGB LEDs. A Korean character takes 16×16 pixels, and a digit takes 8×16 pixels.
08
DABIT SOLUTION
PIXEL PITCH

Pitch — the distance between pixels

Pitch = the distance between the centers of adjacent pixels (mm). The P number in the model name is the pitch — P3, P4, P6, P8, P10. The wider the pitch, the larger the module for the same number of pixels.

P6
Module size (16 × pitch)
96 × 96 mm

DABIT SOLUTION
PITCH & CAPACITY

Same size, different number of characters

Even when the sign is the same size, a narrower pitch puts more pixels in it — so it can show more characters.

P8 32 × 16 pixels · 2 characters per line
2 characters
P4 64 × 32 pixels · 8 characters on two lines
8 characters
The two modules are exactly the same size — only the number of pixels in them is different
One Korean character fits in 16 pixels × 16 pixels. With a wider pitch (pixel spacing), that one character takes a larger area. On P8 (8mm), one character is 128 × 128mm. On P4 (4mm), it is 64 × 64mm.
Even with modules of the same size, a narrower pitch holds more information.

THREE WAYS

3 ways to integrate

Method Description
Direct protocol transmission The system sends packets
Discrete signals (PLC) Pin signals call saved screens
Direct sensor connection The controller shows sensor values directly

📤 Direct protocol transmission

The method from Part 3. A server or PC makes and sends packets.

Just turn on a pin, and a saved screen appears. No code is needed.

📟 Direct sensor connection

The controller reads sensor values and shows them directly. No external system is needed.

RELAY OUTPUT

Relay output

The LED display does not only receive. It can also turn external devices on and off.

🚨 Warning light and speaker control

Connect a relay to J4 of the controller to control a warning light or speaker.

📤 With one packet line

One packet line can turn a device on, turn it off, or turn it on for a few seconds.

🔗 Together with the display

For example, show an enforcement message and turn on the warning light at the same time.

An LED display both receives and sends — screen display + device control.
