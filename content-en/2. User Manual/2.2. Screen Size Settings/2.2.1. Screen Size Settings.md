>[!abstract] How to set the LED display size in DabitOne

### Where to set the LED display size

#### DabitOne
- `설정` (Settings) > `전광판 화면 구성` (LED display screen configuration)

#### DBPS
- `설정` (Settings) > `전광판 화면 구성` (LED display screen configuration)

#### DabitChe
- `환경설정` (Preferences) > `화면설정` (Screen settings)


### How to set the LED display size
- Height: `the height in modules` (x 16 pixels)
- Width: `the width in modules` (x 16 pixels)
- Layout: `가로형` (Horizontal)
- BPP: `3BPP (8색)` (3BPP (8 colors)) — to use 256-color content on a 256-color edition (all models, V4.5.4 or later), use `8BPP (256색)` (8BPP (256 colors))
- `전송` (Send)

> [!warning] From firmware V4.5.4, the number of columns is fixed to the column limit of the firmware file
> Even if you reduce the number of rows, you cannot increase the number of columns above the limit (for example: DB520S 32 columns, DB720T 32 columns, DB720U 14 columns, DB500S · DB600T 16 columns). For the limit of each model, see [[3.2. Maximum Modules per Controller]]. Before you update, see the cautions in [[2.10.1. Reading Firmware Information and Uploading Firmware]]

> [!info] For the options, see [[2.2.2. Bits per Pixel]] and [[2.6.2. LED Module Layout]]

> [!tip] New controllers (firmware V3.6.0 or later) can read the current screen size **in pixels** with the ASCII command `![00H0!]` — see [[2.9.2. New and Legacy Command Mapping Table]]
