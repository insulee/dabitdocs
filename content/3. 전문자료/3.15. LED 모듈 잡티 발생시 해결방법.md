
> [!abstract] 다빛채에서 업로드한 내용 중 LED 모듈 색상이 이상하게 표시될 때 해결 방법
> 

## 문제 증상

PC에서 다빛채로 LED 모듈에 문구를 업로드 했을 때 **색상이 의도와 다르게 표시**되는 경우 (예: 노란색이어야 하는데 빨강/초록색 점이 섞여서 나옴)

![[LED잡티_3.jpg|300]]

## 해결 방법

### 1단계: Windows 설정 변경
1. 내 PC > 속성 > 고급 시스템 설정
2. 시스템 속성
   - `고급` > 성능 > `설정`
     - ![[LED잡티_1.png]]
3. 성능 옵션 > `시각 효과` > `최적 성능으로 조정`
     - ![[LED잡티_2.png]]
4. `확인` 버튼 클릭

### 2단계: 문구 다시 만들어서 업로드 (중요!)

> [!warning] 중요
> 설정만 바꾸면 잡티가 사라지는 것이 **아닙니다**!  
> 이미 LED 컨트롤러에 업로드된 파일은 잡티가 있는 상태입니다.

1. **다빛채 프로그램**을 다시 실행
2. 문구를 **다시 작성**
3. 표시파일을 **새로 생성**
4. LED 모듈에 **다시 업로드**

## 왜 이렇게 하나요?

Windows의 화면 효과(글자를 부드럽게 보이게 하는 기능)가 켜져 있으면, 다빛채에서 만드는 표시파일에 불필요한 점들이 포함됩니다.

**Windows 설정을 바꾼 후 파일을 새로 만들어야** 깔끔한 표시파일이 생성되어 LED에 잡티 없이 표출됩니다.

> [!tip] 참고
> - 이 설정은 PC 화면 표시 방식만 바꾸는 것으로, 다른 프로그램 사용에는 문제가 없습니다.
> - LED 문구를 만들 때마다 이 설정이 유지되어야 잡티가 발생하지 않습니다.
