title: 3.13. Setting Up and Testing a GPS Receiver
---

> [!Abstract] GPS reception test
> - How to set the GPS baud rate
> - How to test GPS operation

#### GPS baud rate settings (DB500S/DB600 series/DB502S/DB520 series/DB720 series)

- Dabit Solution sells GPS receivers in 2 versions: RS232 and TTL
- In the board settings, set the J2(RS232) speed or the J3(TTL) speed to 9600

##### DabitOne
- `고급` (Advanced) > `보드기능설정` (Board settings)
	- `읽기` (Read)
	- `J2(RS232) 속도` (J2 (RS232) speed) or `J3(TTL) 속도` (J3 (TTL) speed): `9600`
	- `전송` (Send)

##### DBPS
- `설정` (Settings) > `보드 기능 설정` (Board settings)
	- `읽기` (Read)
	- J2(RS232) Baudrate or J3(TTL) Baudrate: `9600`
	- `설정` (Set)
	- `닫기` (Close)

#### GPS operation test
- Install the GPS receiver in an open place with a clear view of the sky, so that it receives the satellite signals well
- Connect the GPS receiver and the controller
	- DB300 + DB502S
		- Connect the GPS receiver and the DB502S through TTL/RS232
		- Connect the DB300 and the DB502 through BH1
		- Supply power to the DB502
	- DB500S/DB600 series/DB520 series/DB720 series
		- Connect the GPS receiver and the controller through TTL/RS232
		- Supply power to the controller
- Make sure that the TX lamp of the controller's RS232 or TTL blinks regularly
- When reading the controller time shows the current time correctly, the GPS receiver is connected correctly

##### DabitOne
- `고급` (Advanced) > `시간설정` (Time settings) > `컨트롤러 시간 읽기` (Read controller time)

##### DBPS
- `설정` (Settings) > `컨트롤러 시간읽기` (Read controller time)
