---
title: 2.1.5. BLE (Bluetooth Low Energy) Communication Settings
---

> [!abstract] BLE (Bluetooth) connection is no longer supported
> For a wireless connection, use the DBW320 wireless option board

> [!warning] End of BLE connection support
> - BLE was removed from the controller firmware
> - Support for the BLE settings window in DabitOne has also ended. The version you can download now still shows it. The next version removes it
> - **For a wireless connection, use the DBW320 wireless option board** — [2.1.6. Using the DBW320 Wireless Option Board](https://docs.dabitsol.com/2.1.6) (Korean)
> - To change the settings of a DB300 that is already installed on site, use **DabitChe** as before
