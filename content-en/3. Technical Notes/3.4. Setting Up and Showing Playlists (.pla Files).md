>[!abstract] How to make a playlist file and show it on the LED modules
>When you upload a .pla file to the controller, it always shows in the order and with the attributes of the playlist, even after a power reset

#### How to make and send a playlist

DabitOne and DabitChe use the same steps. Each document shows the menu paths of both programs side by side.

1. [2.7.1. Making Images](https://docs.dabitsol.com/2.7.1) (Korean): make the image that you want with a paint program and save it as a bmp, jpg, or gif file
2. [2.7.2. Converting Images or Text to dat or ani Files](https://docs.dabitsol.com/2.7.2) (Korean): convert it to a dat or ani file to load the image into the program
3. [2.7.3. Making a Playlist](https://docs.dabitsol.com/2.7.3) (Korean): save the dat or ani files as a playlist file (.pla) and upload it to the controller
