## 1. Text color and text background color
``` sql
![000/C1가/C2나/C3다/C4라/C5마/C6바/C7사/C1/G2AB/C3/G4CD/C5/G6EF!]
```

- ![[ascii_ex1.png]]
- `/Cx`: text color
- `/Gx`: text background color
- `![000/C1가/C2나/C3다/C4라/C5마/C6바/C7사/C1/G2AB/C3/G4CD/C5/G6EF!]`
	- `000`: single mode, no BCC check, real-time message
	- `/C1가`: red text, 가
	- `/C2나`: green text, 나
	- `/C3다`: yellow text, 다
	- `/C4라`: blue text, 라
	- `/C5마`: magenta text, 마
	- `/C6바`: cyan text, 바
	- `/C7사`: white text, 사
	- `/C1/G2AB`: red text/green background, AB
	- `/C3/G4CD`: yellow text/blue background, CD
	- `/C5/G6EF`: magenta text/cyan background, EF
- Color codes 5 and 6 are magenta and cyan. Older English documents call them Purple and Skyblue.

## 3. Character encoding and fonts

- `/Fxxyy`
	- xx: character encoding and font
		- System -- A --> Controller -- B --> LED module
		- `00` - A: EUC-KR code (2 bytes), B: Korean Johab font (2 bytes)
		- `01` - A: UTF-16 code (2 bytes), B: Unicode font (2 bytes)
		- `02` - A: UTF-8 code (3 bytes), B: Korean Johab font (2 bytes)
		- `03` - A: UTF-8 code (3 bytes), B: Unicode font (2 bytes)
- `/Tx`: font group
	- Example: upload the following fonts to the controller
		- /T0: Korean Johab font
		- /T1: Unicode font

### /F0003, /T0
- `/F0003`: System -- EUC-KR code (2 bytes) --> Controller -- Korean Johab font (2 bytes) --> LED module
- `/T0`: Korean Johab font

``` SQL
// Apply the F0003 and T0 attribute values
![0032/P0000/D9901/F0003/E0101/S0504/X0000/Y0000/B000/C1/G0/T0!]

// Send 가
![000가!]
```

- System -- EUC-KR code (2 bytes) --> Controller
	- Send the character in **EUC-KR**: **가 -> B0 A1**
	- Send everything except `가` (the attribute values) in **EUC-KR**

| ASCII protocol | !      | [      | 0      | 0      | 0      | **가**      | !      | ]      |
| ---------- | ------ | ------ | ------ | ------ | ------ | ---------- | ------ | ------ |
| Packet         | 21     | 5B     | 30     | 30     | 30     | **B0 A1**  | 21     | 5D     |
| Character encoding     | EUC-KR | EUC-KR | EUC-KR | EUC-KR | EUC-KR | **EUC-KR** | EUC-KR | EUC-KR |
- Controller -- `Korean Johab font (2 bytes)` --> LED module
	- The controller shows the character on the LED module with its Korean Johab font (`/T0`)


### /F0103, /T1
- `/F0103`: System -- UTF-16 code (2 bytes) --> Controller -- Unicode font (2 bytes) --> LED module
-  `/T1`: Unicode font
``` SQL
// Apply the F0103 and T1 attribute values
![0032/P0000/D9901/F0103/E0101/S0504/X0000/Y0000/B000/C1/G0/T1!]

// Send 가
![000가!]
```

- System -- UTF-16 code (2 bytes) --> Controller
	- Send only the character in **UTF-16**: **가 -> AC 00**
	- Send everything except `가` (the attribute values) in **EUC-KR**

| ASCII protocol | !      | [      | 0      | 0      | 0      | **가**      | !      | ]      |
| ---------- | ------ | ------ | ------ | ------ | ------ | ------ | ------ | ------ |
| Packet         | 21     | 5B     | 30     | 30     | 30     | **AC 00**  | 21     | 5D     |
| Character encoding     | EUC-KR | EUC-KR | EUC-KR | EUC-KR | EUC-KR | **UTF-16** | EUC-KR | EUC-KR |
- Controller -- `Unicode font (2 bytes)` --> LED module
	- The controller shows the character on the LED module with its Unicode font (`/T1`)


### /F0203, /T0
- `/F0203`: System -- UTF-8 code (3 bytes) --> Controller -- Korean Johab font (2 bytes) --> LED module
- `/T0`: Korean Johab font
``` SQL
// Apply the F0203 and T0 attribute values
![0032/P0000/D9901/F0203/E0101/S0504/X0000/Y0000/B000/C1/G0/T0!]

// Send 가
![000가!]
```

- System -- `UTF-8 code (3 bytes)` --> Controller
	- Send only the character in **UTF-8**: **가 -> EA B0 80**
	- Send everything except `가` (the attribute values) in **EUC-KR**

| ASCII protocol | !      | [      | 0      | 0      | 0      | **가**        | !      | ]      |
| ---------- | ------ | ------ | ------ | ------ | ------ | ------------ | ------ | ------ |
| Packet         | 21     | 5B     | 30     | 30     | 30     | **EA B0 80** | 21     | 5D     |
| Character encoding     | EUC-KR | EUC-KR | EUC-KR | EUC-KR | EUC-KR | **UTF-8**    | EUC-KR | EUC-KR |
- Controller -- Korean Johab font (2 bytes) --> LED module
	- The controller shows the character on the LED module with its Korean Johab font (`/T0`)

### /F0303, /T1
- `/F0303`: System -- UTF-8 code (3 bytes) --> Controller -- Unicode font (2 bytes) --> LED module
- `/T1`: Unicode font

``` SQL
// Apply the F0303 and T1 attribute values
![0032/P0000/D9901/F0303/E0101/S0504/X0000/Y0000/B000/C1/G0/T1!]

// Send 가
![000가!]
```


- System -- UTF-8 code (3 bytes) --> Controller
	- Send only the character in **UTF-8**: **가 -> EA B0 80**
	- Send everything except `가` (the attribute values) in **EUC-KR**

| ASCII protocol | !      | [      | 0      | 0      | 0      | **가**        | !      | ]      |
| ---------- | ------ | ------ | ------ | ------ | ------ | -------- | ------ | ------ |
| Packet         | 21     | 5B     | 30     | 30     | 30     | **EA B0 80** | 21     | 5D     |
| Character encoding     | EUC-KR | EUC-KR | EUC-KR | EUC-KR | EUC-KR | **UTF-8**    | EUC-KR | EUC-KR |
- Controller -- Unicode font (2 bytes) --> LED module
	- The controller shows the character on the LED module with its Unicode font (`/T1`)

## 4. Font size and font group
``` sql
![000/P0000/X0012/F0003/T0가나!]
![000/P0001/X1200/F0007/T1다!]
```
- ![[ascii_ex3.png]]
- `/Fxxyy`: font encoding/font size
- `/Tx`: font group
- (Caution) To use two or more font sizes or font groups on one screen, divide the screen into sections (`/Pxxyy`, `/Xxxyy`, `/Yxxyy`). Then set the font size and font group for each section
- `![000/P0000/X0012/F0003/T0가나!]`
	- `000`: single mode, no BCC check, real-time message
	- `/P0000`: real-time message, section 0
	- `/X0012`: from the left edge — no start position, end position at the 48th pixel
	- `/F0003`: EUC-KR code (2 bytes)/Korean Johab font (2 bytes), Latin letters/digits: 8x16, Korean: 16x16
	- `/T0가나!`: font group 0, 가나
- `![000/P0001/X1200/F0007/T1다!]`
	- `000`: single mode, no BCC check, real-time message
	- `/P0001`: real-time message, section 1
	- `/X1200`: from the left edge — start position at the 49th pixel, no end position
	- `/F0007`: EUC-KR code (2 bytes)/Korean Johab font (2 bytes), Latin letters/digits: 16x32, Korean: 32x32
	- `/T1다!`: font group 1, 다

## 6. Entry and exit effects, effect speed and stay time
```SQL
![000/P0000/Y0004/E0101/S2002/C2이동해주세요!]
![000/P0001/Y0408/E0606/S1000/C111가1111  22나2222  33다3333!]
```
- ![[ascii_ex6.png]]
- `/Exxyy`: entry/exit effect, see [[3.23. Message Entry and Exit Effect Codes]]
- `/Sxxyy`: effect speed/stay time
- `![000/P0000/Y0004/E0101/S2002/C2이동해주세요!]`
	- `000`: single mode, no BCC check, real-time message
	- `/P0000`: real-time message, section 0
	- `/Y0004`: from the top edge — no start position, end position at the 16th pixel
	- `/E0101`: entry effect: stop, exit effect: stop
	- `/S2002`: effect speed 20 (relative speed), stay time 2x0.5 = 1 second
	- `/C2이동해주세요`: green text, 이동해주세요 («Please move»)
- `![000/P0001/Y0408/E0606/S1000/C111가1111  22나2222  33다3333!]`
	- `000`: single mode, no BCC check, real-time message
	- `/P0001`: real-time message, section 1
	- `/Y0408`: from the top edge — start position at the 17th pixel, end position at the 32nd pixel
	- `/E0606`: entry effect: right to left, exit effect: right to left
	- `/S1000`: effect speed 10 (relative speed), stay time 0x0.5 = 0 seconds
	- `/C111가1111  22나2222  33다3333!`: red text, 11가1111  22나2222  33다3333

## 8. Page messages
- Register page messages
```SQL
![006002!] : register 2 page messages
```
- Delete page messages
```SQL
![006199!] : delete all page messages
![006100!] : delete page message 1
```
- Example
```SQL
![001/P0000/E0101/S2040/C2다빛솔루션  /C3환영합니다!]
```
- ![[ascii_ex7.png]]
- Packet analysis
	- `001`: single mode, no BCC check, page message
	- `/P0000`: page message 1, section 0
	- `/E0101`: entry effect: stop, exit effect: stop
	- `/S2040`: effect speed 20 (relative speed), stay time 40x0.5 = 20 seconds
	- `/C2다빛솔루션`: green text, 다빛솔루션 («Dabit Solution»)
	- `/C3환영합니다`: yellow text, 환영합니다 («Welcome»)
```SQL
![001/P0200/E0101/X0400/Y0004/C3도로결빙!]
![001/P0201/E4949/S8000/X0200/Y0408/C1서행/C2하세요!]
```
- ![[ascii_ex8.png]]
- `![001/P0200/E0101/X0400/Y0004/C3도로결빙!]`
	- `001`: single mode, no BCC check, page message
	- `/P0200`: page message 2, section 0
	- `/E0101`: entry effect: stop, exit effect: stop
	- `/X0400`: from the left edge — start position at the 17th pixel, no end position
	- `/Y0004`: from the top edge — no start position, end position at the 16th pixel
	- `/C3도로결빙!`: yellow text, 도로결빙 («Icy road»)
- `![001/P0201/E4949/S8000/X0200/Y0408/C1서행/C2하세요!]`
	- `001`: single mode, no BCC check, page message
	- `/P0201`: page message 2, section 1
	- `/E4949`: entry effect: only red text blinks, exit effect: only red text blinks
	- `/S8000`: effect speed 80 (relative speed), stay time 0x0.5 = 0 seconds
	- `/X0200`: from the left edge — start position at the 9th pixel, no end position
	- `/Y0408`: from the top edge — start position at the 17th pixel, end position at the 32nd pixel
	- `/C1서행`: red text, 서행 («Slow»)
	- `/C2하세요!`: green text, 하세요 (with the red text: «Please slow down»)
