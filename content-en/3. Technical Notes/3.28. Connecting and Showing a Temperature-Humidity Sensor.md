> [!abstract] How to connect a temperature/humidity sensor and show its values
> The temperature/humidity sensor (SHT30) can be connected only to the DB502S

#### Connecting the temperature/humidity sensor

| Controller J4 Relay | SHT30       |
| ------------- | ----------- |
| GND           | GND (black)   |
| D1            | Clock signal (yellow) |
| D2            | Data signal (green)  |
| 5V            | VCC (red)   |

#### How to show temperature and humidity
- `보드 기능 설정` (Board settings) > `J4(4핀) 모드` (pin mode) > `SHT31(DB502)`
- ASCII protocol >  `![000/C2온도:/C1/I35/C2/u164/C2습도: /C1/I37/C2/u037!]` (온도 = temperature, 습도 = humidity)
	- Written for a 2 rows × 6 columns module
	- For information text (`/ixx`), see [[3.27. How to Display Information Text]]
	- For user fonts (/uxxx), see the ASCII section of [2.4.3. Entering User Fonts](https://docs.dabitsol.com/2.4.3) (Korean)
- Packet to check the temperature and humidity
	- Sent message: `![00D10!]`
	- Received message: `![00D1 26.6 85.0!]` - temperature: 26.6 degrees, humidity: 85%

> [!tip] New controllers (firmware V3.6.0 or later) can read the temperature and humidity as JSON with the ASCII command `![00Q0!]` — see [[2.9.2. New and Legacy Command Mapping Table]]
