title: 2.4.5. 16x16 Font Settings (Latin Letters and Digits)

> [!abstract] How to show Latin letters and digits with a 16x16 font
> How to show the Latin letters and digits, which a DABIT controller shows at 8x16 pixels, with a 16x16-pixel font

#### Test setup
- Controller: DABIT500S
- Module: DABIT P3 2R6C 16S
#### Send the 16x16 font

1. Open the font settings menu
	- DabitOne: `설정` (Settings) > `폰트전송` (Font transfer)
	- DBPS: `설정` (Settings) > `폰트 전송` (Font transfer)
2. Select font group 2, and then select the 16x16 font files below
	- 영어 (English): `ENG 16x16-ASCII-Roman.fnt`
	- 한글조합형 (Hangul combination type): `KOR 16x16-DABIT(표준).fnt`
	- 사용자폰트 (User font): `USER 16x16-Special(표준).fnt`
3. Click the send font file button to upload

#### Check the applied 16x16 font

1. Open the default display attribute window
	- DabitOne: `기본값 설정` (Set defaults) in the ASCII protocol area of the `전송` (Send) tab
	- DBPS: `속성 초기화` (Reset attributes) > `설정` (Settings)
2. In the window, set the display attributes, such as the font, and save them
	- DabitOne: `기본값으로 설정` (Set as defaults)
	- DBPS: `설정` (Settings)
3. Enter `![000/T1/C7가나다라마바123ABC!]` («가나다라마바» = Korean letters) in the ASCII protocol input box (`/T1` = font group 2)
	- DabitOne: `전송` (Send) > `ASCII 프로토콜` (ASCII protocol)
	- DBPS: `프로토콜 전송` (Send protocol) > `아스키 프로토콜` (ASCII protocol)
4. Send → check the 16x16 font that the LED display shows
5. Display result
	- ![[16픽셀폰트.png|300]]

#### (Reference 1) Sending fonts from the old versions (DabitChe, Protocol Simulator)
- Set the font transfer window as follows
	- Select font group 1
	- Font: `16x16/16x16`
	- 영어 (English): `ENG 16x16-ASCII-Roman.fnt`
	- 한글조합형 (Hangul combination type): `KOR 16x16-DABIT(표준).fnt`
	- 사용자폰트 (User font): `USER 16x16-Special(표준).fnt`
- Click the send button to upload
#### (Reference 2) Sending from the DabitChe app
- To show Korean, insert the `/F0203` packet and send the text encoded in UTF-8
