---
title: 2.7.6. Sending Images from DabitChe
---

> [!abstract] A guide for users of the old DabitChe (V2.x) — from making images in DabitChe to converting, sending playlists, and checking, in one document
> If you use the current program DabitOne, see [[2.7.1. Making Images]] to [[2.7.4. Checking Playlists and Images Uploaded to the Controller]].

### Step 1 — make an image

#### Set the LED display size

- `환경설정` (Preferences) > `화면설정` (Screen settings)
	- 세로 (Height): `2`
	- 가로 (Width) `6`
	- 픽셀당 비트수 (Bits per pixel): `3BPP(8color)`
	- `전송` (Send)
- Whether the module is 3-color or full-color, we recommend that you set **bits per pixel to 3BPP(8Color)**

#### Make a background image with Paint

1. Open the Paint program
	- `표시파일작성` (Create display file) > `그래픽 이미지` (Graphic image)
2. Draw the image in Paint
	- Zoom in to the maximum
	- Tools > `Pencil`
	- Size > `1px`
	- Colors > select a color, and click with the mouse to make the image pixel by pixel
3. `File` > `Save as` > `BMP picture` > select the Image folder > `Save`

> [!note] For details on making a BMP file, see [DabitChe manual > Attachment 2](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf) (Korean)

### Step 2 — convert images or text to dat/ani files

To make a .pla or .bgp file and upload it to the controller, convert bmp/jpg files to dat files and gif files to ani files.

#### Convert a bmp/jpg graphic image to a dat file

- `표시파일작성` (Create display file) > `이미지 편집` (Image editing) > the image editing window
	- Select `이미지 고급편집` (Advanced image editing)
	- Select `배경이미지 불러오기` (Load background image)
	- Click `...` on the right of the main image to load the image (.bmp/.jpg)
	- `저장하기` (Save) > save it as a .dat (or .daz) file

#### Enter text in the image editing window and save it as a dat file

- `표시파일작성` (Create display file) > `이미지 편집` (Image editing) > the image editing window
	- Enter the text, and select the size, alignment, and color
	- `저장하기` (Save) > save it as a .dat (or .daz) file

#### Convert a gif animation to an ani file

- `표시파일작성` (Create display file) > `이미지 편집` (Image editing) > the image editing window
	- Select `GIF 편집` (GIF editing)
	- Click `...` on the right of the main image to load the image (.gif)
	- `저장하기` (Save) > save it as an .ani (or .anz) file

> [!tip] If the ani file is large because it has many frames, we recommend that you save it as a compressed daz or anz file (DabitChe V2.4.8 or later)

> [!note] For the detailed conversion steps, see [DabitChe manual > 4.6 Display files: converting graphic images (Sample 6)](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf) (Korean)

### Step 3 — make a playlist and upload it

- Playlist > display file name > `이미지` (Image) or `동영상` (Video) > Select file > select .dat or .ani > `열기` (Open)
- Click the `+` button to add up to 255 images and animation files
- `파일` (File) > `저장` (Save) > Save as > file type >
	- Main schedule: `Playlist File (*.pla)` > enter the .pla file name > `저장` (Save)
	- Background image: `BG Playlist(*.bgp)` > enter the .bgp file name > `저장` (Save)
- `컨트롤러 접속` (Connect to controller) > `업로드` (Upload)

> [!note] For details on making a playlist, see [DabitChe manual > 5.1 Making a playlist, 5.2 Making a background playlist](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf) (Korean)

### Step 4 — check the uploaded playlist and images

#### There is no download (read) function

- DabitChe does not have a function to bring the playlist (.pla) or background image (.bgp) files saved in the controller back to the PC (download or read).
- So check the uploaded content with the display tests below.

#### Check the playlist (.pla) — restart the power

- When you turn the controller power off and on again, the uploaded playlist shows in the registered order.
- You can see which playlist is uploaded by looking at the screen.

#### Check the background images (.bgp) — display test

- DabitChe > `고급설정` (Advanced settings) > `Protocol Simulator(V6)` > `특수기능` (Special functions) > select background image > enter the number > `전송` (Send)
- Or call it with the ASCII protocol: `![000/B001!]` (shows background image 1)
- If you send the numbers in order from 1, you can check which image is saved at which number.
