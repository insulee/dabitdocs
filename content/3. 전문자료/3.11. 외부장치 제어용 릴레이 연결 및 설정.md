#### 2 Relay Module - 외부장치 연결 구성
- COM (Common): 공통 단자로 NO 또는 NC와 연결되어 전기 회로의 입력 단자로 사용
- NO (Normally Open): 평소에 회로가 열려 있으며, 릴레이가 활성화되면 닫혀서 장치가 켜짐
- NC (Normally Closed): 평소에 회로가 닫혀 있으며, 릴레이가 활성화되면 열려서 장치가 꺼짐
- 릴레이를 220V로 사용할 경우, 역기전력(back electromotive force, back EMF)으로 인해, 컨트롤러 오작동 또는 LED에 잡티가 생긴다면 스파크 킬러 설치를 권장
	- 스파크 킬러는 외부장치와 릴레이 연결 포트와 같은 포트에 설치
	- 예. 외부장치가 릴레이의 COM, NO 포트에 연결되었다면 스파크 킬러도 COM, NO 포트에 연결

#### 연결 후 테스트 방법 (DabitOne)
- `고급` > `릴레이 신호` 다이얼로그 (2개의 채널 컨트롤 가능)
	- `None`: 기존 설정 유지
	- `On`: 릴레이 활성화
	- `Off`: 릴레이 비활성화
	- `숫자`: x100ms 동안 활성화
	- `전송`

#### 릴레이 제어 패킷 (ASCII 프로토콜)

**프레임 구조:** `![0022{Relay1}{Relay2}!]`

| 필드 | 길이 | 설명 |
| ---- | ---- | ---- |
| `0022` | 4자리 | 릴레이 제어 OPCode |
| Relay1 | 5자리 | 릴레이 1 제어값 |
| Relay2 | 5자리 | 릴레이 2 제어값 |

**릴레이 제어값 인코딩:**

| 선택 | 전송 값 | 의미 |
| ---- | ------- | ---- |
| None | `61696` | 기존 설정 유지 (변경 없음) |
| On | `61440` | 릴레이 상시 활성화 |
| Off | `00000` | 릴레이 비활성화 |
| 1~230 | `00001`~`00230` | 해당 값 × 100ms 동안 활성화 후 자동 비활성화 |

**전송 예시:**

| 목적 | 패킷 |
| ---- | ---- |
| Relay1=On, Relay2=Off | `![00226144000000!]` |
| Relay1=Off, Relay2=On | `![00220000061440!]` |
| Relay1=500ms 활성화, Relay2=유지 | `![00220005061696!]` |
| 두 채널 모두 On | `![00226144061440!]` |
| 두 채널 모두 Off | `![00220000000000!]` |

> [!info] RS485 다중 연결 시
> RS485 주소가 설정된 경우, OPCode 4자리 중 앞의 `0`이 RS485 주소(HEX)로 대체된다.
> 예: 주소 5 → `![5022{Relay1}{Relay2}!]`
