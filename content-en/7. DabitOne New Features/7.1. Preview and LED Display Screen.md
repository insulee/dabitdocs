title: 7.1. Preview and LED Display Screen
---

> [!abstract] Preview and LED display screen (new in DabitOne)
> DabitOne shows the screen in 2 ways: the **preview** to check before sending, and the **LED display screen** that mirrors the actual display after sending.

#### Comparison at a glance

| Item | Preview before sending | LED display screen |
|------|-----------------|------------|
| **Time** | **Before** sending | **After** sending (real time) |
| **Purpose** | Practice (rehearsal) | Actual display |
| **Actual sending** | No — check only | Mirrors the sent content as it is |
| **Location** | `미리보기` (Preview) button → separate window | Borderless window at the top left of the monitor |
| **Use** | Check typos, colors, and cut-off parts in advance | Check the actual display of the sent content |

#### Preview before sending — check before you send

A practice screen that shows how the display will look before you send. It does not actually send.

1. In the `전송` (Send) tab, select the message or image to send
2. Click the `미리보기` (Preview) button. The `전광판 미리보기` (LED display preview) window opens next to the main window — it plays the entry, stay, and exit effects as they move
   〔1 screenshot: Send tab + preview window〕
3. Check typos, colors, and cut-off parts, then click `전송` (Send)

#### LED display screen — actual display after sending

The actual display screen: it mirrors the content sent to the controller on the connected PC monitor, the same as the LED display. A separate legacy program (`DIBD_Display.exe`) did this job before. DabitOne builds it again as a window in the app.

1. In `전광판 화면` (LED display screen) on the right of the `전송` (Send) tab, click `전광판 화면 열기` (Open LED display screen) (you can select a scale of 1–20 and `항상 위` (Always on top))
2. A black window with the same ratio as the LED display appears
   〔1 screenshot: LED display screen window〕
3. Text, images, and effects that you send after this show in real time. With the control bar under the window, you can also fill the screen, show a background image, and turn the display on/off

> [!note] Do not confuse them
> The **preview** is practice before sending, so it does not actually send. The **LED display screen** is the actual display after sending. The names are similar, but the purposes are different.
