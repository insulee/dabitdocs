
> [!abstract] dbNet에서 LAN to Serial 컨버터(DB300E)의 연결 및 네트워크 설정 안내
> 시리얼만 있는 컨트롤러에 이더넷 통신을 달아주는 컨버터 DB300E의 설정 방법


### 특징
- Client TCP/IP, Server TCP/IP, UDP 연결 가능
- 아래의 내용은 Client TCP/IP 연결로, 그 외의 연결은 [[2.1.4. Server TCPIP, UDP 설정]] 참고
- 컨버터와 컨트롤러는 시리얼(TTL 또는 RS232)로 연결

### 네트워크 어댑터의 IPv4 주소 확인
- 윈도우 검색 > 명령프롬프트 > `ipconfig /all`
- 이더넷 어댑터 또는 무선 LAN 어댑터의 IPv4 주소..... : `***.***.***.***` 확인

### 컨버터의 네트워크 값 입력
- 통신 > dbNet > 하단 공통 버튼 행(`Search`/`Set`/`Add`/`Reset`)의 `Search`
- 연결하려는 컨버터의 Mac address 선택 — `Board Name`에 `DB300E` 표시
- IP Address, Subnet Mask, Gateway, Port 등 **네트워크 정보 변경**
	- IP Address: 연결되어 있는 네트워크 어댑터 IPv4 주소와 **네번째 옥탯(Octet)은 다른 값**으로 입력
	- 예를 들어
		- 네트워크 어댑터의 IPv4 주소: 169.254.121.210
		- 컨버터의 IP Address: 169.254.121.*** (1~255 중 210을 제외한 값)
		- Subnet Mask, Gateway: 네트워크 어댑터와 **동일한 값**
- `Set`

### 컨버터 정보 확인 (DB300 그룹)
- MAC 선택 후 `DB300` 그룹의 `Read`를 누르면 컨버터 정보를 읽어옴
	- `Version`: 펌웨어 버전 (예: Ethernet V2.0.4)
	- `Port`: 컨버터가 컨트롤러와 연결된 시리얼 방식 — **기본값 `TTL`**
	- `Baud Rate`: 통신 속도 (기본 115200)

> [!tip] 연결이 안 될 때 — Port 확인
> 컨버터의 `Port`는 기본값이 `TTL`입니다. 컨트롤러와 **RS232로 배선**했는데 Port가 `TTL`로 되어 있으면 통신이 되지 않습니다.
> 1. MAC 선택 > `DB300` 그룹의 `Read`
> 2. `Port`가 배선 방식과 맞는지 확인 (RS232 배선인데 `TTL`이면 불일치)
> 3. 다르면 `Port`를 `RS232`(또는 `TTL`)로 바꾸고 `Write`

### (예외) 이더넷으로 1:1 연결시 네트워크 어댑터의 수동 IP 주소 설정
- 윈도우 검색 > `네트워크 연결 보기`를 눌러 네트워크 연결 폴더 열기
- 이더넷 아이콘 > 우측버튼 클릭 >` 속성` 
- `인터넷 프로토콜 버전 4(TCP/IPv4) `> `속성`
	- 다음 IP 주소 사용
		- IP 주소: 컨버터의 IP Address와 **네번째 옥텟(Octet)은 다른 값**으로 입력
		- Subnet Mask, Gateway: 컨버터와 **동일한 값**
