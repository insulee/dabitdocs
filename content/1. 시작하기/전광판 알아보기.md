
> [!abstract] 전광판 컨트롤러·LED 모듈·통신 프로토콜을 처음 접하는 분을 위한 입문 자료

전광판이 어떻게 데이터를 받아 화면에 글자를 띄우는지, 외부 시스템(주차관제·PLC·센서)이 어떻게 전광판에 데이터를 보내는지 그림과 실시간 예시로 설명합니다.

**[전광판 알아보기 자료 열기](signage-intro.html)** — 풀스크린 슬라이드 28장, 약 20분 소요

### 1. 자료 구성

| 파트 | 내용 |
|------|------|
| **1부 — 프로토콜 전광판 컨트롤러란** | LED 모듈과 컨트롤러의 구성, 리모컨형과 프로토콜형의 차이, 데이터가 화면에 표시되는 흐름 |
| **2부 — 화면을 만드는 하드웨어** | LED 모듈, 픽셀 피치(P3/P4/P6/P8/P10), 같은 모듈로 다양한 화면 크기 만들기 |
| **3부 — 데이터 보내기** | TTL·RS232·RS485·Ethernet·WiFi·BLE 연결, 패킷 구조, 패킷 빌더 |
| **4부 — 연동 사례** | 주차관제, 불법주정차 단속, PLC, 소음 센서, 릴레이 출력 |

### 2. 인터랙티브 위젯

자료 안에는 직접 클릭해서 동작을 확인하는 위젯이 포함되어 있습니다.

- 패킷 빌더 — 메시지·색·효과·속도를 바꾸면 LED 미리보기와 생성된 패킷이 실시간으로 변경
- 연동 사례 시뮬레이터 — 주차관제(입차/출차로 잔여 면수 변화), 불법주정차 단속(위반 차량 적발), PLC(화면 호출), 소음 센서(dB 측정값 표시)
