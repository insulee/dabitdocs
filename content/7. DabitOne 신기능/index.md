> [!abstract] DabitOne에서 새로 생긴 기능 모음
> 레거시(DBPS·다빛채)에는 없던, DabitOne에서 추가하거나 크게 개선한 기능 모음. 항목을 누르면 자세한 사용법으로 이동

#### 콘텐츠 편집

- [[7.3. 내장 GIF 편집기]] — 앱 안에서 점멸·순환 같은 여러 장면(프레임) 콘텐츠를 직접 제작
- [[7.7. 분할 영역 독립 속도·유지시간]] — 메인 화면과 분할 화면의 흐름 속도를 따로 설정
- [[7.8. 시스템 글꼴과 글자 크기]] — PC에 설치된 글꼴 사용 + 고정 크기 외 자유 크기
- [[7.9. 화면 확장 (가로·세로 배율)]] — 가로·세로 배율(1~9)로 간단히 키우기

#### 전송

- [[7.5. 전송 전 안전장치]] — 전광판보다 큰 이미지 차단 + 전광판 크기 자동 맞춤
- [[7.4. 공장초기화 2단계]] — 콘텐츠만 지우기(소프트) / 전체 초기화(강력) 선택
- [[7.10. 영상과 이미지 혼합 스케줄]] — 영상(ANI)과 이미지(DAT)를 한 스케줄에 함께 등록
- [[7.2. 자동전송(AutoSend)]] — 프리셋으로 설정·콘텐츠를 한 번에 자동 전송 (별도 앱)

#### 미리보기 · 표출 화면

- [[7.1. 미리보기와 전광판 화면]] — 보내기 전 미리보기 + 보낸 후 실제 표출 화면 (HDMI 캡처용)

#### 설정 / 편의

- [[7.11. IP 주소 입력 편의]] — 숫자만 누르면 점(.)이 자동으로 찍힘
- [[7.12. 색상모드 전환]] — 색상 표현 모드 확인·전환 (고급)

#### 고급

- [[7.6. AI 자연어 제어]] — "노란색으로 왼쪽 스크롤"처럼 말로 전광판 제어 (실험적)
- [[7.13. 진단·엔지니어 모드]] — 통신 문제를 진단하는 고급 도구
