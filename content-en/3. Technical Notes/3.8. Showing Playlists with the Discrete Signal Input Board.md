> [!abstract] How to show playlists with the Discrete Signal Input Board
> How to receive discrete signals from a PLC or a relay/switch and show the message saved under that number on the LED module

#### How to connect the Discrete Signal Input Board

1. **PLC NPN output card**
	- Connect the COM terminal of the PLC to the plus (+12V/24V) of the external power supply
	- Connect the COM terminal of the Discrete Signal Input Board to the minus (-GND) of the external power supply
	- Connect the PLC to S1~S8 of the Discrete Signal Input Board
	- ![[접점보드NPN.png]]
2. **PLC PNP output card**
	- Connect the COM terminal of the PLC to the minus (-GND) of the external power supply
	- Connect the COM terminal of the Discrete Signal Input Board to the plus (+12V/24V) of the external power supply
	- Connect the PLC to S1~S8 of the Discrete Signal Input Board
	- ![[접점보드PNP.png]]
3. **PLC RELAY output card**
	- Connect the COM terminal of the PLC to the RCOM terminal of the Discrete Signal Input Board
	- Connect the PLC to S1~S8 of the Discrete Signal Input Board
	- ![[접점보드RELAY.png]]

#### Discrete input settings and showing content on the LED display
- JP3 3Pin Connector on the controller
    - Connect 3.3V and COM with the jumper pin (for PLC RELAY output)
        - Supplies 3.3V to pin 1 (VDD) of BH1
        - The input signal of the "Discrete Signal Input Module" works normally at a voltage from 4V to 28V
    - Connect 5V and COM with the jumper pin
        - Supplies 5V to pin 1 (VDD) of BH1
        - The input signal of the "Discrete Signal Input Module" works normally at a voltage from 9V to 28V
- In `보드기능설정` (Board settings) > `BH1(10핀) 모드` (pin mode), you can set 3 types of discrete input
	- 8Pin Input(HEX): up to 255 return values
	- 8Pin Input(BCD): up to 99 return values
	- 8Pin Input(Number): up to 8 return values
	- For the return values of each of the 3 discrete input methods, see [[3.9. Return Values for Each Discrete Signal Setting]]
- (Important) If S5 on the Discrete Signal Input Board lights red, or if the data is not sent
	- Check whether `보드기능설정` (Board settings) > `BH1(10핀) 모드` (pin mode) is TTL/RS485. If it is, change it to 8Pin Input
	- We recommend that you **move the jumper pin to the other position (3.3V <-> 5V)**
- Use a discrete input to call text or images that you uploaded before with [2.7.3. Making a Playlist](https://docs.dabitsol.com/2.7.3) (Korean) or [3.30. Showing Page Text by Background Image Number](https://docs.dabitsol.com/3.30) (Korean). The LED module shows them
