> [!abstract] How to put content files (.dat/.ani) into a playlist (.pla/.bgp) and send it to the controller
> Make the playlist on the `편집` (Edit) tab > `저장` (Save) > one click on the `전송` (Send) button uploads it to the controller.

> [!note] If you use the old DabitChe, see [[2.7.6. Sending Images from DabitChe]].

### Make the playlist

1. `편집` (Edit) tab > `새표시목록` (New playlist)
2. Add items (rows) with `추가` (Add). Arrange the list with `삭제` (Delete), `↑`/`↓` (move up/down), and `복제` (Duplicate)
3. Fill in the items — there are two ways
	- The `편집` (Edit) button on the right of the row > make text or an image in the `콘텐츠 편집` (Content editing) window, and click `표시파일에 적용` (Apply to display file)
	- Double-click `표시파일명` (Display file name) > select the file type (`이미지` (Image)/`동영상 (GIF)` (Video (GIF))/`페이지문구` (Page text))
		- `이미지` (Image): select a .dat or .bmp/.png/.jpg/.jpeg file (a normal image is converted to .dat automatically — [7.6. Automatic DAT Conversion of Images](https://docs.dabitsol.com/7.6) (Korean))
		- `동영상 (GIF)` (Video (GIF)): select an .ani file
		- `페이지문구` (Page text): it is added to the item as soon as you select it, without selecting a file
4. Preview how it will look in `표시파일 보기` (Display file view) at the bottom of the screen — for details on checking before you send, see [7.1. Preview and LED Display Screen](https://docs.dabitsol.com/7.1) (Korean)
- You can mix images (.dat) and videos (.ani) in one list

### Save — pla and bgp

- `저장` (Save) or `다른이름저장` (Save as) > select the file type (default folder `Data\Playlist`)
	- Main schedule: `스케줄 파일 (*.pla)` (Schedule file (*.pla)) — the controller **shows the items automatically, in order,** with their effect, speed, and stay time
	- Background image: `배경 파일 (*.bgp)` (Background file (*.bgp)) — the controller keeps them in memory and **shows the one that you select by number**
- The last playlist that you opened comes back automatically when you restart the program.

### Send

1. `편집` (Edit) tab > `전송` (Send)
	- If the list is not saved, a save confirmation window shows first. The extension that you save (.pla/.bgp) decides the transfer method.
2. Automatic check before the transfer — if a .dat/.ani file that the list uses is missing, or an image is larger than the LED display, a message window opens and the transfer stops
3. If it is not connected, it connects automatically with the current communication settings
4. A progress window shows, and you can click `취소` (Cancel). When it is done, the "전송 완료" (Transfer complete) message shows.
