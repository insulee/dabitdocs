
> [!abstract] 신형 컨트롤러(DIBD520·720 계열)에서 확장된 ASCII 프로토콜을 안내합니다 — 확장 명령 체계와 64색 문자색(`/K`)
> 기본 패킷 구조는 [[2.8.1. ASCII 프로토콜 매뉴얼]]과 동일하며, 이 문서는 신형 펌웨어에서 **추가된 부분**만 다룹니다.

## 1. 신 프로토콜 개요

- 시작/종료 문자, 주소, Error Check 등 **패킷 프레임은 기존과 동일**합니다: `![AEM...!]`
- 기존 명령·속성은 신형 컨트롤러에서도 그대로 동작합니다 (하위 호환)
- 신형 펌웨어는 여기에 두 갈래를 추가합니다:
	- **확장 명령** — 메시지 형식(M) 자리에 **두 글자 코드**를 쓰고, 값은 공백으로 구분합니다. 예: `![00V3 1!]` (미디어 재생). 각 명령의 상세는 해당 기능 문서에서 안내합니다.
	- **확장 표시 속성** — 아래 64색 문자색 `/K`가 대표입니다.

> [!note] 응답 형태
> 문구 메시지의 응답은 기존과 동일합니다(`![0EMR!]`, 정상 `0`/실패 `F`). 확장 명령은 실패 시 `F` 뒤에 원인 숫자가 붙을 수 있습니다 (예: 형식 오류, 값 범위 초과, 미지원).

## 2. 64색 문자색 `/K`

기존 `/C`(8색)를 확장한 문자 색상 속성입니다. 빨강·초록·파랑을 **각 4단계**로 조합해 64색을 표현합니다.

### 2.1. 문법

`/Knn` — nn은 `00`~`63`의 색 번호 (항상 2자리)

```
색 번호 = 파랑×16 + 초록×4 + 빨강   (각 채널 0~3)
```

| 예시 코드 | 색 | 구성 |
| --- | --- | --- |
| `/K00` | 검정 | - |
| `/K03` | 빨강 | R3 |
| `/K07` | 주황 | R3+G1 |
| `/K12` | 초록 | G3 |
| `/K15` | 노랑 | R3+G3 |
| `/K22` | 분홍 | R2+G1+B1 |
| `/K48` | 파랑 | B3 |
| `/K51` | 자주 | R3+B3 |
| `/K60` | 청록 | G3+B3 |
| `/K63` | 흰색 | R3+G3+B3 |

- 기존 `/C`의 8색은 위 표의 검정·빨강·초록·노랑·파랑·자주·청록·흰색으로 **모두 표현 가능**합니다.

### 2.2. 사용 예시

```
![000/K03가/K12나/K48다/K63라!]
```

'가'는 빨강, '나'는 초록, '다'는 파랑, '라'는 흰색으로 표시됩니다. 글자 중간에서 얼마든지 색을 바꿀 수 있습니다.

### 2.3. 제약 사항

> [!warning] 한 메시지에는 한 색 체계만 사용하세요
> `/K`와 `/C`·`/G`를 한 메시지에 섞으면 `/K` 이후의 `/C`가 **의도와 다른 색**으로 표시됩니다. 색을 확장할 메시지는 전체를 `/K`로 통일하는 것을 권장합니다 — 기존 8색도 모두 `/K`로 표현할 수 있습니다.

- 문자 배경색은 지정할 수 없습니다 (항상 검정) — `/G`는 `/K`와 함께 쓸 수 없습니다
- 16비트 컬러(16C) 컨트롤러에서 전체 색이 표현되며, 8색(08C) 컨트롤러는 가까운 8색으로 축약됩니다
- Firmware: **V4.1.3**에서 동작 확인 (2026-08-14, DIBD720 계열)
