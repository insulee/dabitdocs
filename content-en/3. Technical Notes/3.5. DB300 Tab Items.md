title: 3.5. DB300 Tab Items
---

> [!abstract] dbNet > items of the DB300 tab
>Debugging mode, data connection port (TTL/RS232), and baud rate settings of the DB300 series (DB300E, DB300WB, DB320WB), and the Packet Setting that the LAN-to-Serial converter uses to send data to the controller

> [!warning] The DB300WB · DB320WB are discontinued
> - Use the Wi-Fi version content in this document to manage DB300WB · DB320WB units that are already installed
> - For wireless connection at new sites, use the **DBW320 wireless option board** — [[2.1.6. Using the DBW320 Wireless Option Board]]

#### Where to set the DB300
> [!warning] Support for the DB300 settings window in DabitOne has ended
> - The version that you download now still shows it, but the next version removes it
> - To change the settings of a DB300 that is already installed on site, use **DabitChe**
> - The item descriptions below use the DabitOne screen. The item names on the DabitChe screen can be different

#### Adding the DB300 Info tab (Dabit Protocol Simulator)
- DABITNet > `COMM` > Advanced > DB300 Tab: `Enable`

#### Reading and changing DB300 series information (DabitOne)
- `통신` (Communication) tab > dbNet > `DB300` >
	- `Read`: reads the information
	- `Version`: DB300 firmware version (read-only)
	- `Debugging`
		- `Disabled`: turns debugging mode off
		- `Enabled`: turns debugging mode on
	- `Port`
		- `TTL`: connects through the TTL port (default value for the Ethernet version)
		- `RS232`: connects through the RS232 port (default value for the Wi-Fi version)
	- `Baud Rate`
		- `115200`: default baud rate value (you can change it)
	- `Write`: saves the changes

#### Packet Setting
- DabitOne has no input UI for Packet Setting. When you click `Write`, DabitOne always sends the fixed values below.
	- Char (ASCII) 1st: `!` 2nd: `]` [^1]
	- Char (HEX) 1st: `10` 2nd: `03` [^2]
	- Timeout (ms): `10` [^3]  


[^1]: ASCII packet example ![0001234ABCD!]
[^2]: HEX packet example 10 02 00 00 21 94 00 00 63 01 00 03 01 00 00 14 02 00 00 00 04 00 03 03 03 03 03 03 03 03 31 32 33 34 41 42 43 44 10 03
[^3]: When no packet comes for 10 ms, the reception is complete
