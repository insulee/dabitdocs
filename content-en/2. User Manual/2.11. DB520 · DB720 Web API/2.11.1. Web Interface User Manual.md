title: 2.11.1. Web Interface User Manual
---

> [!abstract] How to change the text, brightness, and screen size of a DB520 · DB720 LED display from a phone browser
> The steps for store owners who change the text come first. The steps for installers who set up the connection and the size come after.

## 1. 5 things to know first

1. **The phone and the LED display must be on the same Wi‑Fi (router).** You do not need the internet.
2. **Text that you sent looks sharp in the preview.** A screen that another program put up looks blurred. This is not a fault.
3. **The minimum brightness is 1%.** 0% means "automatic brightness", not off, so this screen does not use it.
4. **When you apply a screen size, the LED display restarts for about 10 seconds.** During that time, the connection drops for a moment.
5. **A background image appears on the LED, but not in the phone preview.** This is not a fault (section 5).

## 2. Supported devices

- **Controllers**: all DB520 · DB720 models (firmware family DIBD520 · DIBD720) — tested on real DIBD520S · DIBD720U boards
- **Firmware**: you can use it on the shipping version, official V4.5.4 (tested on real boards with V3.8.5 · V4.2.0)
- **Phone browser**: Safari on iPhone, Chrome on Android
- **Address**: `http://<controller-IP>/` — the address that you are using now shows in `컨트롤러 주소` (Controller address) on the `설정` (Settings) sheet and at the bottom of the home screen

## 3. The screen at a glance

![[db720-web-01-home.png|300]]

| Position | Name | What it does |
| --- | --- | --- |
| Top left | **Connection dot** | Green = connected, red = disconnected, gray = not checked yet |
| Top right | `설정` (Settings) | Name · controller address · API key |
| Center card | **지금 전광판** (Display now) | Live preview + `켜기` (On) / `끄기` (Off) |
| Two buttons below the card | `화면 크기` (Screen size) · `전광판 제어` (Display control) | Size settings / brightness · pages · test patterns |
| Large button at the bottom | `문구 작성` (Write text) | Makes text and sends it to the LED display |

## 4. Send text

![[db720-web-02-compose.png|300]]

1. On the home screen, tap `문구 작성` (Write text).
2. **Select the type.** `실시간 메시지` (Real-time message) is not saved. It appears at once and disappears when the next text comes. `페이지 메시지` (Page message) is saved on the LED display and stays after the power goes off and on. The pages show in turn, as many as the page count.
3. Write the text in `글 내용` (Text). The maximum is 200 characters.
4. In `글자색` (Text color), select one of 8 colors. The order is 검정 (black) · 빨강 (red) · 초록 (green) · 노랑 (yellow, default) · 파랑 (blue) · 분홍 (magenta) · 하늘 (cyan) · 흰색 (white).
5. Select `입장효과` (Entry effect) and `방향` (Direction). The defaults are `정지` (Stop) · `방향없음` (None). There are 12 effects, such as Stop, Shift, Wipe, Blind, and Curtain. The direction list changes with the effect.
6. The default of `퇴장효과` (Exit effect) is `사용 안 함` (Not used). If you leave it as it is, the text **stays on**.
7. Select `효과속도` (Effect speed) (from very fast to very slow) and `유지시간` (Stay time) (from 0 to 40 seconds). The defaults are `보통 (20)` (normal) and `1초`.
8. Select `글자 크기` (Text size). The sizes are from `12×12` to `64×64`, and the default is `16×16 (기본)` (default).
9. Tap `전광판으로 전송` (Send to display). For a page message, one more confirmation window appears: "페이지 N에 저장합니다 … 진행할까요?" (Save to page N … continue?).

![[db720-web-03-after-send.png|300]]

- If it succeeds, the notice **"실시간 메시지를 전송했습니다"** (Real-time message sent) or **"저장했어요"** (Saved) appears. If it fails, a red notice appears with the reason.
- If the text is wider than the screen, the message **"글이 길어요 — 이동/와이프 계열 효과로 하면 전체가 보여요"** (The text is long — use a Shift or Wipe type effect to show all of it) appears.
- If the text has characters that the LED display cannot draw, such as emoji, **a warning that they can break or show as blanks** appears below the input field.

> [!tip]
> This phone remembers the last text and options that you sent. The next time you open `문구 작성` (Write text), they come back as they were.

## 5. How to read the preview

![[db720-web-03b-preview.png|300]]

- **Text that you sent looks sharp.** The phone draws it with the same dot font as the LED display.
- **A screen that another program sent, saved pages, and text with special characters look blurred.** The phone receives the video of the real LED display as it is. Even when it is blurred, that is the real screen.
- **"실시간 화면"** (Live screen) below the preview means that the video is coming in normally. **"96×32px"** on the right is the current screen size of the LED display (width × height in pixels).
- If the caption is **"미리보기 일시 중단"** (Preview paused), the video stopped for a moment. If it is **"오프라인 — 연결을 확인해 주세요"** (Offline — check the connection), the connection to the LED display is lost.
- **A background image does not appear in the preview.** The real LED display shows the background and the text together, but the phone preview video shows only the text (being checked in the firmware).

## 6. Power, brightness, pages, and test patterns

![[db720-web-04-control.png|300]]

- **Power**: `켜기` (On) / `끄기` (Off) on the home card. If it succeeds, "화면을 켰어요" (Screen turned on) / "화면을 껐어요" (Screen turned off) appears.
- **Brightness**: in `전광판 제어` (Display control) > `밝기` (Brightness), tap one of `100%` · `75%` · `50%` · `25%` · `최소` (Minimum). `최소` is 1%.
- **Page count**: in `페이지 수 / 초기화` (Page count / Clear), select 1~10 and tap `전송` (Send). The saved pages show in turn, up to this number.
- **Clear**: select the pages to delete (`전체 (페이지 1~10)` (all pages) or one of pages 1~10) and tap `초기화` (Clear).
- **Test pattern**: in `화면 점검 패턴` (Screen test pattern), select one of 8 patterns (full red, green, blue, or white, color bars, grid, horizontal stripes, module borders) and tap `켜기` (On). Tap `끄기` (Off) to go back to the original screen.

> [!warning] You cannot undo a clear
> The confirmation window shows "지운 문구는 되돌릴 수 없습니다 (보드 영구 반영)" (Deleted text cannot be restored — saved permanently on the board). A page count change is also saved permanently on the LED display.

## 7. Screen size

![[db720-web-05-size.png|300]]

- The unit is **the number of 16px modules**. `세로` (Height) 2 × `가로` (Width) 6 is 32px × 96px, and the pixel count shows below the fields right away.
- Each field accepts 1~60. When you open the sheet, the fields show the current values of the LED display.
- When you tap `적용` (Apply), the confirmation window "세로 2(32px) x 가로 6(96px)로 바꿀까요?" (Change to this size?) appears.
- After you apply, **"적용했어요 — 보드가 재시작 중입니다(약 10초)"** (Applied — the board is restarting) appears, and the connection dot turns red for a moment. After about 10 seconds, it comes back by itself.
- If the LED display cannot accept the size, a message such as **"이 보드는 6열×4단을 다 못 해요 — 6열×2단으로 적용됐어요"** (This board cannot do all of it — a smaller size was applied) tells you the value that was actually applied.

> [!note] For installers
> Set the screen size once at installation, to match the actual number of modules. Store owners do not need to change it.

## 8. Settings

![[db720-web-06-settings.png|300]]

- `이름` (Name): up to 20 characters, such as the store name. The title at the top left of the home screen (`내 전광판` (My display)) changes to this name. It is saved only on this phone.
- `컨트롤러 주소 (고급)` (Controller address (advanced)): the address of the LED display that you are connected to now. It is shown here only, and you cannot change it. To connect to another LED display, enter its address in the browser address bar.
- `API 키` (API key): it usually shows **"키 없음"** (No key), and you cannot enter a key. On an LED display with a key set, it shows "설정됨 (마스킹)" (Set (masked)).

## 9. Troubleshooting

| Problem | Cause | What to do |
| --- | --- | --- |
| The connection dot is not green (red or gray) | The phone and the LED display are on different Wi‑Fi networks, or the LED display power is off | Change the phone Wi‑Fi to the same router as the LED display, check the power, and refresh |
| You sent text, but the LED display did not change | You missed a failure notice, or another program is sending camera video | Send again and read the notice. If the confirmation window "카메라 영상 송출 중" (Camera video is playing) appears, switch to saved content in that program |
| The preview is blurred | It is a screen from another program, or a saved page | This is normal. When you send text, that text looks sharp |
| The preview is black, or shows "미리보기 일시 중단" (Preview paused) | The video stopped for a moment | Wait a few seconds. If it continues, refresh |
| You tapped `100%`, but "밝기 99%" (Brightness) appears | The maximum that the LED display accepts is 99 | This is normal. 99% is the brightest value |
| The connection drops for a moment after you apply a screen size | The LED display restarts with the new size (about 10 seconds) | Wait, then open `화면 크기` (Screen size) again and check the values |
| Special characters or emoji do not appear | The LED display font does not have these characters | Use Korean, English letters, numbers, and basic symbols |
| Text changed from another phone is not in my `문구 작성` (Write text) fields | The fields remember only what this phone sent last | Check the current screen in the preview. Refresh the home screen to get the latest state |
| The phone says "No internet" and drops the Wi‑Fi | The phone drops a Wi‑Fi network without internet by itself, or changes to mobile data | In the phone's Wi‑Fi settings, set it to keep that network, and turn off automatic switching to mobile data |

## 10. Not available yet

> [!warning] Do not say these work until they are confirmed
> The items below are still being checked, or do not work with the current design. If you say that they work, customers on site lose trust.

- **Background image in the preview**: `전광판 제어` (Display control) > `배경이미지` (Background image) > `적용` (Apply), and `문구 작성` (Write text) > `전문 옵션` (Advanced options) > `배경이미지` (Background image), apply correctly on the LED display. But the phone preview does not show the background (being checked in the firmware).
- **Remote access from outside the store**: it works only on the same Wi‑Fi. To use it from outside, you need a separate relay service.
- **Direct phone connection**: there is no function to connect a phone directly to the LED display by Bluetooth or Wi‑Fi. The connection always goes through a router.
- **Uploading screen files over the web**: this function needs an API key, so this screen does not offer it.
