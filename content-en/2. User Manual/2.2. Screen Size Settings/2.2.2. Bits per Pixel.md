title: 2.2.2. Bits per Pixel
---

> [!abstract] About the BPP (bits per pixel) option of the LED display screen configuration

#### 2BPP (3 colors)
- Bits: 2bpp (2 bits per pixel). One pixel uses 2 bits (0 or 1)
- Values: $2^2$ = 4 values (including off, `00`) → 3 colors
	- `00`: Black
	- `10`: Red
	- `01`: Green
	- `11`: Yellow
#### 3BPP (8 colors)
- Bits: 3bpp (3 bits per pixel). One pixel uses 3 bits (0 or 1)
- Number of colors: $2^3$ = 8 colors 
	- `000`: Black
	- `100`: Red
	- `010`: Green
	- `001`: Blue
	- `110`: Yellow
	- `101`: Magenta
	- `011`: Cyan
	- `111`: White
	- ![[빛의삼원색.png|300]]
#### 8BPP (256 colors)
- Bits: 8bpp (8 bits per pixel)
- Number of colors: $2^8$ = 256 colors
- **V4.5.4 or later (official)**: all models use 256 colors (only the DB720 16-bit color option uses 65,536 colors) — DB400 · DB402 · DB500 · DB502 · DB600 · DB520 · DB720. To keep 256 colors, the maximum number of columns is smaller (DB500S · DB600S · DB600T 16 columns, DB600U 8 columns, DB400S · DB402S 10 columns) — see [[3.2. Maximum Modules per Controller]]
- **Before the V4.5.4 upgrade (V4.0.3 or earlier)**: DB400 · DB402 · DB500 · DB502 · DB600 used 8 colors (DB520 · DB720 used 256 colors from the start). DB400 · DB402 boards that shipped earlier can also be upgraded to V4.5.4 (256 colors) with the `_legacy_v1` · `_legacy_v2` files (only DB502 boards that shipped earlier stay at V4.0.3) — [2.10.1. Reading Firmware Information and Uploading Firmware](https://docs.dabitsol.com/2.10.1) (Korean)
#### 16BPP (65,536 colors)
- Bits: 16bpp (16 bits per pixel)
- Number of colors: $2^{16}$ = 65,536 colors
- Used with the **DB720 16-bit color option** (DB725T 4 rows × 16 columns · DB725U 8 rows × 12 columns): 32 levels of red · 64 of green · 32 of blue. The standard DB720 · DB520 and the other models use 256 colors (8BPP) — [[3.2. Maximum Modules per Controller]]
- For how to connect DB720 through the DBS540 hub, see [[3.33. DBS540 Hub Connection Guide]] (DB520 supports direct connection only)
