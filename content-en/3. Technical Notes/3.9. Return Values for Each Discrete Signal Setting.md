> [!abstract] Return values and input methods for each discrete signal setting

#### Definitions of HEX, Number, and BCD

|     | Number (decimal)      | HEX (hexadecimal)                                 | HEX to binary          | BCD                      |
| --- | :---------------- | :---------------------------------------- | ------------------- | ------------------------ |
| Definition  | The integers that we usually use | Shows a value with digits and letters<br>Uses 0-9 and A-F (10-15) | Changed to binary to show on the Discrete Signal Input Board | Shows each digit of a decimal number as a 4-bit binary number |
| Example  | 1                 | 0x1                                       | 0000 0001           | 0000 0001                |
|     | 9                 | 0x9                                       | 0000 1001           | 0000 1001                |
|     | 10                | 0xA                                       | 0000 1010           | 0001 0000                |
|     | 11                | 0xB                                       | 0000 1011           | 0001 0001                |
|     | **99**            | 0x63                                      | 0110 0011           | **1001 1001**            |
|     | 100               | 0x64                                      | 0110 0100           | 0001 0000 0000           |
|     | 128               | 0x80                                      | 1000 0000           | 0001 0010 1000           |
|     | **255**           | 0xFF                                      | **1111 1111**       | 0010 0101 0101           |
|     | 256               | 0x100                                     | 0001 0000 0000      | 0010 0101 0110           |

1. **Decimal (Number)**:
    - The number system that we use every day
    - Uses the digits 0 to 9.
    - For example, decimal 99 means the usual number 99 that we know
2. **Hexadecimal (HEX)**:
    - Shows a value with digits and letters
    - Uses 0-9 and A-F (10-15)
    - Example: decimal 9 is 0x9 in hexadecimal, 15 is 0x0F, 99 is 0x63, and 255 is 0xFF
3. **Binary**:
    - A number system that uses only 0 and 1
    - Example: decimal 9 is 1001 in binary, 15 is 0000 1111, and 255 is 1111 1111.
4. **BCD (Binary-Coded Decimal)**:
    - Shows each digit of a decimal number as a 4-bit binary number
    - Example: decimal 9 is 1001 in BCD, 15 is 0001 0101, 99 is 1001 1001, and 255 is 0010 0101 0101

#### Return values
- The input method (HEX, BCD, Number) changes how the discrete input signal is read. This sets the value that the LED display shows
- The process reads the input signal from the state of each pin, reads it in one of these ways, and then decides which number to show
- To show the background image number that you registered when you connect the Discrete Signal Input Board, set `8pin Input(HEX, BCD, Number)`
	- DabitOne: `고급` (Advanced) > `보드기능설정` (Board settings) > `BH1(10핀) 모드` (pin mode)
	- Here you can select one of three options: HEX, Number, or BCD

|     |               |  S8  |  S7  |  S6  |  S5  | S4  | S3  | S2  | S1  | SUM |
| --- | ------------- | :--: | :--: | :--: | :--: | :-: | :-: | :-: | :-: | :-: |
| HEX | Return value           | 0x80 | 0x40 | 0x20 | 0x10 | 0x8 | 0x4 | 0x2 | 0x1 |     |
|     | Decimal          | 128  |  64  |  32  |  16  |  8  |  4  |  2  |  1  |     |
|     | Example            |  0   |  0   |  1   |  0   |  0  |  0  |  0  |  1  | 33  |
|     | Maximum           |  1   |  1   |  1   |  1   |  1  |  1  |  1  |  1  | 255 |
| BCD | Return value<br>(decimal) |  80  |  40  |  20  |  10  |  8  |  4  |  2  |  1  |     |
|     | Example            |  0   |  0   |  1   |  1   |  0  |  0  |  1  |  1  | 33  |
|     | Maximum           |  1   |  0   |  0   |  1   |  1  |  0  |  0  |  1  | 99  |
| NUM | Return value           |  8   |  7   |  6   |  5   |  4  |  3  |  2  |  1  |     |

1. **HEX**
	- Return values:  S8> `0x80, 0x40, 0x20, 0x10, 0x8, 0x4, 0x2, 0x1` >S1
	- For example, if S6 and S1 are connected:
		- 1x32 + 1x1 = 33
		- Shows background image 33
	- The Discrete Signal Input Board has 8 pins. **If all pins are 1, the maximum value is 0xFF (255)**
2. **BCD**
	- Return values: S8> `80, 40, 20, 10, 8, 4, 2, 1` >S1
	- For example, if S6, S5, S2, and S1 are connected:
		- 1x20 + 1x10 + 1x2 + 1x1 = 33
		- Shows background image 33
	- The Discrete Signal Input Board has 8 pins, so **the BCD format can show two digits, up to 99**
3. **NUM**
	- Return values: S8> `8, 7, 6, 5, 4, 3, 2, 1` >S1
	- For example, if only S8 is connected, it returns 8. If only S1 is connected, it returns 1
	- The maximum value in the NUM format is 8
