
> [!abstract] 페이지 문구로 배경이미지를 만들어 패킷 또는 접점보드를 이용하여 표출


#### 1. 배경화면 표시 목록(.bgp) 전송

1. DabitOne 실행 및 통신 연결
2. 페이지 문구 페이지 개수 등록 (페이지 개수: 5 > 전송)
	- DabitOne: `전송` > `페이지메시지` > `페이지 수`
	- DBPS: `설정` > `페이지 메시지 설정` > `총 개수 설정`
	- 다빛채: `고급설정` > `Protocol Simulator` > `특수기능` > `페이지문구 페이지 개수`
3. 표시 파일 등록 및 업로드 
	- DabitOne `편집` 탭 표시목록에서 일반문구 5개 등록
	- 파일 형식을 `배경 파일 (*.bgp)`로 선택하여 저장
	- `전송` 버튼으로 업로드

이 단계를 완료하면 일반문구 5개(기본값)가 순서대로 반복 표시

#### 2. 페이지 문구 패킷 전송

- DabitOne에서 페이지 문구 패킷 전송 (레거시: DBPS, 다빛프로토콜시뮬레이터, 다빛채에서도 동일 패킷 전송)
- 전송예시
	- `![001/P0000/C1안녕하세요!]`
	- `![001/P0100/C2반갑습니다!]`
	- `![001/P0200/C3감사합니다!]`
	- `![001/P0300/C6가나다라마바!]`
	- `![001/P0400/Y0004/E0606/S1000/C7방문을 환영합니다.!]`


이 단계를 완료하면 위의 입력한 페이지 문구 5개가 순서대로 반복 표시

#### 3. 공백 표시 목록(.pla) 전송

1. 아무것도 입력하지 않은 공백 화면 1개(.dat)를 만들어 저장
2. 표시 파일 등록 및 업로드
	- DabitOne `편집` 탭 표시목록에 공백화면 1개만 등록
	- 파일 형식을 `스케줄 파일 (*.pla)`로 선택하여 저장
	- `전송` 버튼으로 업로드

#### 4. 페이지 번호 호출하여 표시
