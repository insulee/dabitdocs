
> [!abstract] 신형 컨트롤러의 확장 ASCII 명령을 기능별로 정리하고, 기존(구) 숫자형 명령과의 대응 관계를 안내합니다
> 명령 구조·응답 규칙은 [[2.9.1. 신 ASCII 프로토콜 소개]]를 먼저 읽어 주세요.

> [!note] 표 읽는 법
> - **구 명령**: 기존 숫자형 특수 명령 코드 (`![0042!]` 형태의 두 자리). "신규"는 신형에서 새로 생긴 기능
> - **응답**: `0/F`=쓰기 ACK(시리얼 기준), `JSON`=공백 1칸 뒤 JSON, `echo`=보낸 값 회신
> - 여기 없는 관리·진단용 명령(공장초기화 등)은 안전상 별도 안내로만 제공합니다 — 고객지원으로 문의해 주세요

## 1. 시스템·정보 조회

| 신 명령 | 기능 | 구 명령 | 응답 | 비고 |
| --- | --- | --- | --- | --- |
| `![00M1!]` | 시스템(펌웨어) 정보 문자열 | `81` | 정보 문자열 | |
| `![00M2!]` | 펌웨어 버전 상세 | `97` | JSON | |
| `![00NJ!]` | 펌웨어 버전·빌드일 | 신규 | JSON | `{"v":"...","date":"..."}` |
| `![00NK!]` | 보드 정보 일괄(모델·버전·색상능력·화면크기) | 신규 | JSON | 연동 시 기기 식별에 권장 |
| `![00NF!]` | 메모리·가동시간 | 신규 | JSON | |
| `![00NI!]` | 부팅 정보·리셋 사유 | 신규 | JSON | |
| `![00NG!]` | 네트워크 상태(이더넷·IP·MQTT) | 신규 | JSON | |
| `![00NC!]` / `![00ND!]` / `![00NE!]` | USB / SD / 내장 저장소 상태 | 신규 | JSON | 미지원 보드는 `F` |
| `![00NA!]` | 디스플레이 성능(fps 등) | 신규 | JSON | |

## 2. 시간·화면 제어

| 신 명령 | 기능 | 구 명령 | 응답 | 비고 |
| --- | --- | --- | --- | --- |
| `![00K0{YYMMDD}{d}{HHMMSS}!]` 쓰기 / `![00K0!]` 읽기 | 시간(RTC) 설정·조회 — d=요일(0=일 ~ 6=토) | `30`/`31` | `0/F` · JSON | 값 없으면 읽기 |
| `![00H0!]` | 화면 크기 조회 (**픽셀 단위**) | `40`/`43` | JSON | 구 명령은 모듈 단위였음 |
| `![00H2S{패턴}!]` 쓰기 / `![00H2!]` 읽기 | 표출신호(스캔 패턴) 설정·조회 | `44`/`45` | echo `![00H2 S{패턴}!]` | **V3.8.3+**. 값에 공백 넣으면 `F5` |
| `![00H3{n}!]` / `![00H3!]` | 색상모드(0=8색/1=256색/2=16비트) 설정·조회 | `47`/`48` | JSON | 조회 시 24비트(24C)는 읽기 전용 표시 |
| `![00H4{nnn}!]` | 배경이미지 표출(000~255) | `20` | `0/F` | |
| `![00H6{0~7}!]` | 화면 단색 채우기 | `70` | `0/F` | |
| `![00H7{NNNN}!]` / `![00H7!]` | 화면 주사율 목표(Hz) 설정·조회 — 0000=자동 | 신규 | echo · JSON | 재부팅 불필요. **DIBD520·720 전용** (그 외 `F3` — 실측) |
| `![00J0{NN}!]` / `![00J0!]` | 밝기(00=자동, 01~99) 설정·조회 | `50`/`51` | `0/F` · 단일값 | |
| `![00J3{NN}!]` | 점멸 횟수(00~21) | `55` | `0/F` | |
| `![00J4{HHVV}!]` | 폰트 두께(가로·세로 각 10~30 = 1.0~3.0배) | `56` | `0/F` | |

## 3. 표출·메시지

| 신 명령 | 기능 | 구 명령 | 응답 | 비고 |
| --- | --- | --- | --- | --- |
| `![00L0{NN}!]` | 페이지 메시지 개수(01~10) | `60` | `0/F` | |
| `![00L1{NN}!]` | 페이지 삭제(00~09, 99=전체) | `61` | `0/F` | |
| `![00L2!]` | 실시간 메시지 삭제 | `62` | `0/F` | |
| `![00P3{0\|1}!]` | LED 전원 OFF/ON | `21` | `0/F` | |
| `![00P4!]` | 화면 복구(진단 화면 해제 + 스케줄 재생) | 신규 | `0/F` | 재부팅 없이 복구 |
| `![00NB{0~9,A}!]` | 진단 테스트 패턴(0=해제, 5=컬러바 등) | 신규 | echo | 30초 후 자동 해제 |
| `/K{nn}` 속성 | 64색 문자색 | 신규 | — | [[2.9.3. 64색 문자색 (K 속성)]] 참고. **V4.1.3 확인** |

## 4. 미디어 재생 (신형 콘텐츠)

| 신 명령 | 기능 | 구 명령 | 응답 | 비고 |
| --- | --- | --- | --- | --- |
| `![00V3 {id}!]` | 미디어 콘텐츠 재생 (공백 1칸 + 콘텐츠 id) | 신규 | JSON echo | **V4.1.3 + DIBD520·720 전용** (구펌·타 기종은 `F`) |
| `![00V4 1!]` | 미디어 재생 중지 (**` 1` 인자 필수**) | 신규 | JSON echo | 인자 없으면 `F1`. DIBD520·720 전용 |

> [!note]
> 미디어 파일 업로드·목록·삭제는 ASCII가 아니라 별도 네트워크 API로 동작하며, DabitOne의 `미디어 재생` 창이 이를 대신 처리합니다 — [[2.7.5. 미디어 재생 (변환 없이 사진·영상 전송)]] 참고. 미디어 콘텐츠와 기존 방식(표시목록) 콘텐츠는 전광판에 **동시에 저장되지 않습니다** (한쪽을 보내면 다른 쪽이 삭제됨).
