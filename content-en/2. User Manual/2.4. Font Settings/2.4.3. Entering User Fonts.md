title: 2.4.3. Entering User Fonts
---

> [!abstract] How to show arrows, special symbols, emoji, and so on with a user font, and the code tables


- You can make the characters that you want, such as arrows (←→↑↓↔↖↗↙↘◀▲▶▼), special symbols (♠♥♣♦♬♭☎), emoji, Greek letters (αβγ), and narrow or wide Latin letters/digits, and show them on the LED display with the ASCII/HEX protocol
- The user font size is based on 16x16 pixels, and you can make up to 999 characters
- Use a user font whose name starts with USER in the Font folder of DabitOne (for DBPS · DabitChe, the `Sys > Font` folder). If necessary, edit or enter the characters that you want with the fontman.exe program
- The example code tables below can be different from the font that you actually use. Check them with the fontman.exe program


### User font code tables and packet examples
- The tables below are made-up examples. Check the contents of the font that you will actually use with fontman.exe, and then enter the codes
