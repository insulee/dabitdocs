
> [!abstract] Server TCP/IP, UDP 설정
> Server TCP/IP와 UDP 연결 시 네트워크 환경에 따른 상세 설정 절차를 안내

### 통신 방식
- 다빛솔루션의 전광판 컨트롤러 및 LAN to Serial 컨버터는 다양한 산업 환경과 사용자 요구사항에 맞춰 네 가지 통신 방식을 지원
-  Serial 통신
	- TTL, RS232/485를 통한 직렬 통신
	- 근거리 일대일 통신에 적합
- Client TCP/IP (기본 설정)
	- 컨트롤러가 Server, 프로그램(PC, PLC, 서버)이 Client 역할을 수행
	- 가장 일반적이고 안정적인 통신 방식
	- 상세 연결 방법은 아래 문서 참조
		- [[2.1.1. 이더넷 통신 설정]]
		- [[2.1.2. LAN to Serial 컨버터 통신 설정]]
- Server TCP/IP
	- 컨트롤러가 Client 역할을 수행
	- 중앙 서버 시스템 구축 시 활용
- UDP
	- 비연결형 프로토콜
	- 빠른 데이터 전송이 필요한 경우에 적합
### 설정 방법
#### Server TCP/IP 설정
- Server TCP/IP 설정 가능한 장치
	-  TCP/IP 통신이 가능한 컨트롤러(DB500, DB600)
	- LAN to Serial 컨버터
		- 이더넷 버전
		- Wifi(station모드) 버전
- dbNet > `Network` > `Search`
	- Board List: 연결하려 컨트롤러/컨버터의 Mac address 선택
	- Controller Client Mode(Server TCP/IP) 체크
	- Server IP, Server Port 입력
	- `Set`
	- `Search` > 네트워크 정보 변경 확인
	- `Add`
	- Server TCP/IP 체크 및 정보 확인

- (참고) 연결되지 않을 때
	- 서버와 장치(컨트롤러/컨버터)의 네트워크 정보가 동일해야 연결 가능
	- 동일하지 않는 경우 IP Address(앞 3개 옥탯), Subnet Mask, Gateway, Port를 서버에 맞춰서 변경


#### UDP 설정
- Server TCP/IP 설정 가능한 장치
	- TCP/IP 통신이 가능한 컨트롤러(DB500, DB600)
	- LAN to Serial 컨버터
		- 이더넷 버전
		- Wifi(station모드) 버전

- dbNet > `Network` > `Search`
	- Board List: 연결하려 컨트롤러/컨버터의 Mac address 선택
	- IP Address(앞 3개 옥탯), Subnet Mask, Gateway, Port를 서버에 맞춰서 변경
	- **(중요) Port: 5108(Ethernet 연결시), 5107(wifi 연결시)**
	- `Set`
	- `Search` > 네트워크 정보 변경 확인
	- `Add`
	- UDP 체크
		- IP Address: 컨트롤러/컨버터의 `IP Address`
		- IP Port: 컨트롤러/컨버터의 `IP Port` (Ethernet: `5108`, wifi: `5107`)
