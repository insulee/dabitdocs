title: 7.2. Built-in GIF Editor
---

> [!abstract] Built-in GIF editor (new in DabitOne)
> A tool to make content with several scenes (frames), such as blinking and cycling text, directly in the app

#### What is better

- In the legacy programs, you made GIFs with an external program and could **only load** them
- In DabitOne, you **make and edit them directly in the app** — you can make simple moving content yourself on site
- Work with a pixel canvas + a 16-color palette + a frame timeline (add · duplicate · delete · play)

#### How to use

1. In the `편집` (Edit) tab, click the `GIF 편집` (GIF edit) button
2. Draw on the canvas, and add frames in the timeline below
3. Set the display time (delay) for each frame
4. Click `저장` (Save) to make the GIF file

> [!note] Note
> The GIF editor is a separate tool. Load the file that you made into the schedule separately — the editor does not send it directly.
