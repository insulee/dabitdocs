title: 3.23. Message Entry and Exit Effect Codes
---

> [!abstract] Message entry and exit effect codes
> Effect direction options and descriptions in the entry and exit effect code tables of the ASCII and HEX protocols
#### Stop effect (Stop)

| ASCII | HEX  | Direction | Description |
| ----- | ---- | ---------------- | --------------------- |
| 01    | 0x01 | None       | Stop effect (default) |
| 02    | 0x02 | BrightOn   | The text gets brighter gradually |
| 03    | 0x03 | BrightOff | The text gets darker gradually |
| 04    | 0x04 | HoriMirror | The mirrored image and the normal image repeat |
| 05    | 0x05 | VerMirror  | The mirrored image and the normal image repeat |

#### Shift effect (Shift)
- The text moves 1 pixel at a time

| ASCII | HEX  | Direction | Description |
| ----- | ---- | ---------- | ------------- |
| 06    | 0x06 | Left   | Moves from right to left |
| 07    | 0x07 | Right | Moves from left to right |
| 08    | 0x08 | Up     | Moves from bottom to top |
| 09    | 0x09 | Down  | Moves from top to bottom |

#### Wipe effect (Wipe)
- The text appears on the screen 1 pixel at a time
- Entry effect and exit effect by direction
	- In the set direction, the entry effect shows the text and the exit effect hides the text
	- Example: when the direction is Left, the entry effect shows the text from right to left, and the exit effect hides the text from right to left

| ASCII | HEX  | Direction | Description |
| ----- | ---- | ---------- | --------------- |
| 12  | 0x0C | Left   | Wipes from right to left |
| 13  | 0x0D | Right | Wipes from left to right |
| 14  | 0x0E | Up     | Wipes from bottom to top |
| 15  | 0x0F | Down  | Wipes from top to bottom |

#### Blind effect (Blind)
- Each character appears as if a blind opens

| ASCII | HEX  | Direction | Description |
| ----- | ---- | ---------- | --------------- |
| 18  | 0x12 | Left   | Appears from right to left |
| 19  | 0x13 | Right | Appears from left to right |
| 20  | 0x14 | Up     | Appears from bottom to top |
| 21  | 0x15 | Down  | Appears from top to bottom |

#### Curtain effect (Curtain)
- The effect works from the middle of the set module area for the whole text
- `Horizontal`: the center of the module width is the reference
- `Vertical`: the center of the module height is the reference
- `Outward`: the effect spreads up, down, left, and right
- `Inward`: the effect moves to the center

| ASCII | HEX  | Direction | Description |
| -------- | ---- | ------------------- | -------------------- |
| 24  | 0x18 | Hori.Side (horizontal, outward)   | Wipes from the horizontal center to the left and right |
| 25  | 0x19 | Hori.Center (horizontal, inward) | Wipes from the left and right to the horizontal center |
| 26  | 0x1A | Ver.Side (vertical, outward)    | Wipes from the vertical center up and down |
| 27  | 0x1B | Ver.Center (vertical, inward)  | Wipes from the top and bottom to the vertical center |

#### Zoom-in effect (ZoomIn)

| ASCII | HEX  | Direction | Description |
| -------- | ---- | ------------------- | --------------------- |
| 35  | 0x23 | Left            | Zooms in from right to left |
| 36  | 0x24 | Right          | Zooms in from left to right |
| 37  | 0x25 | Up              | Zooms in from bottom to top |
| 38  | 0x26 | Down           | Zooms in from top to bottom |
| 39  | 0x27 | Right Down | Zooms in from top left to bottom right |

#### Rotate effect (Rotate)

| ASCII | HEX  | Direction | Description |
| ----- | ---- | ------------------- | --- |
| 40  | 0x29 | Counterclockwise 1  | The whole text rotates counterclockwise |
| 41  | 0x28 | Clockwise 1 | The whole text rotates clockwise |
| 42  | 0x2B | Counterclockwise 2  | The whole text is split in two horizontally and rotates counterclockwise |
| 43  | 0x2A | Clockwise 2 | The whole text is split in two horizontally and rotates clockwise |

#### Background blink effect (Blink, 8 times)

| ASCII | HEX  | Direction | Color |
| ----- | ---- | ---------- | --- |
| 44  | 0x2C | Red    | Only the red background blinks |
| 45  | 0x2D | Green  | Only the green background blinks |
| 46  | 0x2E | Yellow   | Only the yellow background blinks |
| 47  | 0x2F | White  | Only the white background blinks |
| 48  | 0x30 | All Sequential | The backgrounds of all colors blink in sequence |

#### Text color blink effect (Blink, 8 times)

| ASCII | HEX  | Direction | Color |
| ----- | ---- | --------- | --- |
| 49  | 0x31 | Red   | Only red text blinks |
| 50  | 0x32 | Green | Only green text blinks |
| 51  | 0x33 | Yellow  | Only yellow text blinks |
| 52  | 0x34 | White | Only white text blinks |
| 53  | 0x35 | All Sequential | Text of all colors blinks in sequence |
| 55  | 0x37 | All Simultaneous | Text of all colors blinks at the same time |

#### 3D effect (3D)

| ASCII | HEX  | Direction | Description |
| ----- | ---- | --------- | --- |
| 54  | 0x36 | Left   | The text rotates in 3D as it appears |
