
> [!abstract] 완성형 한글 코드표 매뉴얼


### 1. 개요

- KSC5601은 한국어 문자 세트를 정의하는 완성형 한글 인코딩 표준으로, 1987년 한국정보통신표준(KS X 1001)에서 제정
- 이 표준의 한글은 자주 쓰는 완성형 글자 2,350자이며, 한자 · 특수문자와 함께 2바이트 코드(94×94 배열)로 표현


### 2. KSC5601 코드 영역

#### 2-1. 주요 코드 범위

| 코드 영역         | 설명            | 범위              |
|-------------------|----------------|-------------------|
| 한글 완성형 문자  | 완성형 한글 2,350자 | 0xB0A1 ~ 0xC8FE  |
| 한자 및 특수문자  | 한자와 특수 기호 포함 | 기타 영역          |

#### 2-2. 한글 완성형 문자 구조

- 한글 2,350자를 **가나다 순**으로 늘어놓고, 한 줄(행)에 94자씩 0xB0A1부터 차례로 코드를 붙였습니다
- 초성 · 중성 · 종성을 조합한 모든 글자가 들어 있지는 않습니다. 2,350자에 없는 글자(예: 똠)는 2바이트 코드가 없습니다


### 3. 한글 코드값 찾는 방법

> [!warning] 초성 · 중성 · 종성 인덱스로는 계산할 수 없습니다
> KSC5601 한글은 쓰는 글자만 골라 늘어놓은 표라서, 자모 인덱스로 코드값을 계산할 수 없습니다. `(초성 × 588) + (중성 × 28) + 종성` 공식은 **유니코드** 공식입니다(6.3.3 참고).

1. 표에서 글자의 **순번**(0부터)을 찾습니다 — 가 = 0, 각 = 1, 간 = 2 …
2. 순번으로 두 바이트를 구합니다
   - 첫째 바이트 = 0xB0 + (순번 ÷ 94의 몫)
   - 둘째 바이트 = 0xA1 + (순번 ÷ 94의 나머지)
3. 프로그램에서는 표를 직접 만들지 말고 EUC-KR(CP949) 변환 기능을 씁니다
   - 예(Python): `"닿".encode("euc-kr")` → `B4 EA`


### 4. 예제 계산

### 6. KSC5601 코드와 유니코드의 특징

#### 6.1. KSC5601과 Unicode의 개요

##### KSC5601

- KSC5601(KS X 1001)**은 1987년 대한민국에서 제정된 문자 집합 표준으로, 완성형 한글을 포함
- KSC5601은 2,350개의 완성형 한글과 약 8,800개의 한자, 특수문자 등을 포함한 총 94×94의 2바이트 문자 집합을 정의
- 한글은 정해진 완성형 글자 2,350자만 표현 (초성 · 중성 · 종성을 조합해 새 글자를 만들 수 없음)

##### Unicode

- Unicode는 전 세계의 모든 문자를 하나의 체계로 통합하기 위해 설계된 문자 집합 표준
- 현대 한글 11,172자를 모두 완성형으로 담고, 초성 · 중성 · 종성 자모도 따로 담음
- Unicode의 한글 범위:
    - U+AC00 ~ U+D7A3: 완성형 한글 11,172자
    - U+1100 ~ U+11FF: 한글 자모 (초성, 중성, 종성의 개별 문자)
    - U+3130 ~ U+318F: 호환용 한글 자모

#### 6.2. KSC5601과 Unicode의 주요 차이점

| 항목           | KSC5601                       | Unicode              |
| ------------ | ----------------------------- | -------------------- |
| 한글 처리 방식 | 완성형 문자만 표현 가능                 | 조합형 문자와 완성형 문자 모두 지원 |
| 문자 수     | 2,350개의 한글 문자                 | 11,172개의 한글 문자       |
| 조합 가능성   | 초성, 중성, 종성 조합 불가 (정해진 글자만 지원) | 초성, 중성, 종성 조합 가능     |
| 코드 범위    | 0xB0A1 ~ 0xC8FE               | U+AC00 ~ U+D7A3      |
| 표현 가능 문자 | 제한적 (일부 문자 표현 불가)             | 전 세계 모든 문자 표현 가능     |

#### 6.3. KSC5601과 Unicode의 매핑 관계

##### 6.3.1. 기본 매핑

- KSC5601 한글 2,350자는 Unicode 완성형 한글 11,172자(U+AC00 ~ U+D7A3) **안에 모두 들어 있지만, 1:1로 대응하지는 않음**
- 두 표 모두 가나다 순이라 글자 순서는 같지만, 사이 간격이 달라 순번끼리 더하고 빼서는 바꿀 수 없음
    - 예: "간" — KSC5601 순번 2(0xB0A3) / Unicode 순번 4(U+AC04)

##### 6.3.2. 변환 방법

- 변환은 대응표(코덱)로 함. 프로그램의 EUC-KR(CP949) ↔ Unicode 변환 기능을 사용
    - 예(Python): `"간".encode("euc-kr")` → `B0 A3` / `bytes([0xB0, 0xA3]).decode("euc-kr")` → `간` (U+AC04)

##### 6.3.3. 유니코드 순번 공식 (참고)

- Unicode 완성형 한글은 자모 조합으로 계산됨 (KSC5601에는 쓸 수 없음)
- Unicode 코드 = U+AC00 + (초성 인덱스 × 588) + (중성 인덱스 × 28) + 종성 인덱스
    - 예: "닿" = ㄷ(3) · ㅏ(0) · ㅎ(27) → (3 × 588) + (0 × 28) + 27 = 1791 → U+AC00 + 1791 = U+B2FF
