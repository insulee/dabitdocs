
> [!abstract] 컨트롤러에 배터리를 연결해 전원 차단 시에도 정확한 시간 표시를 위한 설정 방법

## 1. 홀더 부착 가능 컨트롤러 - 코인 건전지 홀더 연결

### 개요

- **컨트롤러 뒷면에 코인 건전지 홀더를 부착할 수 있는 컨트롤러(DB500, DB600)**의 경우, 홀더에 코인 건전지를 장착하면 컨트롤러 내부의 시계칩에 의해 정확한 시간 정보가 유지
- 전원 차단 시에도 코인 건전지를 통해 RTC(Real Time Clock) 기능이 계속 작동되어,  전원 재공급 시 시간 리셋 없이 시간이 정상적으로 표시됨.

### 설치 방법

1. 코인 건전지 홀더 부착
    - +, - 극성을 확인하여, 컨트롤러 뒷면의 코인 건전지 홀더 부착구에 솔더링(납땜)으로 장착
2. 코인 건전지 장착
    - 올바른 극성을 확인한 후, 코인 건전지를 삽입




## 2. 홀더 부착 불가능  컨트롤러 - DS1302 RTC 모듈 연결

### 개요

- **홀더 부착이 불가능한 컨트롤러(DB502)**의 경우, DS1302 RTC 모듈을 추가 연결하여 전원 차단 시에도 시간 정보가 초기화되지 않도록 설정
- 모듈 연결 후 보드 기능 설정을 통해 컨트롤러가 DS1302를 인식하도록 구성함.

### 연결 배선도

| **DS1302 모듈** | **컨트롤러 연결 핀** |
| ------------- | ------------- |
| **RST**       | TTL RX        |
| **GND**       | RELAY GND     |
| **CLK**       | RELAY D2      |
| **DAT**       | RELAY D1      |
| **VCC**       | RELAY 5V      |

### 설정 방법

1. DS1302 RTC 모듈 연결
    - 위 배선도에 따라 DS1302 모듈과 컨트롤러를 연결
2. 보드 기능 설정
    - (중요) 컨트롤러의 보드 기능 설정에서 **J4(4pin) Function** 항목을 **DS1302**로 선택
    - DS1302 모듈을 통한 RTC 기능이 활성화되어, 전원 차단 후에도 RTC 모듈에 저장된 시간 정보가 유지


## 3. 컨트롤러 시간 설정 확인

- DBPS > 설정 > `컨트롤러 시간읽기`
- 또는 [[10_RnD_Team/12_Area/20_Firmware/10_docs/21_펌웨어_기술문서/다빛솔루션 프로토콜/2.8.1. ASCII 프로토콜 매뉴얼|ASCII 프로토콜]] `![0031!]`을 전송해 응답을 통해 확인 가능
- 컨트롤러 전원 차단 후 전원 재공급 시 리셋 없이 시간이 정상적으로 표시되는지 확인
- 최초 시간설정을 하려면 DBPS > 설정 > `PC 시간 동기화`
