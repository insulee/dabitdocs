#### Software downloads

- Get the latest **DabitOne** from the [Dabit Solution official download page](https://dabitsol.com/en/download/)
- If you need an older version, [[Training and Directions|contact Dabit Solution]]

#### How are DabitOne and DabitChe different?

**DabitOne** and **DabitChe** are **two different programs**. DabitOne is not a new name for DabitChe.

- **DabitOne** — the new program. You can get it from the official download page
- **DabitChe** — the program you already use. **You can keep using it.** If you need it, contact Dabit Solution

**Basic tasks work in both programs**: setting the screen size, the display signal, and fonts, and making playlists. Only the menu locations and button names are different. These documents describe DabitOne, and they also give the DabitChe paths.

Only the features in `7. DabitOne New Features` are new in DabitOne. DabitChe does not have them. You can find the DabitChe menu locations in the [DabitChe manual](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf) (Korean).
