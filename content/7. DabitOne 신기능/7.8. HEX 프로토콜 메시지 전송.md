> [!abstract] 전송 탭의 HEX 프로토콜 영역은 문구 표시 속성을 화면에서 고르면 DabitOne이 패킷을 만들어 보내는 곳입니다
> 명령 문자열을 외우지 않아도 됩니다. 항목을 고르고 문구를 넣은 뒤 `HEX 전송`을 누르면 되고, 같은 내용을 `ASCII 변환`으로 ASCII 명령 문자열로 바꿔 볼 수도 있습니다.

#### 개요

- `전송` 탭은 세 영역으로 나뉩니다.
	- **HEX 프로토콜** — 문구 하나를 표시 속성과 함께 보내는 곳. 이 문서의 주제입니다
	- **ASCII 프로토콜** — 명령 문자열을 직접 입력해 보내는 곳. [[2.8.1. ASCII 프로토콜 매뉴얼]] 참고
	- **전광판 제어**(오른쪽 열) — 페이지 수·밝기·전원처럼 문구와 별개인 명령을 버튼 하나로 보내는 곳
- HEX 프로토콜과 ASCII 프로토콜은 **같은 일을 다른 형식으로** 합니다. 화면에서 고른 항목 하나하나가 ASCII 명령의 `/P`, `/D`, `/F` 같은 속성 코드와 1:1로 대응합니다.
- 언제 쓰나
	- 전광판에 문구를 띄워 보고 효과·색·크기를 바꿔 가며 확인할 때
	- 외부 시스템 연동을 준비할 때 — 화면에서 만든 설정을 `ASCII 변환`으로 문자열로 뽑아 개발자에게 전달합니다

![[hex_tab_overview.png]]

#### 사용 순서

1. `통신` 탭에서 전광판과 연결을 맞추고, `설정` 탭의 전광판 크기가 실제 보드와 같은지 확인합니다. 크기가 다르면 영역(X·Y) 좌표가 어긋납니다
2. `전송` 탭 > HEX 프로토콜에서 **메시지종류**와 **섹션**을 고릅니다
3. 표시반복·효과·폰트·영역·색을 고릅니다. 바꿀 것이 없으면 기본값 그대로 둡니다
4. 맨 아래 문구 칸에 표시할 글을 넣습니다
5. `미리보기`로 PC 화면에서 모양을 확인합니다
6. `HEX 전송`을 누릅니다. 아래 로그에 `TX:`(보낸 패킷)와 `[OK] Receive:`(전광판 응답)가 찍히면 성공입니다

> [!tip] 응답이 없을 때
> 로그에 `[OK] Receive:` 대신 `[FAIL] – 컨트롤러 응답 없음`이 찍히고 "전송 실패" 알림이 뜨면 포트는 열렸지만 전광판이 답하지 않은 것입니다. 케이블·전원·통신 속도, RS485 주소를 확인하세요. "연결 안 됨" 계열 문구는 포트나 소켓 자체가 안 열린 것이므로 `통신` 탭의 연결 방식·주소·포트를 먼저 확인합니다.

#### 항목별 설명

표의 **ASCII 대응** 열은 `ASCII 변환`을 눌렀을 때 그 항목이 어느 속성 코드로 나가는지 보여 줍니다. 코드의 뜻은 [[2.8.1. ASCII 프로토콜 매뉴얼]] 2장에 있습니다.

| 항목 | 고를 수 있는 값 | 뜻 | ASCII 대응 |
| --- | --- | --- | --- |
| 메시지종류 | 실시간 / 페이지 | 실시간은 지금 바로 한 번 띄우는 문구, 페이지는 컨트롤러에 저장해 두고 순서대로 돌리는 문구. `페이지`를 고르면 페이지 번호(1~10) 칸이 나타납니다 | `/Pxx` (페이지 번호) |
| 섹션 | 0 / 1 / 2 | 화면을 나눠 쓸 때 이 문구가 들어갈 칸 번호 | `/P__yy` (섹션 번호) |
| 표시반복 | 무한반복 / 표시안함 / 1~10회 / 20~90회 | 문구를 몇 번 보여 줄지 | `/Dxx` (99=무한) |
| 화면전환 | 즉시전환 / 순차전환 | 즉시전환은 지금 나오는 문구를 끊고 바로 바꿈, 순차전환은 지금 문구가 끝난 뒤 바꿈 | `/D__yy` (01=즉시, 00=순차) |
| 인코딩/폰트 | EUC-KR/한글조합형, UTF16/유니코드, UTF8/한글조합형, UTF8/유니코드 | PC가 보내는 문자 코드와 컨트롤러가 쓸 폰트 종류의 짝. 기본 폰트 구성이면 `EUC-KR/한글조합형` 그대로 둡니다. 유니코드 항목은 유니코드 폰트를 올린 폰트그룹에서만 — 보드 폰트와 다르면 한글이 깨지거나 빈칸으로 나옵니다 | `/Fxx` |
| 폰트크기 | 12·14·16(기본)·20·24 … 64픽셀 | 글자 높이. 그 크기의 폰트가 컨트롤러에 들어 있어야 합니다 | `/F__yy` |
| 폰트그룹 | 폰트그룹 1~4 | 컨트롤러에 저장된 폰트 묶음 중 어느 것을 쓸지 | `/Tx` |
| 입장효과 | 정지·이동·와이프·블라인드·커튼·줌·회전·배경플래시·텍스트플래시·3D효과 + 방향 | 문구가 나타날 때의 움직임. 효과를 고르면 오른쪽 방향 칸의 선택지가 그 효과에 맞게 바뀝니다 | `/Exx` |
| 퇴장효과 | 사용안함 + 입장효과와 같은 목록 | 문구가 사라질 때의 움직임 | `/E__yy` |
| 효과속도 | 0(빠름) ~ 255(느림) | 숫자가 작을수록 빠릅니다 | `/Sxx` |
| 유지시간 | 0초 ~ 9시간 | 문구가 다 나타난 뒤 화면에 머무는 시간 | `/S__yy` |
| 가로영역(X) | 0 ~ 화면 너비, 4픽셀 단위 | 문구를 넣을 가로 범위(시작~끝). `0 ~ 0`은 화면 전체 | `/Xxxyy` |
| 세로영역(Y) | 0 ~ 화면 높이, 4픽셀 단위 | 문구를 넣을 세로 범위(시작~끝). `0 ~ 0`은 화면 전체 | `/Yxxyy` |
| 배경이미지 | 사용안함 / 이미지 1~255 | 컨트롤러에 저장해 둔 배경 이미지 번호 — [[3.3. 배경이미지 제작 및 표출]] | `/Bxxx` |
| 문자색 | 0~7 숫자열 | **글자마다** 색을 정합니다. 아래 "문자색 쓰는 법" 참고 | `/Cx` |
| 배경색 | 0~7 한 자리 | 글자 뒤 배경색 | `/Gx` |
| 문구 | 자유 입력 | 전광판에 표시할 글 | 명령 끝의 본문 |

색 번호는 화면에 적힌 대로 `0:검정 1:빨강 2:초록 3:노랑 4:파랑 5:분홍 6:하늘 7:흰색`입니다.

> [!note] 영역 목록의 범위
> 가로·세로영역 목록은 `설정` 탭의 전광판 크기에 맞춰 만들어집니다. 96×32 화면이면 가로는 0~96, 세로는 0~32까지 4픽셀 단위로 나옵니다.

#### 문자색 쓰는 법

문자색 칸에는 색 번호를 **글자 수만큼** 이어서 적습니다. 첫 번째 숫자가 첫 글자 색, 두 번째 숫자가 두 번째 글자 색입니다.

| 문구 | 문자색 | 결과 |
| --- | --- | --- |
| `다빛솔루션` | `3` | 다섯 글자 모두 노랑 |
| `다빛솔루션` | `12` | 다 빨강, 빛·솔·루·션 초록 |
| `다빛솔루션` | `12345` | 글자마다 빨강·초록·노랑·파랑·분홍 |

문구가 숫자열보다 길면 **마지막 숫자가 끝까지 반복**됩니다. `미리보기`를 누르면 글자별 색이 그대로 보이므로 보내기 전에 확인하세요.

#### 버튼 4개

| 버튼 | 하는 일 |
| --- | --- |
| `초기화` | 항목을 기본값으로 되돌리고 문구를 비웁니다. 전송하지 않습니다 |
| `ASCII 변환` | 지금 고른 항목과 문구를 ASCII 명령 문자열로 바꿔 아래 ASCII 프로토콜 칸에 넣습니다. `패킷복사`로 복사해 외부 연동 개발에 쓸 수 있습니다. 전송하지 않습니다 |
| `미리보기` | 전광판 미리보기 창을 열어 PC 화면에서 모양을 보여 줍니다. 창이 열린 뒤 값을 바꿨으면 버튼을 다시 눌러야 반영됩니다 |
| `HEX 전송` | 전광판으로 보냅니다. 전송 중에는 버튼이 잠시 비활성화됩니다 |

![[hex_ascii_convert.png]]

`ASCII 변환` 결과 예 — 기본값에 문구 `다빛솔루션`을 넣은 경우:

```
![000/P0000/D9901/F0003/E0101/S2008/X0000/Y0000/B000/C1/G0/T0다빛솔루션!]
```

`/P0000`(실시간·섹션 0) `/D9901`(무한반복·즉시전환) `/F0003`(EUC-KR·16픽셀) `/E0101`(입장 정지·퇴장 정지) `/S2008`(속도 20·유지 4초) `/X0000` `/Y0000`(영역 전체) `/B000`(배경 없음) `/C1`(빨강) `/G0`(배경 검정) `/T0`(폰트그룹 1) 순서입니다.

> [!note] 문자색이 여러 자리일 때
> `ASCII 변환`은 문자색 칸의 **첫 번째 숫자**만 `/C`에 넣습니다. 글자별 색을 ASCII 명령으로 쓰려면 [[2.8.1. ASCII 프로토콜 매뉴얼]]의 `/C1빨강/C2녹색` 방식으로 직접 나눠 적습니다.

#### 오른쪽 열 — 전광판 제어

문구와 상관없이 전광판 상태를 바꾸는 명령입니다. 값을 고르고 옆 버튼을 누르면 바로 나갑니다.

| 항목 | 하는 일 | ASCII로 치면 |
| --- | --- | --- |
| 페이지메시지 > 페이지 수 | 페이지 메시지를 몇 개 돌릴지(1~10) 정해 보냅니다 | `![006005!]` (5개) |
| 페이지메시지 > 초기화 | 페이지 메시지를 지웁니다. `전체` 또는 `Page 1~10` 하나 | `![006199!]` (전체) |
| 밝기 | 100 / 75 / 50 / 25 / 5%. `고급설정`은 시간대별 밝기 창을 엽니다 | `![005050!]` (50%) |
| 전광판 켜기/끄기 | LED 출력을 켜고 끕니다. 컨트롤러 전원과는 다릅니다 | `![00211!]` / `![00210!]` |
| 배경이미지 | 저장된 배경 이미지 번호를 불러옵니다 | `![0020010!]` (10번) |
| 화면채우기 | 화면 전체를 한 색으로 채웁니다. 배선·색 확인용 | `![00707!]` (흰색) |
| 섹션별 효과 | 여러 섹션의 효과를 함께 시작할지(동시), 따로 돌릴지(개별) — [[2.5.3. 섹션별 효과 동시표출과 개별표출]] | `![0062N!]` / `![0062Y!]` |
| 전광판 화면 | 실제로 보낸 화면을 PC에 테두리 없는 창으로 띄웁니다. 전송이 아닙니다 — [[7.1. 미리보기와 전광판 화면]] | — |

#### 알아두기

- **메시지종류·페이지·섹션을 바꾸면 입력값이 따라 바뀝니다.** DabitOne은 페이지+섹션 조합마다 마지막 설정을 따로 기억합니다. 섹션 1로 바꿨더니 문구가 달라 보이는 것은 섹션 1에 저장해 둔 값이 돌아온 것입니다. 프로그램을 껐다 켜도 유지됩니다
- **로그 읽기** — `TX:` 다음이 보낸 패킷, `[OK] Receive:` 다음이 전광판 응답입니다. 로그는 접기(▼)와 `지우기`로 정리할 수 있습니다
- **효과 방향은 효과마다 다릅니다** — 이동·와이프·블라인드는 왼쪽·오른쪽·위·아래, 커튼은 수평·수직 열림·닫힘, 회전은 시계·반시계, 플래시는 색. 코드표는 [[3.23. 메시지 입장 및 퇴장 효과 코드표]]
- 페이지 메시지를 보내려면 오른쪽 열에서 **페이지 수를 먼저** 보내 두어야 합니다. 페이지 수보다 큰 번호는 표시되지 않습니다
- `미리보기`는 보내기 전 초안, `전광판 화면`은 실제로 나간 화면입니다. 둘 다 PC가 그린 근사치이므로 최종 확인은 실제 전광판으로 합니다
