title: 2.5.2. Split Display with Sections
---

> [!abstract] Sections
>  Sections are a powerful function that splits the LED display screen so that it can show several pieces of information at the same time. However, a real-time message and a page message cannot show at the same time. A real-time message has priority over a page message.

#### 1. What is a section?
- A section is an area of the LED display screen. With this function, you split the screen into several areas and show different content in each one.
- You can control each section separately. Different sections can show different messages, colors, effects, and so on at the same time.

#### 2. Main features of sections
1. Splitting
    - Split the screen into several sections to show several pieces of content at the same time
    - You set the size and position of each section
2. Separate control
    - Each section can have its own message and settings (color, effect, display speed, and so on)
    - For example, split the screen into left and right, and show different content in each part
3. Message priority limit
    - **Important**: a real-time message and a page message cannot show at the same time
    - A real-time message shows before a page message
    - If a real-time message comes while a page message shows, the page message stops and the real-time message shows
    - If you send a page message while a real-time message shows, the page message does not show
4. Many uses
    - You can set text, images, animation effects, and so on for each section separately
    - This is useful when you show the same message type (real-time or page) in several sections

#### 3. Section data structure
1. ID number
    - Each section has its own number (ID). You control the section with this number
    - ASCII protocol example
        - `P000x`: section x
2. Position and size
    - Set the start position (x, y) and size (width, height) of the section in screen pixels
    - ASCII protocol example
        - `/X0a0b/Y0c0d`: from the top left of the modules — start point (`a*4` pixels on the X axis, `c*4` pixels on the Y axis), end point (`b*4` on the X axis, `d*4` pixels on the Y axis)
3. Content of each section
    - Set different content for each section, such as real-time messages, page messages, and images

#### 4. Examples of sections

> [!warning] Message type limit
> A real-time message and a page message cannot show at the same time. When you split the screen into sections, use the same message type.

**Splitting into sections with real-time messages**
1. Parking lot LED display
    - Left section: number of free parking spaces (real-time message)
    - Right section: current time (real-time message)
2. Traffic information sign
    - Top section: live traffic conditions (real-time message)
    - Bottom section: current date and time (real-time message)

**Splitting into sections with page messages**
1. Multipurpose advertising display
    - Top section: advertising text 1 in rotation (page message)
    - Bottom section: advertising text 2 in rotation (page message)
2. Information LED display
    - Left section: information text in rotation (page message)
    - Right section: caution text in rotation (page message)

**Examples of message priority**
- When a page message shows in the right section
    - If you send a real-time message to the left section → the page message on the right stops, and only the real-time message on the left shows
- When a real-time message shows in the top section
    - If you send a page message to the bottom section → it does not show (the real-time message has priority)

> [!note] For how to split sections with the ASCII protocol, see [[2.8.2. ASCII Protocol Examples#2. Sections and horizontal and vertical positions]]
