title: 7. DabitOne 신기능
---

> [!abstract] DabitOne에서 새로 생긴 기능 모음
> 레거시(DBPS·다빛채)에는 없던, DabitOne에서 추가하거나 크게 개선한 기능 모음. 항목을 누르면 자세한 사용법으로 이동

- [[7.1. 미리보기와 전광판 화면]] — 보내기 전 미리보기 + 보낸 후 실제 표출 화면
- [[7.2. 내장 GIF 편집기]] — 앱 안에서 점멸·순환 같은 여러 장면(프레임) 콘텐츠를 직접 제작
- [[7.3. 공장초기화 2단계]] — 콘텐츠만 지우기(소프트) / 전체 초기화(강력) 선택
- [[7.4. IP 주소 입력 편의]] — 숫자만 누르면 점(.)이 자동으로 찍힘
- [[7.5. 색상모드 전환]] — 색상 표현 모드 확인·전환 (고급)
- [[7.6. 이미지 자동 DAT 변환]] — 일반 이미지를 고르면 즉시 .dat로 변환해 목록에 등록
