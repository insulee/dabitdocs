 
> [!abstract] 이미지 변환
> - DabitOne: 별도 변환 단계 없음 — `콘텐츠 편집`에서 저장하는 순간 .dat/.ani 파일이 자동 생성
> - 다빛채(레거시): .pla 또는 bgp파일을 만들어 컨트롤러에 업로드하기 위해  bmp/jpg 파일을  dat 파일로, gif 파일을 ani파일로 변환하는 과정
> - **(중요)** 다빛채(레거시): 모듈의 종류가 3컬러, 풀컬러에 상관없이 사전에 **픽셀당 비트수를 3BPP(8Color)**로 설정하는 것을 권장 (DabitOne은 저장 시 자동 적용되므로 설정 불필요)

### DabitOne

DabitOne에는 다빛채의 "이미지 변환" 같은 별도 메뉴 없음 — `콘텐츠 편집` 창에서 콘텐츠를 만들고 `저장`하는 순간 .dat(이미지)·.ani(동영상) 파일이 자동으로 생성

#### 이미지(bmp/png/jpg)를 dat 파일로
1. `편집` 탭 > `콘텐츠 편집`
2. 이미지 줄의 `찾기` > 이미지 파일(.bmp/.png/.jpg) 선택
	- 이미지는 원본 크기 그대로 블록 위치(X, Y)에 배치, 블록 영역(W, H) 밖은 잘림
	- .dat 파일도 배경 이미지로 불러오기 가능
3. `저장` 또는 `다른이름저장` > .dat 파일 생성 (기본 폴더 `Data\Image`)
	- 〔캡처 1장〕

#### 문자를 dat 파일로
1. `편집` 탭 > `콘텐츠 편집`
2. `메인 블록`에 문구를 입력하고 폰트·크기·색상 선택
	- 글꼴 옵션 상세: [[7.8. 시스템 글꼴과 글자 크기]]
3. `저장` 또는 `다른이름저장` > .dat 파일 생성

#### gif 애니메이션 이미지를 ani 파일로
1. `편집` 탭 > `콘텐츠 편집`
2. `GIF 찾기` > 이미지 파일(.gif) 선택
3. `저장` 또는 `다른이름저장` > 파일 형식이 자동으로 `ANI 파일 (*.ani)`로 바뀌어 저장 (기본 폴더 `Data\Video`)
- GIF 자체를 만들거나 고치는 방법은 [[7.3. 내장 GIF 편집기]] 참고

#### 표시파일명에서 바로 변환 (빠른 방법)
- `편집` 탭 표시목록의 `표시파일명` 더블클릭 > `이미지` > 파일 선택 창에서 파일 형식을 `이미지 (*.bmp;*.png;*.jpg)`로 바꾼 뒤 이미지 파일 선택
	- 파일 형식 기본값은 `DAT 파일 (*.dat)` — 이미 만들어 둔 .dat 파일을 그대로 고르면 변환 없이 항목에 바로 등록
- 전광판 크기로 자동 변환된 .dat가 `Data\Image` 폴더에 즉시 생성되고 항목에 등록 (예: `msg001.dat`)
- 이때 이미지는 비율과 상관없이 전광판 크기로 늘어나거나 줄어듦 — 비율을 지키려면 `콘텐츠 편집`의 `찾기` 사용

#### 다빛채와 달라진 점
- 변환 메뉴 없음 — 저장이 곧 변환
- .dat/.ani 저장 시 같은 이름의 `.blocks.json` 파일이 함께 저장 — `콘텐츠 편집` > `열기`로 다시 불러와 수정할 때 필요하므로, 파일을 다른 PC로 옮길 때 함께 복사
- 저장한 .dat/.ani는 [[2.7.3. 표시목록 만들기]]에서 표시목록(.pla/.bgp)으로 묶어 전송

### 다빛채 (레거시)

#### bmp/jpg 그래픽 이미지를 dat 파일로 변환
- `표시파일작성` > `이미지 편집` > 이미지 편집 창
	- `이미지 고급편집` 체크
	- `배경이미지 불러오기` 체크
	- 메인이미지 오른쪽에 `...` 클릭하여 이미지(.bmp/.jpg) 불러오기
	- `저장하기` >  .dat(또는 .daz) 파일로 저장 

#### 이미지 편집 창에서 글자를 입력해 dat 파일로 저장
 - `표시파일작성` > `이미지 편집` > 이미지 편집 창
	 - 텍스트 입력 및 크기, 정렬, 색상 선택
	 - `저장하기` >  .dat(또는 .daz) 파일로 저장 

#### gif 애니메이션 이미지를 ani 파일로 변환
- `표시파일작성` > `이미지 편집` > 이미지 편집 창
	- `GIF 편집` 체크
	- 메인이미지 오른쪽에 `...` 클릭하여 이미지(.gif) 불러오기
	- `저장하기` >  .ani(또는 .anz) 파일로 저장


#### 표시목록 만들기
- .dat와 .ani 파일은 [[2.7.3. 표시목록 만들기]]에서 .pla 또는 .bgp로 표시목록을 만들어 LED 모듈에 표출
- ani 파일의 프레임이 많아 용량이 커진다면 압축이 적용된 daz, anz 파일로 저장할 것을 권장 (다빛채 V2.4.8 이상)

> [!note] 상세한 변환과정은 [다빛채 매뉴얼 > 4.6 표시파일: 그래픽 이미지 변환하기 (샘플6)](http://www.dabitsol.com/files/DabitChe_UserManual_v9.0.pdf)
