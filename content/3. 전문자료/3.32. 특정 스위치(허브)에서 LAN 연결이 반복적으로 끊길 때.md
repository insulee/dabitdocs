
> [!abstract] 특정 스위치(허브)에 연결하면 LAN 링크가 붙었다 끊어졌다를 반복하는 증상의 원인과 해결 방법
> 스위치의 EEE(절전 이더넷) 기능 결함이 원인. 스위치 교체 또는 컨트롤러 10M 고정 설정으로 해결

#### 증상

- 컨트롤러를 특정 스위치(허브)에 연결하면 **링크가 약 2초 간격으로 연결↔끊김을 반복** (스위치 포트의 링크 LED가 규칙적으로 깜빡임)
- DabitOne·다빛채 어느 쪽에서든 **TCP 연결이 계속 실패**하거나 수시로 끊김 (장치 검색은 되는데 접속이 안 되는 경우)
- **같은 컨트롤러를 다른 스위치나 공유기에 연결하면 정상 동작**
- 확인된 문제 스위치: **NEXI NX-SG1005N** 등 일부 저가형 비관리형 스위치

#### 원인 — 스위치의 EEE(절전 이더넷) 기능

EEE(Energy Efficient Ethernet)는 주고받는 데이터가 없을 때 신호를 잠시 꺼서 전기를 아끼는 스위치의 절전 기능입니다.

- 일부 저가형 스위치는 이 기능에 결함이 있어, **100M로 연결되면 절전 모드에 들어갔다가 링크를 끊어버립니다**
- **컨트롤러 고장이 아닙니다** — 링크 협상은 매번 정상 완료되는데, 성립한 링크가 유지되지 않는 것입니다
- EEE는 100M 이상에서만 동작하므로, **10M로 연결하면 이 기능이 개입하지 않아 해결됩니다**

#### 해결 방법 (셋 중 하나 선택)

| 방법 | 적용 대상 | 설명 |
| --- | --- | --- |
| ① 스위치(허브) 교체 | 모든 경우 | 정상 동작이 확인된 스위치·공유기로 교체. 가장 확실한 방법 |
| ② 스위치의 EEE 끄기 | 관리형 스위치 | 스위치 관리 화면에서 EEE(또는 Green Ethernet) 기능 비활성화 |
| ③ 컨트롤러 10M 고정 | 펌웨어 V4.1.0 이상 | 아래 명령으로 컨트롤러를 10M 전용으로 전환. 스위치를 바꿀 수 없는 현장용 |

> [!tip] 10M로 바꿔도 느려지지 않습니다
> 실측 결과 10M와 100M의 응답 속도·파일 전송 속도는 동일합니다. LED 표출 데이터는 10M 대역폭으로 충분합니다.

#### 10M 고정 설정 명령

- 지원 펌웨어: **V4.1.0 이상** (버전 확인은 [[3.21. 컨트롤러 펌웨어 정보 해석]] 참고)
- 이전 버전의 **10M 전용 펌웨어는 별도로 요청**
- 전송 경로: UDP(5108) 또는 시리얼(115200) — TCP가 안 되는 상황에서도 전송 가능

| 명령 | 동작 |
| --- | --- |
| `![00NG!]` | 현재 상태 읽기 → `{"eth":"UP","ip":"...","lmode":N,"l10m":N}` |
| `![00NG1!]` | **10M 고정** (설정 저장 후 재부팅 시 적용) |
| `![00NG2!]` | auto(100M 포함) 고정 (재부팅 시 적용) |
| `![00NG0!]` | 설정 해제 — 펌웨어 기본값으로 복귀 |

- `lmode` = 저장된 설정값 (1 = 10M 고정 / 2 = auto / 0 또는 255 = 미설정)
- `l10m` = 현재 적용 상태 (1이면 10M만 사용 중)

> [!note] 명령 후 반드시 재부팅
> 설정 명령은 저장만 하고 즉시 적용되지 않습니다. 응답에 `reboot:1`이 오면 저장된 것이며, **재부팅해야 적용**됩니다. 재부팅 후 `![00NG!]`로 `lmode:1`, `l10m:1`을 확인하세요.

#### 설정 절차 예시

1. `![00NG1!]` 전송 → 응답 `{"lmode":1,"l10m":1,"reboot":1}` 확인
2. 컨트롤러 재부팅 (전원 재인가)
3. `![00NG!]` 전송 → `lmode:1`, `l10m:1` 확인
4. 링크가 안정적으로 유지되고 TCP 접속이 되는지 확인

> [!warning] 주의사항
> - **공장초기화하면 이 설정이 풀립니다.** 초기화 후 같은 증상이 재발하면 `![00NG1!]`을 다시 전송하세요.
> - **링크가 완전히 끊긴 컨트롤러에는 명령이 도달하지 않습니다.** 이때는 ①정상 스위치(공유기 직결 등)에 임시로 연결해 설정한 뒤 원래 자리로 옮기거나 ②시리얼(115200)로 명령을 전송하세요.
