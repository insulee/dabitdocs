title: 3.17. Outgoing Inspection Process
---

> [!abstract] The inspection process before products ship
#### 1. Visual inspection
- Check the controllers made by the SMT company with your eyes for defects in appearance.
#### 2. Bootloader and firmware upload
- Upload the bootloader and the firmware to the controller.
- Check for errors that can occur during the upload, and try again if necessary.
#### 3. Program settings and controller operation check
-  If the customer asks, set the font files, screen settings, and network default values.
-   Check that the controller works normally.
#### 4. Display test
- Set up the same environment with the LEDs that the customer uses and the controller to deliver.
- Check the LED display for defects such as text color, sagging text, dot display, and fonts.
#### 5. Random sampling before packing
- Before packing, check random samples again: the LED display, screen settings, network values, and so on.
#### 6. Packing and delivery
- Pack the controllers that passed all inspections.
- Pack them in sponge-type antistatic cases to keep damage during transport as low as possible.
- Deliver the packed products.
