> [!abstract] The process to send a reset command to the DB502 through the DB300 and check it


#### DB502+300 setup diagram
- You must connect the DB300 and the debugging PC/laptop with an RS232 cable. Connect the cable to the PC/laptop with an RS232-to-USB adapter
	- ![[db300-reset_setup1.png|530]]
	- ![[db300-reset_setup2.jpg|370]]
#### Debugging mode settings
- **Important**: after you connect the DB502+300, make sure that they operate correctly

##### DabitOne
- `통신` (Communication) tab > dbNet
	- `Search` at the bottom of dbNet > select the target in the device list[^1]
	- `DB300` GroupBox on the right > `Read`
	- `Debugging`: `Enabled`
	- `Port`: `TTL`
	- `Baud Rate`: `115200`
	- `Write`

##### Dabit Protocol Simulator
- `DABIT Protocol Simulator` > `설정 및 제어` (Settings and control) > `통신 설정` (Communication settings) > communication settings window > `DABITNet`
	- `Network` > `Search` > Board List:  `**-**-**-**-**-**`[^1] 
	- `COMM` > Advanced > DB300 Tab - `Enable`: adds the DB300 Info tab
	- `DB300 Info `> `Read` 
	- Options
		- Debugging State: `Enable`
		- Dev Connect Port: `TTL`
		- Dev Baudrate: `115200`
	- `Write`
	- `Exit`

> [!note] For the DB300 Info tab, see [[3.5. DB300 Tab Items]]

[^1]: Check the Local IP, Port, Subnet Mask, Gateway, and other values of the DB300E

#### SerialPortMon settings
- Connect in 2 ways, UDP and Serial (RS232). Then check the sent packets and whether the reset command runs
	1. UDP connection
		- SerialPortMon > Connect
		- Connection dialog box
			- UDP
			- `시작 IP 주소` (Start IP address): the same address as in the Internet Protocol Version 4 (TCP/IPv4) properties of the PC
			- `원격 IP 주소` (Remote IP address): `255.255.255.255`
			- Select `Broadcast`
			- `포트번호` (Port number): `5108`
			- Connect
			- ![[db300-reset_7.png|270]]![[db300-reset_8.png|230]]
	2. Serial connection
		- **Important**: make sure that the DB300 and the PC are connected with an RS232 cable
		- SerialPortMon > Connect
		- Connection dialog box
			- Serial(COM)
			- `연결포트` (Connection port): the port of the RS232 cable
			- `통신속도` (Speed): `115200`
			- `데이터비트` (Data bits): `8`
			- `패리티` (Parity): `None`
			- `정지 비트` (Stop bits): `1`
			- `흐름 제어` (Flow control): `None`
			- Connect
		- ![[db300-reset_9.png|300]]
#### Reset commands
- Reset commands
	- **Reset command with a response**
	    - Transmit packet:
	        - `++SET++![00410!]`
	    - Response packet:
	        - `![00410!]`
	- **Reset command without a response**
	    - Reset command for one MAC address
	        - `RESET  <MAC address of the DB300>` 
	    - Reset command for all controllers on the same network
	        - `RESET  DIBD-ALL`
	- **Caution**: put 2 spaces between RESET and the MAC address/DIBD-ALL
- `단축키 지정` (Assign shortcut keys) > enter the reset commands in advance in `단축키가 눌렀을때 전송할 문자열` (String to send when the shortcut key is pressed)
	- ![[db300-reset_10.png]]
	- Click `보내기` (Send) for one command at a time. Then
		- the UDP window shows the sent packet, and
		- the Serial window shows whether the reset ran

	1. `++SET++![00410!]`
		- ![[db300-reset_11.png|250]]![[db300-reset_12.png|250]]
	2. `RESET  <MAC address of the DB300>`
		- ![[db300-reset_13.png|250]]![[db300-reset_14.png|250]]
	3. `RESET  DIBD-ALL` 
		- ![[db300-reset_15.png|250]]![[db300-reset_16.png|250]]
