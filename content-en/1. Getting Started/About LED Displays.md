> [!abstract] An introduction for readers who are new to LED display controllers, LED modules, and communication protocols

> [!tip] Open the material
> This material uses diagrams and live examples. It shows how an LED display receives data and shows text on the screen. It also shows how external systems (parking control, PLC, sensors) send data to an LED display.
>
> **<a href="/en/static/signage-intro-en.html" target="_blank" rel="noopener">About LED Displays</a>** — 28 full-screen slides, about 20 minutes (opens in a new tab)

### 1. Contents

| Part | Content |
|------|------|
| **Part 1 — What is a protocol LED display controller?** | How LED modules and the controller fit together, remote-control type vs. protocol type, how data flows to the screen |
| **Part 2 — The hardware that makes the screen** | LED modules, pixel pitch (P3/P4/P6/P8/P10), many screen sizes from the same module |
| **Part 3 — Sending data** | TTL · RS232 · RS485 · Ethernet · Wi-Fi connections, packet structure, packet builder |
| **Part 4 — Integration examples** | Parking control, illegal parking enforcement, PLC, noise sensor, relay output |

### 2. Interactive widgets

The material includes widgets. You can click them to see how things work.

- Packet builder — change the message, color, effect, or speed. The LED preview and the generated packet change in real time
- Integration simulator — parking control (free spaces change as cars enter and leave), illegal parking enforcement (detects violating vehicles), PLC (calls up screens), noise sensor (shows dB readings)
