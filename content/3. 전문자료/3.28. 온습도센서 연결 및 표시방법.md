
> [!abstract] 온습도 센서의 연결 및 표시방법 안내
> 온습도 센서(SHT30)는 DB502S 제품에만 연결가능

#### 온습도 센서 연결

| 컨트롤러 J4 Relay | SHT30       |
| ------------- | ----------- |
| GND           | GND (검정색)   |
| D1            | 클럭 신호 (노란색) |
| D2            | 데이터 신호(녹색)  |
| 5V            | VCC (빨간색)   |

#### 온습도 표시 방법
- 보드 기능 설정 > J4(4핀) 모드 > SHT31(DB502)
- 아스키 프로토콜 >  `![000/C2온도:/C1/I35/C2/u164/C2습도: /C1/I37/C2/u037!]`
	- 2단 6열 모듈 기준으로 작성
	- 정보문구(`/ixx`)에 관한 자세한 내용은 [[3.27. 정보문구 표시 방법]] 참고
	- 사용자폰트(/uxxx)에 관한 자세한 내용은 [[2.4.3. 사용자 폰트 입력 방법#ASCII]] 참고
- 온습도 확인 패킷
	- 전송 메시지: `![00D10!]`
	- 받은 메시지: `![00D1 26.6 85.0!]` - 온도: 26.6도, 습도: 85%
