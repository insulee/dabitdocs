
>[!abstract] 표출신호 설정 방법 안내
### 표출신호 설정 경로

#### DabitOne
- `설정` > `표출신호 설정`

#### DBPS
- `설정` > `표출신호 설정`

#### 다빛채
- `환경설정` > `표출신호 설정`


### 표출신호 설정 방법
- 표출신호: `해당 모듈의 표출신호` 
- Color Order: `RGB` (필요시 변경)
- Scan Order: `138 IC` (기본값)
- `전송`

### 프로그램에서 표출신호가 없는 경우

- Drive IC 지원 가능 여부를 확인
- [[2.3.2. 표출신호 문자열 패턴 프로토콜 설정 매뉴얼]]을 참고하여 표출신호 설정


### DabitOne 표출신호 화면 기능 (V4.5.5 기준)

`설정` > `표출신호 설정` 화면에서 아래 기능을 쓸 수 있습니다.

#### 두 가지 신호 체계 보기

- 신호 목록은 **문자열 패턴**(예: `S16D1T1C0I0W16P0_a16`)과 **이전 신호**(예: `16D-P16D1S11`) 두 체계로 볼 수 있습니다
- 목록 아래 `이전 신호 보기` / `문자열 패턴 보기` 버튼으로 전환합니다
- 구형 자료에 이전 신호명만 적혀 있어도 그대로 찾아 쓸 수 있습니다

#### 모듈 정보 확인

- 목록에서 신호를 선택하면 오른쪽 `모듈 정보`에 해당 신호를 쓰는 모듈이 표시됩니다
- 다빛솔루션 제품명과 호환 타사 모듈(HUB75 계열)이 함께 나와, 모듈 뒷면 모델명으로 신호를 역으로 찾을 때 유용합니다

#### 자주 쓰는 신호 ★ 등록

- 신호를 선택하고 `★ 등록`을 누르면 목록 위쪽에 ★ 표시로 고정됩니다
- 다시 선택해 `★ 해제`를 누르면 풀립니다. 현장별로 자주 쓰는 신호를 위에 모아둘 때 씁니다

#### 메모

- 신호마다 메모를 남길 수 있습니다 (예: "OO현장 P10 모듈")
- 메모를 쓰고 `메모 저장`을 누르면 프로그램을 다시 켜도 유지됩니다

#### 표출신호를 모를 때 — 자동전송

- `자동전송`을 누르면 설정한 간격(기본 3초)으로 목록의 신호를 하나씩 차례로 전송합니다
- 화면이 **제대로 나오는 순간의 신호가 그 모듈의 표출신호**입니다. `중지`를 누르고 해당 신호를 `전송`으로 확정하세요
- 신호가 틀리면 글자가 뒤섞이거나 눌려 보이고, 화면이 아예 나오지 않기도 합니다

#### 목록에 없는 신호 — 표출신호 입력

- `표출신호 입력` 버튼을 누르면 코드를 직접 넣는 창이 열립니다
- `전송`: 코드를 바로 전광판에 적용 / `등록 후 전송`: 목록에 저장하면서 적용 — 등록한 코드는 프로그램을 다시 켜도 유지됩니다
- 등록된 신호는 같은 창에서 `선택 전송`·`삭제`로 관리합니다
- 코드 작성 규칙은 [[2.3.2. 표출신호 문자열 패턴 프로토콜 설정 매뉴얼]] 참고. 컨트롤러 펌웨어 V3.8.3 이상에서 지원

> [!tip] 신형 컨트롤러(펌웨어 V3.8.3 이상)는 ASCII 명령 `![00H2!]`로 표출신호를 조회·설정할 수 있습니다 — [[2.9.2. 신·구 명령 대응표]] 참고

> [!info] 다빛솔루션 모듈과 타업체 모듈의 표출신호는  [[3.1. LED 모듈정보와 표출신호]]를 참고
