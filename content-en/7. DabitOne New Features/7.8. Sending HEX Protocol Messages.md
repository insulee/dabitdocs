---
title: 7.8. Sending HEX Protocol Messages
---

> [!abstract] In the HEX protocol area of the Send tab, you select the text display attributes on the screen, and DabitOne makes and sends the packet
> You do not need to memorize command strings. Select the items, enter the text, and click `HEX 전송` (HEX send). With `ASCII 변환` (ASCII conversion), you can also see the same content as an ASCII command string.

#### Overview

- The `전송` (Send) tab has 3 areas.
	- **HEX protocol** — the area to send one text with its display attributes. This is the topic of this document
	- **ASCII protocol** — the area to enter and send a command string directly. See [[2.8.1. ASCII Protocol Manual]]
	- **LED display control** (right column) — the area to send, with one button, commands that are separate from the text, such as page count, brightness, and power
- The HEX protocol and the ASCII protocol do **the same work in different formats**. Each item that you select on the screen matches 1:1 an attribute code of the ASCII command, such as `/P`, `/D`, and `/F`.
- When to use it
	- When you show text on the LED display and check it while you change the effects, colors, and size
	- When you prepare an integration with an external system — make the settings on the screen, export them as a string with `ASCII 변환` (ASCII conversion), and give the string to the developer

![[hex_tab_overview.png]]

#### Steps

1. In the `통신` (Communication) tab, set up the connection to the LED display. In the `설정` (Settings) tab, make sure that the LED display size is the same as the actual board. If the size is different, the area (X · Y) coordinates do not match
2. In `전송` (Send) tab > HEX protocol, select the `메시지종류` (Message type) and the `섹션` (Section)
3. Select the display repeat, effects, font, area, and colors. If there is nothing to change, keep the default values
4. Enter the text to show in the text box at the bottom
5. Check the look on the PC screen with `미리보기` (Preview)
6. Click `HEX 전송` (HEX send). When the log below shows `TX:` (sent packet) and `[OK] Receive:` (LED display response), it is successful

> [!tip] When there is no response
> If the log shows `[FAIL] – 컨트롤러 응답 없음` (no controller response) instead of `[OK] Receive:` and the «전송 실패» (Send failed) notification appears, the port opened, but the LED display did not answer. Check the cable, power, communication speed, and RS485 address. A message of the «연결 안 됨» (Not connected) type means that the port or socket itself did not open. In that case, first check the connection method, address, and port in the `통신` (Communication) tab.

#### Item descriptions

The **ASCII match** column of the table shows which attribute code each item becomes when you click `ASCII 변환` (ASCII conversion). Chapter 2 of [[2.8.1. ASCII Protocol Manual]] gives the meaning of the codes.

| Item | Values that you can select | Meaning | ASCII match |
| --- | --- | --- | --- |
| `메시지종류` (Message type) | Real-time / Page | Real-time text shows once right now. Page text is saved in the controller and shows in turn. When you select `페이지` (Page), the page number (1~10) box appears | `/Pxx` (page number) |
| `섹션` (Section) | 0 / 1 / 2 | When you divide the screen, the number of the area where this text goes | `/P__yy` (section number) |
| `표시반복` (Display repeat) | Infinite repeat / Do not show / 1 to 10 times, 20 to 90 times (in steps of 10) | How many times to show the text | `/Dxx` (99=infinite) |
| `화면전환` (Screen change) | Immediate change / Sequential change | Immediate change stops the current text and changes at once. Sequential change changes after the current text ends | `/D__yy` (01=immediate, 00=sequential) |
| `인코딩/폰트` (Encoding/font) | EUC-KR/Hangul combination type, UTF16/Unicode, UTF8/Hangul combination type, UTF8/Unicode | The pair of the character code that the PC sends and the font type that the controller uses. With the default font set, keep `EUC-KR/한글조합형` (EUC-KR/Hangul combination type). Use the Unicode items only with a font group that has a Unicode font — if it is different from the board font, Korean text breaks or shows as blanks | `/Fxx` |
| `폰트크기` (Font size) | 12·14·16 (default)·20·24 … 64 pixels | Character height. The controller must have a font of that size | `/F__yy` |
| `폰트그룹` (Font group) | Font group 1~4 | Which of the font sets saved in the controller to use | `/Tx` |
| `입장효과` (Entry effect) | Stop · move · wipe · blind · curtain · zoom · rotate · background flash · text flash · 3D effect + direction | The movement when the text appears. When you select an effect, the options in the direction box on the right change to fit that effect | `/Exx` |
| `퇴장효과` (Exit effect) | Not used + the same list as the entry effects | The movement when the text disappears | `/E__yy` |
| `효과속도` (Effect speed) | 0 (fast) ~ 255 (slow) | The smaller the number, the faster | `/Sxx` |
| `유지시간` (Stay time) | 0 seconds ~ 9 hours | The time the text stays on the screen after it fully appears | `/S__yy` |
| `가로영역(X)` (Horizontal area (X)) | 0 ~ screen width, in steps of 4 pixels | The horizontal range (start~end) for the text. `0 ~ 0` is the full screen | `/Xxxyy` |
| `세로영역(Y)` (Vertical area (Y)) | 0 ~ screen height, in steps of 4 pixels | The vertical range (start~end) for the text. `0 ~ 0` is the full screen | `/Yxxyy` |
| `배경이미지` (Background image) | Not used / image 1~255 | The number of a background image saved in the controller — [[3.3. Making and Showing Background Images]] | `/Bxxx` |
| `문자색` (Text color) | Digit string of 0~7 | Sets the color **of each character**. See «How to write the text color» below | `/Cx` |
| `배경색` (Background color) | One digit of 0~7 | Background color behind the characters | `/Gx` |
| `문구` (Text) | Free input | The text to show on the LED display | The body at the end of the command |

The color numbers are as written on the screen: `0:검정 1:빨강 2:초록 3:노랑 4:파랑 5:분홍 6:하늘 7:흰색` (0: black, 1: red, 2: green, 3: yellow, 4: blue, 5: pink, 6: sky blue, 7: white).

> [!note] Range of the area lists
> The horizontal and vertical area lists follow the LED display size in the `설정` (Settings) tab. For a 96×32 screen, the horizontal list goes from 0 to 96, and the vertical list from 0 to 32, in steps of 4 pixels.

#### How to write the text color

In the text color box, write color numbers one after another, **as many as the characters**. The first digit is the color of the first character, and the second digit is the color of the second character.

The examples use the Korean text `다빛솔루션` («Dabit Solution», 5 characters).

| Text | Text color | Result |
| --- | --- | --- |
| `다빛솔루션` | `3` | All 5 characters yellow |
| `다빛솔루션` | `12` | 다 red; 빛·솔·루·션 green |
| `다빛솔루션` | `12345` | Each character red · green · yellow · blue · pink |

If the text is longer than the digit string, **the last digit repeats to the end**. `미리보기` (Preview) shows the color of each character as it is, so check it before you send.

#### The 4 buttons

| Button | What it does |
| --- | --- |
| `초기화` (Reset) | Returns the items to the default values and clears the text. It does not send |
| `ASCII 변환` (ASCII conversion) | Converts the currently selected items and text to an ASCII command string and puts it in the ASCII protocol box below. You can copy it with `패킷복사` (Copy packet) and use it for external integration development. It does not send |
| `미리보기` (Preview) | Opens the LED display preview window and shows the look on the PC screen. If you change values after the window opens, click the button again to apply them |
| `HEX 전송` (HEX send) | Sends to the LED display. During sending, the button is disabled for a short time |

![[hex_ascii_convert.png]]

Example of the `ASCII 변환` (ASCII conversion) result — with the default values and the text `다빛솔루션`:

```
![000/P0000/D9901/F0003/E0101/S2008/X0000/Y0000/B000/C1/G0/T0다빛솔루션!]
```

The order is `/P0000` (real-time · section 0) `/D9901` (infinite repeat · immediate change) `/F0003` (EUC-KR · 16 pixels) `/E0101` (entry stop · exit stop) `/S2008` (speed 20 · stay 4 seconds) `/X0000` `/Y0000` (full area) `/B000` (no background) `/C1` (red) `/G0` (black background) `/T0` (font group 1).

> [!note] When the text color has several digits
> `ASCII 변환` (ASCII conversion) puts only the **first digit** of the text color box in `/C`. To write a color for each character in an ASCII command, split it yourself in the `/C1빨강/C2녹색` (빨강 = «red», 녹색 = «green») way of [[2.8.1. ASCII Protocol Manual]].

#### Right column — LED display control

These commands change the LED display state, separately from the text. Select a value and click the button next to it, and the command goes out at once.

| Item | What it does | As ASCII |
| --- | --- | --- |
| `페이지메시지` (Page message) > `페이지 수` (Page count) | Sends how many page messages to cycle (1~10) | `![006005!]` (5) |
| `페이지메시지` (Page message) > `초기화` (Clear) | Clears the page messages. `전체` (All) or one of `Page 1~10` | `![006199!]` (all) |
| `밝기` (Brightness) | 100 / 75 / 50 / 25 / 5%. `고급설정` (Advanced settings) opens the window for brightness by time of day | `![005050!]` (50%) |
| `전광판 켜기/끄기` (LED display on/off) | Turns the LED output on and off. This is different from the controller power | `![00211!]` / `![00210!]` |
| `배경이미지` (Background image) | Loads a saved background image number | `![0020010!]` (No. 10) |
| `화면채우기` (Fill screen) | Fills the whole screen with one color. For checking wiring and colors | `![00707!]` (white) |
| `섹션별 효과` (Effects per section) | Whether to start the effects of several sections together (simultaneous) or run them separately (individual) — [[2.5.3. Simultaneous and Individual Effects per Section]] | `![0062N!]` / `![0062Y!]` |
| `전광판 화면` (LED display screen) | Shows the actually sent screen on the PC in a borderless window. This is not a transfer — [[7.1. Preview and LED Display Screen]] | — |

#### Good to know

- **When you change the message type, page, or section, the input values change with it.** DabitOne remembers the last settings separately for each page+section combination. If the text looks different after you change to section 1, the values saved for section 1 came back. They stay after you turn the program off and on
- **Reading the log** — after `TX:` is the sent packet, and after `[OK] Receive:` is the LED display response. You can tidy the log with fold (▼) and `지우기` (Clear)
- **The effect directions are different for each effect** — move · wipe · blind: left · right · up · down; curtain: horizontal · vertical open · close; rotate: clockwise · counterclockwise; flash: color. For the code table, see [[3.23. Message Entry and Exit Effect Codes]]
- To send a page message, you must first send the **page count** in the right column. Numbers larger than the page count do not show
- `미리보기` (Preview) is a draft before sending, and `전광판 화면` (LED display screen) is the screen that was actually sent. Both are approximations that the PC draws, so do the final check on the actual LED display
