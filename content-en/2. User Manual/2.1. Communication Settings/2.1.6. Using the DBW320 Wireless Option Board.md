> [!abstract] How to change the LED display text from a phone with the DBW320 wireless option board
> Connect the phone to the Wi-Fi of the option board and use the web editor. The DabitOne method (relay) is in preparation

> [!note] ※ mark
> Items with ※ still need confirmation. We update this document as soon as they are confirmed

#### What is the DBW320

- It is a **wireless option board that you attach by cable to the 10-pin (BH1) connector** of the LED display controller
- The option board turns on its own Wi-Fi (in this document, the **board Wi-Fi**). When you connect a phone to it, you can change the LED display text with the **web editor**
- It works even when the site has no router
- It is a wireless connection method that replaces the BLE (Bluetooth) connection

#### Check before installation

| What to check | Details |
| --- | --- |
| Antenna | **Always attach** the external antenna to the antenna connector (U.FL) of the board. Without it, the Wi-Fi signal is very weak |
| Power | One USB-C 5V supply turns it on |
| Controller connection | Connect it to the BH1 connector of the controller with the 10-pin cable |

#### 1. Use it from a phone (web editor)

##### Connect to the board Wi-Fi

1. Supply power to the option board
2. **Wait about 2 minutes.** A new board gets ready to receive router settings for 2 minutes after you turn it on, and then it turns on the board Wi-Fi
3. In the Wi-Fi list of the phone, select **the name that starts with `DBW320-`** and connect
	- The last four characters of the name are different for each board (for example: `DBW320-B841`)
	- The password is **the shared password that you received with the product**
4. The settings screen («옵션보드 무선 설정» (Option board wireless settings)) can open automatically. If it does not open, enter **`192.168.4.1`** in the address bar of the browser
	- On an iPhone, it may not open from the address bar. In that case, turn on Safari after you connect to the Wi-Fi, and open it from the login window that appears

- **Only 2 devices at a time** can connect to the board Wi-Fi
- The board Wi-Fi has no internet. Depending on the phone, the internet can stop while the phone is connected

> [!tip] To skip the wait each time you turn it on
> If the site uses only the board Wi-Fi without a router, tap 「AP 로 계속 운용」 (Keep running as AP) at the bottom of the settings screen once. After that, the board Wi-Fi comes on right away each time you turn it on, with no wait

##### Change the text

1. Tap 「화면 문구 만들기」 (Make screen text) on the settings screen. You can also enter `192.168.4.1/maker.html` in the address bar of the browser
2. Select the **«문구» (Text)** tab at the top
3. Enter the text in **«바로 띄울 문구» (Text to show now)** (up to 60 characters), and select the text color, text size, effect, stay time, and scroll speed
4. When you tap 「바로 띄우기」 (Show now), «문구를 띄웠습니다 (옵션보드 경유)» (The text is shown (via the option board)) appears, and the LED display shows the text

- If the LED display does not show it, change **«한글 방식» (Korean encoding)** between «유니코드 폰트» (Unicode font) ↔ «조합형 폰트» (Johab font) and send it again

#### 2. Use it with DabitOne (relay) — in preparation

- In this method, you find a DBW320 that is connected to a router with 「찾기」 (Find) on the DabitOne «전광판 연결» (Display connection) tab, and tap 「연결 칸에 넣기」 (Put in the connection fields). Then, like a wired LAN board, all DabitOne transfers go through the DBW320 to the attached controller
- The firmware is in preparation. We will add how to use it to this document when it is ready
- Until then, the wireless option board does not connect even if it shows in DabitOne 「찾기」 (Find)

#### Troubleshooting

| Symptom | What to check |
| --- | --- |
| The board Wi-Fi does not show in the list | ① Is the external antenna attached? ② Have about 2 minutes passed since you turned it on? |
| The password is not correct | The password of the board may have been changed. Connect with the changed value, or contact Dabit Solution |
| `192.168.4.1` in the address bar does not open | Open it from the login window that appears right after you connect to the Wi-Fi (on some phones, it appears when you open the browser) |
| Another phone does not connect | Only 2 devices at a time can connect to the board Wi-Fi. Disconnect another device and connect again |
| The LED display does not show the text that you send | Check the 10-pin cable connection, change «한글 방식» (Korean encoding), and send again |

- If it still does not work, keep it in that state and contact Dabit Solution
