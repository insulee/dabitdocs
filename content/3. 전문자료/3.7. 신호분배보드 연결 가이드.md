- 표출신호: `04D-P32D2S31-2<1^4<3`
- LED 모듈: 국내 보급형 전광판 판매 업체 모듈(코런, 양재, 가포, 서울엘이디, 레디스)

- DB600 (최대 4단 표출)
	- BUF21-HUB75-OUT34P => BUF51-3C34-3C20-6Y => SEC410-SD-GP => 모듈
		- ![[3color4duty_db600.png]]
- DB500 (최대 2단 표출)
	- BUF20-HUB75-3C20P -- SEC410-SD-GP -- 모듈
	- ![[3color4duty_db500.png|400]]
#### 1/8 Duty
- 표출신호: `08D-P16D2S23-1^2`
- LED 모듈: 국내 보급형 전광판 판매 업체 모듈(코런, 양재, 가포, 서울엘이디, 레디스)
	- 가포 : GMS3CD8-91209
	- 서울/포스 : SD-83N11(8D)
	- 코런 : CM8D-D83N-A
- **DB500 · DB600 공통 (현행)**: 컨트롤러 HUB75 포트 => **BUF27-HUB75-3C26P-GP8D (V2)**(16 > 26핀 변환) => 모듈
	- HUB75-1에 연결하면 1단, HUB75-2에 하나 더 연결하면 2단 표출

- (단종) DIBD-SEC840-8D-GP를 쓰던 기존 구성 — SEC840은 단종되어 위 BUF27로 대체됩니다
	- DB600: BUF21-HUB75-OUT34P => BUF51-3C34-3C20-6Y => DIBD-SEC840-8D-GP => 모듈

#### DB520 · DB720에서 3컬러 모듈
- DB520 · DB720은 1/4 duty · 1/8 duty 3컬러 표출신호를 다빛원 HEX 방식이나 구버전 ASCII로 보내도 정상 표출됩니다. DB500 · DB600 등 다른 기종도 정식 V4.5.4로 올리면 같습니다(그 전 판은 글자가 깨지거나 나오지 않았음)
- 다른 기종을 V4.5.4로 올릴 때, 예전에 HEX · 구버전 ASCII로 이 신호를 저장해 둔 보드는 명령 없이 램프 방식으로 바뀝니다. 이 모듈이 아닌 패널에 그 신호를 쓰던 현장은 표출이 달라질 수 있으니 실제 모듈의 표출신호를 다시 보내십시오
- **DB520 · DB720 + BUF20 어댑터 + 가포 1/4 duty 램프 모듈은 표출되지 않습니다** — 하드웨어 한계(3.3V 직결 출력이 버퍼 없는 어댑터를 거치면 모듈을 구동하지 못함. 같은 구성은 DB502에서 정상). 전용 버퍼 보드 제작 중이니 필요하시면 문의해 주십시오
