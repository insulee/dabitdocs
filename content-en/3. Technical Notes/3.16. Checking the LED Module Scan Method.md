title: 3.16. Checking the LED Module Scan Method
---

#### Terms
- **Pixel**
	- One **unit that emits light**. The number and density of pixels decide the resolution and sharpness of the screen
- **LED chip**
	- A semiconductor element that emits light when current flows. **One pixel has 3 chips (RGB)**
- **Drive IC**
	- A semiconductor chip that supplies and controls the current of the LED module. Usually its 24 pins handle the input, output, and control signals
		- GND (pin 1): ground
		- SDI (pin 2): Serial Data Input
		- CLK (pin 3): Clock Input
		- LE (pin 4): Latch Enable
		- OE (pin 21): Output Enable
		- SDO (pin 22): Serial Data Output
		- VDD (pin 24): power supply pin
		- R-EXT (pin 23): connect an external resistor to set the current
		- **OUT 0~OUT 15: output pins that drive each LED chip**
			- One pin drives one LED chip
			- One drive IC (16 output pins in total) controls 16 LED chips
		- ![[pin_configuration.png|200]]
- **Scan method**
	- The scan is the number of rows that are driven at one time in an LED display
	- For example, in 1/8 scan, only 1 row of 8 rows is on at the same time

#### How to find the number of drive ICs needed for a scan method


|     | Step                              | Formula        | Example (2 rows × 2 columns)          | Description                                 |
| --- | ------------------------------- | ---------- | ---------------- | ---------------------------------- |
| 1   | Total pixels                           | a          | 1024 = 32 x 32   | 1 row × 1 column is <br>16x16 pixels                 |
| 2   | Number of LED chips                         | b = a x 3  | 3072 = 1024 x 3  | 3 chips (RGB) <br>in 1 pixel             |
| 3   | Drive ICs needed to control<br>all LED chips | c = b / 16 | 192 = 3072 / 16  | One drive IC <br>controls 16 chips         |
| 4   | Scan method                            | d          | 1/8              |                                    |
| 5   | Drive ICs needed for the scan method                | e = c x d  | 24 = 192 x (1/8) | 1/8 scan needs <br>only one of every <br>8 drive ICs |

#### When you do not know the scan method: find it from the actual number of drive ICs

|     | Step                              | Formula        | Example (2 rows × 2 columns)         | Description                                                  |
| --- | ------------------------------- | ---------- | --------------- | --------------------------------------------------- |
| 1   | Total pixels                           | a          | 1024 = 32 x 32  | 1 row × 1 column is <br>16x16 pixels                                  |
| 2   | Number of LED chips                         | b = a x 3  | 3072 = 1024 x 3 | 3 chips (RGB) <br>in 1 pixel                              |
| 3   | Drive ICs needed to control<br>all LED chips | c = b / 16 | 192 = 3072 / 16 | One drive IC <br>controls 16 chips                          |
| 4   | Number of drive ICs on the module                  | e          | 24              |                                                     |
| 5   | Scan method                            | d = e / c  | 1/8 = 24 / 192  | Only 24 of the 192 drive ICs <br>needed to control all <br>LED chips are on the module |

#### A quick way to check the scan method for 1 row × 1 column
- For a module of 1 row × 1 column 
	- The drive ICs needed to control all LED chips: 48 (c11)
		- 1 row × 1 column = 16x16 pixels = 256 pixels = 768 (= 256 x 3) LED chips
		- 768/16 = 48
	- Count the drive ICs (e) on 1 row × 1 column and divide by 48 (c11) to find the scan method (d)
- Examples
	- DABIT_P8_1R2C_4S_6500cd = 12, 12/48 = 1/4 Scan
	- DABIT_P6_2R2C_8S_6500cd = 6, 6/48 = 1/8 Scan
	- DABIT_P3_1R4C_16S_900cd = 3, 3/48 = 1/16 Scan
	- DABIT_P3_2R6C_16S_2700cd = 3, 3/48 = 1/16 Scan
	- DABIT_P3_4R4C_32S_900cd = 1.5, 1.5/48 = 1/32 Scan
- (Exception) A 3-color module has 2 LED chips (RG) per pixel, so 1 row × 1 column has 512 (= 256 x 2) LED chips
	- The drive ICs needed to control all LED chips: 32 (= 512 / 16) 
	- Count the drive ICs (e) on 1 row × 1 column and divide by 32 (c11_3) to find the scan method (d)
