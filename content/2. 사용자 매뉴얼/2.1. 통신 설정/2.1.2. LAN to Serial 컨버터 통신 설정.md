
> [!abstract] dbNet에서 LAN to Serial 컨버터의 이더넷 버전과 Wifi 버전의 연결 및 네트워크 설정 안내


### 이더넷 버전 연결
#### 특징
- Client TCP/IP, Server TCP/IP, UDP 연결 가능
- 아래의 내용은 Client TCP/IP 연결로, 그 외의 연결은 [[2.1.4. Server TCPIP, UDP 설정]] 참고

#### 네트워크 어댑터의 IPv4 주소 확인
- 윈도우 검색 > 명령프롬프트 > `ipconfig /all`
- 이더넷 어댑터 또는 무선 LAN 어댑터의 IPv4 주소..... : `***.***.***.***` 확인

#### 컨버터의 네트워크 값 입력
- dbNet > `Network` > `Search`
- Board List: 연결하려 컨트롤러의 Mac address 선택
- IP Address, Subnet Mask, Gateway, Port 등 **네트워크 정보 변경**
	- IP Address: 연결되어 있는 네트워크 어댑터 IPv4 주소와 **네번째 옥탯(Octet)은 다른 값**으로 입력
	- 예를 들어
		- 네트워크 어댑터의 IPv4 주소: 169.254.121.210
		- 컨버터의 IP Address: 169.254.121.*** (1~255 중 210을 제외한 값)
		- Subnet Mask, Gateway: 네트워크 어댑터와 **동일한 값**
- `Set`


#### (예외) 이더넷으로 1:1 연결시 네트워크 어댑터의 수동 IP 주소 설정
- 윈도우 검색 > `네트워크 연결 보기`를 눌러 네트워크 연결 폴더 열기
- 이더넷 아이콘 > 우측버튼 클릭 >` 속성` 
- `인터넷 프로토콜 버전 4(TCP/IPv4) `> `속성`
	- 다음 IP 주소 사용
		- IP 주소: 컨트롤러의 IP Address와 **네번째 옥텟(Octet)은 다른 값**으로 입력
		- Subnet Mask, Gateway: 컨트롤러와 **동일한 값**

#### DHCP로 연결

- Dynamic Host Configuration Protocol(DHCP)는 네트워크 상의 장치들이 IP 주소 및 기타 네트워크 설정(서브넷 마스크, 기본 게이트웨이, DNS 서버 등)을 자동으로 할당받을 수 있도록 지원하는 프로토콜
	1. dbNet > `Network` > IP Config Method > `DHCP` > `Set`
	2. 컨버터의 전원을 다시 공급
	3. dbNet > `Network` > `Search`
	4. 자동으로 할당 받은 네트워크 값 확인


### WiFi 버전 - AP모드 연결(기본값)

#### 특징
- AP 모드는 전광판 컨트롤러가 무선 액세스 포인트(라우터 역할)를 하여, PC에서 컨트롤러에 직접 연결
- 네트워크 환경이 없거나, 컨트롤러와 PC가 가까운 곳에서 직접 연결이 필요할 때 사용
- 컨트롤러의 네트워크 설정 없이 바로 접근하여 현장 설치 시 유용 

#### 컨버터의 네트워크 값 입력 (dbNet)
- PC 또는 노트북의 wifi 검색 > `AP-dabitnet`, password: `dabitnet` 
	- 연결시 네트워크 환경에 따라 일정 시간이 소요
	- (참고) 컨버터의 SSID와 Password의 변경은 dbNET > DB300 > Wifi Mode: `AP`, 변경할 SSID/Password 입력 > `Set`
- dbNet > `Search`
- Board List: 연결하려 컨버터의 Mac address 선택
	- IP Address: `192.168.4.1` (**고정 IP로 변경 불가능**)
	- Subnet Mask: `255.255.255.0`
	- Gateway: `192.168.1.1`
	- Port: `5000`
	- `Set`

### WiFi 버전 - Station모드 연결

#### 특징
- Station 모드는 컨트롤러가 기존 Wi-Fi 네트워크에 클라이언트로 연결되는 방식
- 컨트롤러가 기존 Wi-Fi 네트워크에 접속해야 할 때 사용
- 전광판 컨트롤러가 네트워크에 연결된 상태로, PC가 네트워크를 통해 컨트롤러에 접근
- Client TCP/IP, Server TCP/IP, UDP 연결 가능
- 아래의 내용은 Client TCP/IP 연결로, 그 외의 연결은 [[2.1.4. Server TCPIP, UDP 설정]] 참고

#### 무선 LAN 어댑터의 IPv4 주소, 기본 게이트웨이 확인
- 윈도우 검색 > 명령프롬프트 > `ipconfig /all`
- 무선 LAN 어댑터 Wi-Fi의 IPv4 주소 확인

#### 컨버터의 네트워크 값 입력 (dbNet)

- dbNet > `Search`
- Board List: 연결하려 컨버터의 Mac address 선택
- DB300 > Wifi Mode: `STA`, 연결할 공유기의 SSID/Password 입력 > `Set`
- `Search` > IP Address, Subnet Mask, Gateway, Port 등 **네트워크 정보 변경**
	- IP Address: 연결되어 있는 네트워크 어댑터 IPv4 주소와 **네번째 옥탯(Octet)은 다른 값**으로 입력
	- 예를 들어
		- 네트워크 어댑터의 IPv4 주소: 169.254.121.210
		- 컨버터의 IP Address: 169.254.121.*** (1~255 중 210을 제외한 값)
		- Subnet Mask, Gateway: 네트워크 어댑터와 **동일한 값**

#### DHCP로 연결
- Dynamic Host Configuration Protocol(DHCP)는 네트워크 상의 장치들이 IP 주소 및 기타 네트워크 설정(서브넷 마스크, 기본 게이트웨이, DNS 서버 등)을 자동으로 할당받을 수 있도록 지원하는 프로토콜
	1. dbNet > `Network` > IP Config Method > `DHCP` > `Set`
	2. 컨버터의 전원을 다시 공급
	3. dbNet > `Network` > `Search`
	4. 자동으로 할당 받은 네트워크 값 확인
