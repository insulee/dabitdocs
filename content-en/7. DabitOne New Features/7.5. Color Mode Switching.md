---
title: 7.5. Color Mode Switching
---

> [!abstract] Color mode switching (new in DabitOne · advanced)
> An advanced setting that reads and changes the color mode of the controller

> [!note] Official firmware V4.5.4 or later has no color mode switching command
> All models ship with 256 colors (only the DB720 16-bit color option has 65,536 colors), and the firmware file sets the color depth. Switching with the combo box on this screen works only with firmware **V4.4.0 or earlier**. With V4.5.4 or later, only `읽기` (Read) works.

#### What is better

- A function that the legacy programs did not have: you can check and switch the color mode of the controller
- When you select a mode in the combo box, it applies at once after a confirmation window — there is no separate send button

#### How to use

1. In the `색상모드` (Color mode) item of the `고급` (Advanced) tab, click `읽기` (Read) to check the current mode
2. To change it, select a new mode in the combo box — options: `08C 8색` (08C 8 colors) / `08B 256색` (08B 256 colors)
3. When you approve in the confirmation window, DabitOne sends it, and the controller restarts automatically (5–10 seconds)

> [!warning] Caution
> Advanced function. The color mode can work differently by board type and firmware, so always check the display result after you change it. (This item needs more on-site verification)

> [!note] For integration developers — checking and switching the color mode (legacy protocol first)
> 1. **Check the current color capability — all firmware**: look at the letters after the model name in the `![0081!]` response. `_08C` 8 colors · `_08B` 256 colors · `_16C` 65,536 colors. Example: `DIBD600T_08C_04R020C` → 8 colors. See [[3.21. Reading Controller Firmware Information]]
> 2. **Switching — V3.8.3 to V4.4.0**: legacy command `![00470!]` (8 colors) / `![00471!]` (256 colors) or new command `![00H3{n}!]`. Below V3.8.3, the firmware build fixes the color mode, and you cannot change it with a command. Some switching firmware versions in this range still show `08C` in `![0081!]` after you change to 256 colors, so check the current mode with `![00H3!]`
> 3. **V4.5.4 (official) or later**: there is no color depth selection command (H3 write · legacy command 47) — all models have 256 colors, and the firmware file sets the color depth. The `![00H3!]` query works as before — see [[2.9.2. New and Legacy Command Mapping Table]]
