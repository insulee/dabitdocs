---
title: 3.31. Setting the X, Y Coordinate Offset
---

>[!abstract] How to set the X, Y coordinate offset of the ASCII protocol. The command that changes the default 4-pixel unit to a 1-pixel unit, and how to apply it

#### Supported firmware

- Firmware: **V3.0.5 or later**

#### Basic offset concept

- The X, Y coordinate commands of the ASCII protocol (`/Xxxyy`, `/Yxxyy`) use a **4-pixel unit** by default
  - `/X0100`: moves 4 pixels on the X axis: (01) × 4 = 4 pixels
  - `/Y0100`: moves 4 pixels on the Y axis: (01) × 4 = 4 pixels

#### Changing the offset to a 1-pixel unit

- When you need fine position control, set the offset to 1. Then **you can control the position in 1-pixel units**
  - `/X0100`: moves 1 pixel on the X axis: (01) × 1 = 1 pixel
  - `/Y0100`: moves 1 pixel on the Y axis: (01) × 1 = 1 pixel

#### DabitOne setting path

- `고급` (Advanced) tab > `오프셋` (Offset) button > in the `오프셋 변경` (Change offset) window, select the pixel unit and send

> [!note] DabitChe does not support this
> The offset setting is a **DabitOne-only** function. DabitChe does not have this menu. If you need this setting, use DabitOne.

#### Offset setting commands

##### Send packet (special command code: 58)

- `![0058 1!]` : sets the offset to 1 pixel
- `![0058 4!]` : sets the offset to 4 pixels (default)
- Firmware V3.6.0 or later gets the new `![00J6N!]` packet first (no space before the number, example: `![00J61!]`). Only old firmware falls back to `![0058 N!]`

##### Response packet

- `![00580!]` : setting succeeded
- `![0058F!]` : setting failed

#### Examples

##### Offset = 4 pixels (default)

```
![0058 4!]
![000/F0003/X0100/Y0100/C3다빛솔루션!]
```
- `/X0100`: 01 × 4 = moves 4 pixels
- `/Y0100`: 01 × 4 = moves 4 pixels

##### Offset = 1 pixel

```
![0058 1!]
![000/F0001/X0293/Y0230/C7가나다라마바!]
```
- `/X0293`: start point 02 × 1 = 2 pixels, end point 93 × 1 = 93 pixels
- `/Y0230`: start point 02 × 1 = 2 pixels, end point 30 × 1 = 30 pixels

The message text in the examples is Korean: 다빛솔루션 means "Dabit Solution", and 가나다라마바 is a row of sample Korean characters.

> [!note] If the message goes past the frame, set offset=1, then adjust the **X-axis start/end** and **Y-axis start/end** values **to multiples of the character size**. Then the message shows correctly.

> [!warning] After you set the offset, always check the response packet (`![00580!]`) before you send a message. If the setting fails (`![0058F!]`), send it again.

Reference: [[2.8.1. ASCII Protocol Manual]], section 2.2.6 (/Xxxyy, /Yxxyy)
