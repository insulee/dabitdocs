---
title: 2.5.3. Simultaneous and Individual Effects per Section
---

> [!abstract] Simultaneous effects vs. individual effects
> When 2 or more sections use effects at different speeds, this setting decides whether the effect cycles of the sections are **synchronized or independent**. Choose whether all sections move together with the slowest section (simultaneous), or each section moves at its own speed (individual).

#### 1. Overview

- **Simultaneous effects (E0)**
	- Synchronizes the effect cycles of all sections
	- Faster sections wait until the effect of the slowest section ends
	- When the last section finishes → **all sections start** the next cycle **at the same time**
- **Individual effects (E1)**
	- Each section runs its own **independent** cycle at its own speed
	- A faster section starts the next cycle as soon as its effect ends
	- Repeats regardless of the progress of the other sections

#### 2. Where to set it

- Menu path
	- DabitOne: the `섹션별 효과` (Effects per section) group on the right of the `전송` (Send) tab > in the combo, select `효과 동시 표출` (Simultaneous effects) or `효과 개별 표출` (Individual effects) > `전송` (Send)
	- Legacy (DBPS): **실시간 문구 설정 > 효과 동시표출** (Real-time text settings > Simultaneous effects) or **효과 개별표출** (Individual effects)
- ASCII protocol commands
	- `![0062N!]` : **simultaneous** effects (E0)
	- `![0062Y!]` : **individual** effects (E1)
	- Response: `![00620!]` (processed normally)
	- Send the display mode first, then send the section packets
- Value in the firmware information
	- `E0` : simultaneous effects
	- `E1` : individual effects
	- For how to check the firmware information, see [[3.21. Reading Controller Firmware Information]]

#### 3. How it works — example

> [!example] Conditions
> - Screen: 2 rows × 6 columns
> - Section 1 (row 1): entry/exit effect = move left, speed = `10` (fast)
> - Section 2 (row 2): entry/exit effect = move left, speed = `30` (slow)

##### Simultaneous effects (E0)

| Time | Section 1 (speed 10) | Section 2 (speed 30) |
|---|---|---|
| Cycle start ~ section 1 done | Moving left | Moving left |
| Section 1 done ~ section 2 done | **Waits (stopped)** | Keeps moving left |
| When section 2 is done | **Starts together** → next cycle, move left | **Starts together** → next cycle, move left |

- Even if section 1 finishes first, it **waits** until section 2 ends
- When the slowest section finishes → all sections start the next cycle **together**
- Shows several sections in harmony, **as one unit**

##### Individual effects (E1)

| Time | Section 1 (speed 10) | Section 2 (speed 30) |
|---|---|---|
| Cycle start ~ section 1 done | Moving left | Moving left |
| Right after section 1 is done | Starts the next cycle **at once**, moving left | Keeps moving left (still in cycle 1) |
| When section 2 is done | In its own cycle | Starts the next cycle, moving left |

- Section 1 keeps repeating **at its own speed**, with no wait
- Section 2 also runs at its own speed, regardless of section 1
- Each section works in its own rhythm, like an **independent information board**

#### 4. ASCII example measured on a board

These are the exact packets that were checked on a real board (96×32) in firmware verification.

```
![0062Y!]
![000/P0000/Y0004/F0003/S1000/E0606/D1001/C6가나다라!]
![000/P0001/Y0408/F0003/S3000/E0606/D1001/C11234!]
```

- Line 1: sets individual effects (to change to simultaneous effects, `![0062N!]`)
- Line 2: section 0 = row 1 (`/Y0004`), sky-blue `가나다라`, right-to-left move (`E0606`), speed 10 (fast)
- Line 3: section 1 = row 2 (`/Y0408`), red `1234`, same effect, speed 30 (slow)
- Measured result
	- **Simultaneous (N)**: when the fast row 1 finishes its cycle, it **waits with a blank screen**. When the slow row 2 ends, the two rows restart **together**
	- **Individual (Y)**: row 1 does not wait and keeps repeating at its own speed — the start times of the two rows drift apart

#### 5. Practical example — an updated value and scrolling guidance text

Row 1 shows a value that changes often (vehicle number, temperature, and so on), and row 2 shows scrolling guidance text.

```
![000/P0000/D9901/X0000/Y0004/E0101/S1000/T0/C1123가 4567!]
![000/P0001/D9901/X0000/Y0408/E0606/S2000/T0/C2지금즉시이동해주세요!]
```

As it is, each time you update (resend) the value in row 1, the text in row 2 starts scrolling again from the beginning.
**To keep row 2 scrolling when you update the value**, change two things.

1. Send individual effects first: `![0062Y!]`
2. In the row 1 packet, change `/D9901` (immediate display) to `/D9900` (normal display)

```
![0062Y!]
![000/P0000/D9900/X0000/Y0004/E0101/S1000/T0/C1456나 7890!]
```

- If you resend with `yy=01` (immediate display) of `/Dxxyy`, the effects of the other sections on the screen also restart
- With `yy=00` (normal display) + individual effects, only the value in row 1 changes, and the text in row 2 keeps scrolling
- For the definition of the `/D` attribute, see [[2.8.1. ASCII Protocol Manual#2.2.2. /Dxxyy|2.8.1 /Dxxyy]]

#### 6. How to choose

| Situation | Recommended setting |
|------|----------|
| You want several sections to work as one unified display | Simultaneous effects (E0) |
| You run each section as an independent information area | Individual effects (E1) |
| You use effects with very different speeds (you want the fast section to repeat often) | Individual effects (E1) |
| Real-time text shows slight jitter | Individual effects (E1) |

> [!tip] Example: fixing text jitter
> If real-time text shows slight jitter or flicker, changing the setting to individual effects can remove the interference from cycle synchronization between sections, and the symptom may improve.
