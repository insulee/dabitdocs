title: 3.26. KS C 5601 (Wansung) Korean Code Table
---

> [!abstract] Manual for the precomposed (Wansung) Hangul code table


### 1. Overview

- KSC5601 is a precomposed (Wansung) Hangul encoding standard that defines the Korean character set. It was established in 1987 as a Korean information and communication standard (KS X 1001)
- The Hangul in this standard is 2,350 frequently used precomposed syllables. Together with Hanja (Chinese characters) and special characters, they are expressed in a 2-byte code (94×94 array)


### 2. KSC5601 code areas

#### 2-1. Main code ranges

| Code area         | Description            | Range              |
|-------------------|----------------|-------------------|
| Precomposed Hangul characters  | 2,350 precomposed Hangul syllables | 0xB0A1 ~ 0xC8FE  |
| Hanja and special characters  | Includes Hanja and special symbols | Other areas          |

#### 2-2. Structure of the precomposed Hangul characters

- The 2,350 Hangul syllables are arranged in **Korean alphabetical (가나다) order**. Codes are given in order from 0xB0A1, 94 syllables per row
- Not every combination of initial, medial, and final jamo is included. A syllable that is not in the 2,350 (for example, 똠) has no 2-byte code


### 3. How to find a Hangul code value

> [!warning] You cannot calculate the code from the initial · medial · final indexes
> KSC5601 Hangul is a table of selected syllables in use, so you cannot calculate a code value from the jamo indexes. The formula `(initial × 588) + (medial × 28) + final` is the **Unicode** formula (see 6.3.3).

1. Find the **sequence number** (from 0) of the syllable in the table — 가 = 0, 각 = 1, 간 = 2 …
2. Get the two bytes from the sequence number
   - First byte = 0xB0 + (the quotient of sequence number ÷ 94)
   - Second byte = 0xA1 + (the remainder of sequence number ÷ 94)
3. In a program, do not make the table yourself. Use the EUC-KR (CP949) conversion function
   - Example (Python): `"닿".encode("euc-kr")` → `B4 EA`


### 4. Example calculations

#### Code value of "가":
- Sequence number: 0
- 0 ÷ 94 = quotient 0, remainder 0
- First byte: 0xB0 + 0 = 0xB0 / second byte: 0xA1 + 0 = 0xA1
- Final code value: **0xB0A1**

#### Code value of "각":
- Sequence number: 1
- 1 ÷ 94 = quotient 0, remainder 1
- First byte: 0xB0 + 0 = 0xB0 / second byte: 0xA1 + 1 = 0xA2
- Final code value: **0xB0A2**

#### Code value of "낙":
- Sequence number: 292
- 292 ÷ 94 = quotient 3, remainder 10
- First byte: 0xB0 + 3 = 0xB3 / second byte: 0xA1 + 10 = 0xAB
- Final code value: **0xB3AB**

#### Code value of "닿":
- Sequence number: 449
- 449 ÷ 94 = quotient 4, remainder 73
- First byte: 0xB0 + 4 = 0xB4 / second byte: 0xA1 + 73 = 0xEA
- Final code value: **0xB4EA**

#### Code value of "삶":
- Sequence number: 1111
- 1111 ÷ 94 = quotient 11, remainder 77
- First byte: 0xB0 + 11 = 0xBB / second byte: 0xA1 + 77 = 0xEE
- Final code value: **0xBBEE**

#### Code value of "닭":
- Sequence number: 438
- 438 ÷ 94 = quotient 4, remainder 62
- First byte: 0xB0 + 4 = 0xB4 / second byte: 0xA1 + 62 = 0xDF
- Final code value: **0xB4DF**

### 6. Features of KSC5601 codes and Unicode

#### 6.1. Overview of KSC5601 and Unicode

##### KSC5601

- **KSC5601 (KS X 1001)** is a character set standard established in Korea in 1987. It includes precomposed Hangul
- KSC5601 defines a 2-byte character set of 94×94 in total that includes 2,350 precomposed Hangul syllables and about 8,800 Hanja, special characters, and others
- Hangul is limited to the fixed 2,350 precomposed syllables (you cannot make a new syllable by combining initial, medial, and final jamo)

##### Unicode

- Unicode is a character set standard designed to unify all the characters of the world in one system
- It contains all 11,172 modern Hangul syllables as precomposed characters, and it also contains the initial, medial, and final jamo separately
- Hangul ranges in Unicode:
    - U+AC00 ~ U+D7A3: 11,172 precomposed Hangul syllables
    - U+1100 ~ U+11FF: Hangul Jamo (separate initial, medial, and final characters)
    - U+3130 ~ U+318F: Hangul Compatibility Jamo

#### 6.2. Main differences between KSC5601 and Unicode

| Item           | KSC5601                       | Unicode              |
| ------------ | ----------------------------- | -------------------- |
| Hangul handling | Precomposed characters only                 | Supports both jamo combinations and precomposed characters |
| Number of characters     | 2,350 Hangul characters                 | 11,172 Hangul characters       |
| Combination   | Initial, medial, and final jamo cannot be combined (only fixed syllables) | Initial, medial, and final jamo can be combined     |
| Code range    | 0xB0A1 ~ 0xC8FE               | U+AC00 ~ U+D7A3      |
| Characters it can express | Limited (some characters cannot be expressed)             | All the characters of the world     |

#### 6.3. Mapping between KSC5601 and Unicode

##### 6.3.1. Basic mapping

- The 2,350 KSC5601 Hangul syllables are all included in the 11,172 Unicode precomposed Hangul syllables (U+AC00 ~ U+D7A3), **but they do not correspond 1:1**
- Both tables are in Korean alphabetical (가나다) order, so the order of the syllables is the same. But the gaps between them are different, so you cannot convert by adding or subtracting sequence numbers
    - Example: "간" — KSC5601 sequence number 2 (0xB0A3) / Unicode sequence number 4 (U+AC04)

##### 6.3.2. How to convert

- Convert with a mapping table (codec). Use the EUC-KR (CP949) ↔ Unicode conversion function of your program
    - Example (Python): `"간".encode("euc-kr")` → `B0 A3` / `bytes([0xB0, 0xA3]).decode("euc-kr")` → `간` (U+AC04)

##### 6.3.3. Unicode sequence formula (reference)

- Unicode precomposed Hangul is calculated from the jamo combination (you cannot use this for KSC5601)
- Unicode code = U+AC00 + (initial index × 588) + (medial index × 28) + final index
    - Example: "닿" = ㄷ(3) · ㅏ(0) · ㅎ(27) → (3 × 588) + (0 × 28) + 27 = 1791 → U+AC00 + 1791 = U+B2FF
