---
title: 2.7.5. Media Playback
---

> [!abstract] New controllers can upload GIF, JPG, and MJPEG files to the LED display as they are, with no conversion, and play them
> The `편집` (Edit) tab > `미디어 재생` (Media playback) window handles sending, playing, and playlists in one place.

> [!note] Requirements
> - **Only for new controllers (DIBD520 · 720 series).** For older LED displays, use [[2.7.3. Making a Playlist]] (the conversion method).
> - Reading the list and sending files work over a **network (LAN) connection**. The TCP IP settings on the `통신` (Communication) tab must have the address of the LED display.
> - If the LED display does not support it, a message shows at the top of the window and the functions are locked.

#### Open the window

1. `편집` (Edit) tab > `미디어 재생` (Media playback)
2. When the window opens, it reads the media list saved in the LED display automatically. The remaining storage of the LED display shows at the bottom right.

#### Send media

1. Select a file with `미디어 추가` (Add media) > `찾아보기` (Browse) below — **formats that you can send: GIF · JPG (4:2:0) · MJPEG**
2. When you click `보내기` (Send), a confirmation window opens.

> [!warning] It is not stored together with content of the existing method
> The LED display stores only one method at a time. When you send media, **all content that you put in with the existing method (playlist) is deleted**. In the same way, when you send a playlist, the media is deleted.

- **If a JPG photo is not in 4:2:0 format**, the "사진 변환" (Photo conversion) window opens — click `변환하기` (Convert) to convert it automatically and send it. The quality difference is very small.
- **Convert videos such as MP4** to MJPEG before you send them.
- **For BMP · PNG images**, do not use this window. Use the existing method: load them in `콘텐츠 편집` (Content editing) and send them as a playlist.
- If the same file is already in the LED display, it is not sent again, and a message tells you.

#### Play · check · delete

- `재생` (Play): plays the selected media on the LED display. You can also **double-click** an item to play it.
- `중지` (Stop): stops the playback.
- `10초 확인` (10-second check): shows the selected media on the LED display for only 10 seconds, and then goes back to the original screen — useful to check the transfer result quickly.
- `삭제` (Delete): deletes the selected media from the LED display.

> [!tip] When it does not play
> If the message "이 펌웨어는 재생 명령을 지원하지 않습니다" (This firmware does not support the play command) shows, the controller firmware is old. Update the firmware to the latest version and try again.

#### Playlist (play several items in a loop)

1. Select an item in `저장된 미디어` (Saved media) on the left > `추가` (Add) — it is added to `재생목록` (Playlist) on the right
2. Change the order with `↑`/`↓`
3. `목록 전송` (Send list) — the playlist is uploaded to the LED display and **plays in order, in a continuous loop**
4. `목록 해제` (Release list) — stops the loop playback. The saved media files stay.

- The playlist is saved in the LED display, so when you open the window again, it is read from the LED display and restored as it was.

> [!note] For integration developers
> For the ASCII commands for play (`![00V3 {id}!]`) and stop (`![00V4 1!]`), see [[2.9.2. New and Legacy Command Mapping Table]]
